How the notebooks work

Read any notebook in the browser, or open it in a free cloud environment with one click.

One click to run

Every session has Open in Colab and Open in Kaggle links. No installation needed; run the cells from the top.

Small, honest examples

Runnable cells use small built-in or synthetic data and finish in a minute or two on a CPU. Their numbers show how a method behaves; they are not benchmarks.

Clearly labelled

Cells marked NOT RUN need a GPU, a download or an account. Cells marked TODO are exercises for you to complete.
