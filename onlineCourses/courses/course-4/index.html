Building a Small Bangla Language Model

Take a 5–30M-parameter Bangla GPT from raw text to a public release: Unicode cleaning, corpus building, tokenizer, model design, training on free GPUs, evaluation, instruction tuning against a LoRA baseline, compression and responsible release.

Before you start

One notebook per session. Open them in Kaggle Notebooks or Google Colab.

  • Every notebook runs from top to bottom on a CPU using a small built-in Bangla sample, so you can check it works before adding your own data.
  • Cells marked TODO are for students. Cells marked NOT RUN need the network, a GPU or an account, and were not executed when these notebooks were built.
  • Numbers printed on the built-in sample are demonstrations only. Results on a real corpus are yours to measure.
  • Tested once on 17 November 2026 with Python 3, PyTorch 2.15, tokenizers and regex (current versions at that date).
  • Install on Colab or Kaggle if needed: pip install tokenizers regex datasets
