1. Synthetic keywords in noise¶

Keyword spotting listens all the time for one of a few words ("Hey ...", "stop", "next"). The standard dataset is Speech Commands (Warden 2018), one-second recordings of spoken words, also used by MLPerf Tiny (Banbury et al. 2021); it is a download, so here we use a synthetic stand-in with the same structure. Each one-second clip at 16 kHz belongs to one of five classes:

  • three keywords, each a tone pattern: a rising chirp, two beeps (high then low), and a falling chirp with a harmonic, with random speed (±12%), pitch (±7%), loudness and position;
  • other sounds, which must not trigger: random tones, beep sequences, an up-chirp in the wrong frequency band, only the first beep of keyword 2, and noise bursts;
  • background only.

The background is white noise, low-frequency rumble and mains hum at 50 or 100 Hz, at random levels. Real speech is far more varied; the steps are the same.

import time, copy
import numpy as np, pandas as pd
import torch, torch.nn as nn, torch.nn.functional as F
import matplotlib.pyplot as plt

t_start = time.time()
torch.set_num_threads(1); torch.manual_seed(0); np.random.seed(0)
SR = 16000
CLASSES = ["keyword 1: rising chirp", "keyword 2: two beeps", "keyword 3: falling chirp", "other sound", "background only"]

def tone(f0, f1, dur, harm=0.0):                            # a chirp from f0 to f1 Hz, with 10 ms fade in and out
    n = int(dur * SR); f = np.linspace(f0, f1, n); ph = 2 * np.pi * np.cumsum(f) / SR
    env = np.minimum(1, np.minimum(np.arange(n), n - np.arange(n)) / (0.01 * SR))
    return (np.sin(ph) + harm * np.sin(2 * ph)) * env
def gap(d):
    return np.zeros(int(d * SR))
def keyword(k, r):
    s, fj = r.uniform(0.88, 1.12), r.uniform(0.93, 1.07)       # speed and pitch of this "speaker"
    if k == 0: return tone(500 * fj, 1500 * fj, 0.45 * s)
    if k == 1: return np.concatenate([tone(1000 * fj, 1000 * fj, 0.12 * s), gap(0.08 * s), tone(700 * fj, 700 * fj, 0.15 * s)])
    return tone(2000 * fj, 800 * fj, 0.4 * s, harm=0.4)
def other_sound(r):
    kind = r.integers(5)
    if kind == 0: return tone(r.uniform(300, 2500), r.uniform(300, 2500), r.uniform(0.2, 0.6), harm=r.uniform(0, 0.5))
    if kind == 1: return np.concatenate([np.concatenate([tone(*(2 * [r.uniform(400, 2500)]), r.uniform(0.05, 0.15)), gap(r.uniform(0.03, 0.1))])
                                         for _ in range(r.integers(2, 5))])
    if kind == 2: f = r.uniform(1300, 2200); return tone(f, f * r.uniform(1.6, 2.2), r.uniform(0.3, 0.5))   # up-chirp, wrong band
    if kind == 3: fj = r.uniform(0.93, 1.07); return tone(1000 * fj, 1000 * fj, 0.12 * r.uniform(0.88, 1.12)) # first beep only
    n = int(r.uniform(0.1, 0.4) * SR); return r.normal(0, 0.5, n) * np.hanning(n)                             # noise burst
def background(n, r):
    white = r.normal(0, 1, n)
    rumble = np.cumsum(r.normal(0, 1, n)); rumble -= np.convolve(rumble, np.ones(400) / 400, mode="same"); rumble /= rumble.std() + 1e-9
    hum = np.sin(2 * np.pi * r.choice([50, 100]) * np.arange(n) / SR + r.uniform(0, 6))
    return r.uniform(0.02, 0.15) * white + r.uniform(0.0, 0.2) * rumble + r.uniform(0, 0.1) * hum
def clip(label, r):
    x = background(SR, r)
    if label == 4:
        return x
    ev = keyword(label, r) if label < 3 else other_sound(r)
    start = r.integers(0, SR - len(ev)); x[start:start + len(ev)] += ev * r.uniform(0.15, 0.6)
    return x

2. Log-mel features in NumPy¶

A microcontroller cannot afford to run a network on raw audio. Like most keyword spotters, we cut the audio into 30 ms frames (480 samples) every 20 ms, take the power spectrum of each frame with a 512-point FFT, sum it into 20 mel bands (spaced like human pitch perception, from 60 Hz to 4 kHz), and take the logarithm. One second becomes a 49 × 20 "image". We build 3,000 clips: 2,000 for training, 500 for validation and 500 for testing.

N_FFT, WIN, HOP, N_MELS = 512, 480, 320, 20
def mel_filterbank(n_mels, n_fft, sr, fmin=60, fmax=4000):
    mel = lambda f: 2595 * np.log10(1 + f / 700); imel = lambda m: 700 * (10 ** (m / 2595) - 1)
    pts, bins = imel(np.linspace(mel(fmin), mel(fmax), n_mels + 2)), np.fft.rfftfreq(n_fft, 1 / sr)
    return np.stack([np.clip(np.minimum((bins - pts[i]) / (pts[i + 1] - pts[i]), (pts[i + 2] - bins) / (pts[i + 2] - pts[i + 1])), 0, None)
                     for i in range(n_mels)])                    # triangular filters
FB, HANN = mel_filterbank(N_MELS, N_FFT, SR), np.hanning(WIN)
def logmel(x):
    n_frames = 1 + (len(x) - WIN) // HOP
    idx = np.arange(WIN)[None] + HOP * np.arange(n_frames)[:, None]
    power = np.abs(np.fft.rfft(x[idx] * HANN, N_FFT)) ** 2
    return np.log(power @ FB.T + 1e-6).astype(np.float32)

rng = np.random.default_rng(0)
labels = rng.integers(0, 5, 3000)
feats = np.stack([logmel(clip(l, rng)) for l in labels])
mu, sd = feats[:2000].mean(), feats[:2000].std()             # normalize with training statistics only
X = torch.tensor((feats - mu) / sd).unsqueeze(1); y = torch.tensor(labels)
Xtr, ytr, Xva, yva, Xte, yte = X[:2000], y[:2000], X[2000:2500], y[2000:2500], X[2500:], y[2500:]
print(f"features per clip: {feats.shape[1]} frames x {feats.shape[2]} mel bands; class counts {np.bincount(labels)}; "
      f"built in {time.time() - t_start:.0f} s")

fig, ax = plt.subplots(1, 5, figsize=(9, 2.4))
for c in range(5):
    ax[c].imshow(feats[np.where(labels == c)[0][0]].T, origin="lower", aspect="auto", cmap="magma")
    ax[c].set_title(CLASSES[c].split(": ")[-1], fontsize=8); ax[c].set_xlabel("frame (20 ms)", fontsize=7)
    ax[c].tick_params(labelsize=6)
ax[0].set_ylabel("mel band", fontsize=7)
plt.suptitle("log-mel features of one synthetic clip per class", fontsize=9); plt.tight_layout(); plt.show()

3. A DS-CNN and its flash and RAM budget¶

We use a depthwise-separable CNN (DS-CNN), the design Zhang et al. (2017) found best for keyword spotting on microcontrollers: one ordinary convolution (10 × 4 kernel, stride 2) that turns the 49 × 20 input into a 25 × 10 map with $C$ channels, then $B$ blocks of depthwise 3 × 3 and pointwise 1 × 1 convolutions, average pooling and a linear layer. After batch normalization is folded in (session 7), an int8 deployment stores:

  • flash: one byte per weight, plus a 4-byte int32 bias and a 4-byte scale for every output channel (the runtime's code and the rest of the app also live in flash);
  • RAM: the activations. Each layer needs its input and output at once, so the peak is $\max(980 + 250C,\ 2 \times 250C)$ bytes: the input is 49 × 20 = 980 bytes and every later map has 25 × 10 × $C$ values.

Our budget for the model is 64 KB of flash and 32 KB of RAM (1 KB = 1,024 bytes), a small share of a microcontroller with, say, 256 KB of RAM and 1 MB of flash. We list every width $C$ and depth $B$ in a grid and keep the ones that fit.

class DSCNN(nn.Module):
    def __init__(self, C, blocks=3, n_cls=5):
        super().__init__()
        self.conv1 = nn.Sequential(nn.Conv2d(1, C, (10, 4), (2, 2), (5, 1), bias=False), nn.BatchNorm2d(C), nn.ReLU())
        layers = []
        for _ in range(blocks):
            layers += [nn.Conv2d(C, C, 3, 1, 1, groups=C, bias=False), nn.BatchNorm2d(C), nn.ReLU(),   # depthwise
                       nn.Conv2d(C, C, 1, bias=False), nn.BatchNorm2d(C), nn.ReLU()]                 # pointwise
        self.body = nn.Sequential(*layers); self.fc = nn.Linear(C, n_cls)
    def forward(self, x):
        return self.fc(self.body(self.conv1(x)).mean((2, 3)))

def budget(C, blocks, n_cls=5):
    weights = 40 * C + blocks * (9 * C + C * C) + C * n_cls        # int8 bytes
    channels = C + 2 * blocks * C + n_cls                          # output channels of all layers
    flash = weights + 4 * channels + 4 * channels                  # + int32 biases + float32 scales
    ram = max(49 * 20 + 250 * C, 2 * 250 * C)                      # peak input + output activations, int8
    macs = 250 * C * 40 + blocks * 250 * (9 * C + C * C) + C * n_cls
    return flash, ram, macs

FLASH_BUDGET, RAM_BUDGET = 64 * 1024, 32 * 1024
grid = pd.DataFrame([(C, b) + budget(C, b) for b in [2, 3, 4] for C in [8, 16, 32, 48, 64, 96, 128]],

4. Train the candidates and choose¶

Training every candidate would take too long here, so we train four widths with $B = 3$ blocks for six epochs each (about 40 seconds in all), choose on the validation set, and keep the test set for the end. MCUNet (Lin et al. 2020) does this at scale: it first shrinks the search space to networks that fit the memory, then searches inside it, together with an inference engine that uses the memory well.

def train(C, blocks, epochs=6):
    torch.manual_seed(0)
    m = DSCNN(C, blocks); opt = torch.optim.Adam(m.parameters(), 3e-3)
    for _ in range(epochs):
        m.train(); perm = torch.randperm(len(Xtr))
        for i in range(0, len(Xtr), 64):
            idx = perm[i:i + 64]
            loss = F.cross_entropy(m(Xtr[idx]), ytr[idx]); opt.zero_grad(); loss.backward(); opt.step()
    return m.eval()

def accuracy(logits, labels):
    return (logits.argmax(1) == labels).float().mean().item()

trained = {}
for C in [8, 16, 32, 64]:
    t0 = time.time(); m = train(C, 3)
    with torch.no_grad():
        trained[C] = (m, accuracy(m(Xva), yva))
    f, r, mac = budget(C, 3)
    print(f"C = {C:2d}: validation accuracy {trained[C][1]:.3f} | flash {f:6,} B | RAM {r:6,} B | {mac:9,} MACs | "
          f"fits: {f <= FLASH_BUDGET and r <= RAM_BUDGET} | trained in {time.time() - t0:.0f} s")
best_C = max((C for C in trained if all(v <= b for v, b in zip(budget(C, 3)[:2], (FLASH_BUDGET, RAM_BUDGET)))), key=lambda C: trained[C][1])
model = trained[best_C][0]
flash, ram, macs = budget(best_C, 3)
with torch.no_grad():
    test_float = accuracy(model(Xte), yte)
print(f"\nchosen: C = {best_C}, B = 3; test accuracy (float32) {test_float:.3f}; flash {flash:,} bytes, RAM {ram:,} bytes, {macs:,} MACs")
print(f"assumption, not a measurement: at about 1 int8 MAC per clock cycle on a 64 MHz microcontroller, one inference takes "
      f"{1e3 * macs / 64e6:.0f} ms; four inferences per second would keep the processor busy {100 * 4 * macs / 64e6:.0f}% of the time")

5. Int8 post-training quantization¶

We fold each batch normalization into its convolution, quantize every weight to int8 with one symmetric scale per output channel, and quantize every activation to 8 bits with one scale per tensor, its range calibrated on 200 training clips (session 3). We simulate the int8 arithmetic in float32 by rounding to the int8 grid after every layer ("fake quantization"); a microcontroller runtime would compute in integers with int32 accumulators, giving the same values up to the final rescaling.

def fold(conv, bn):
    s = bn.weight / torch.sqrt(bn.running_var + bn.eps)
    return (conv.weight * s.view(-1, 1, 1, 1)).detach(), (bn.bias - bn.running_mean * s).detach()
mods = list(model.body)
layers = [(*fold(model.conv1[0], model.conv1[1]), model.conv1[0])] + [(*fold(mods[i], mods[i + 1]), mods[i]) for i in range(0, len(mods), 3)]

def quant_weight(w):                                         # symmetric int8, one scale per output channel
    s = (w.abs().flatten(1).max(1).values.clamp_min(1e-12) / 127).view(-1, *[1] * (w.dim() - 1))
    return torch.round(w / s).clamp(-127, 127) * s
def fake_quant(x, lo, hi):                                   # 8-bit activations with a calibrated range
    s = (hi - lo) / 255; z = round(-lo / s)
    return (torch.clamp(torch.round(x / s) + z, 0, 255) - z) * s
def forward_int8(x, ranges=None, quant=True, collect=None):
    if quant: x = fake_quant(x, *ranges[0])
    if collect is not None: collect[0].append((x.min().item(), x.max().item()))
    for i, (w, b, conv) in enumerate(layers):
        x = F.relu(F.conv2d(x, quant_weight(w) if quant else w, b, conv.stride, conv.padding, 1, conv.groups))
        if quant: x = fake_quant(x, *ranges[i + 1])
        if collect is not None: collect[i + 1].append((x.min().item(), x.max().item()))
    fc_w = model.fc.weight.detach()
    return F.linear(x.mean((2, 3)), quant_weight(fc_w) if quant else fc_w, model.fc.bias.detach())

with torch.no_grad():
    seen = {i: [] for i in range(len(layers) + 1)}
    for i in range(0, 200, 20):
        forward_int8(Xtr[i:i + 20], quant=False, collect=seen)              # calibration: record each tensor's range
    ranges = [(min(a for a, _ in v), max(b for _, b in v)) for v in seen.values()]
    acc_folded = accuracy(forward_int8(Xte, quant=False), yte)
    logits_q = forward_int8(Xte, ranges)
    acc_int8 = accuracy(logits_q, yte); agree = (logits_q.argmax(1) == model(Xte).argmax(1)).float().mean().item()
print(f"test accuracy: float32 {test_float:.3f}, BN folded {acc_folded:.3f}, int8 (simulated) {acc_int8:.3f}; "
      f"int8 and float32 agree on {100 * agree:.1f}% of test clips")
print(f"float32 weights would need {4 * sum(p.numel() for p in model.parameters()):,} bytes; the int8 model needs {flash:,} bytes of flash")

6. False accepts on a long stream, and the threshold¶

On a device the model never sees neat one-second clips. It slides a one-second window along the audio, here every 0.24 s, and reports a keyword when that keyword's probability passes a threshold, then ignores the next second so one keyword is not counted twice. Two numbers describe it:

  • false accepts per hour on audio that contains no keyword: we build 30 minutes of background with "other sounds" every couple of seconds;
  • hit rate on a 5-minute stream with keywords placed at known times.

A higher threshold means fewer false accepts and more missed keywords. We use the int8 model.

def make_stream(minutes, r, with_keywords=False):
    chunks, events = [], []
    for minute in range(minutes):
        x = background(60 * SR, r); t = r.uniform(0.5, 2.0)
        while t < 59:
            if with_keywords and r.random() < 0.35:
                k = r.integers(3); ev = keyword(k, r); events.append((60 * minute + t, k))
            else:
                ev = other_sound(r)
            s0 = int(t * SR); x[s0:s0 + len(ev)] += ev[:len(x) - s0] * r.uniform(0.15, 0.6)
            t += len(ev) / SR + r.exponential(1.5) + 0.3
        chunks.append(x)
    return np.concatenate(chunks), events

def window_probs(x, hop_frames=12):
    f = (logmel(x) - mu) / sd
    starts = np.arange(0, len(f) - 49, hop_frames)
    W = torch.tensor(np.stack([f[s:s + 49] for s in starts])).unsqueeze(1)
    with torch.no_grad():
        p = torch.cat([F.softmax(forward_int8(W[i:i + 512], ranges), 1) for i in range(0, len(W), 512)])
    return starts * HOP / SR, p.numpy()

def detect(times, p, threshold, refractory=1.0):
    found, last = [], -10.0
    for t, row in zip(times, p):
        k = row[:3].argmax()
        if row[k] >= threshold and t - last >= refractory:
            found.append((t, k)); last = t
    return found

bg_audio, _ = make_stream(30, np.random.default_rng(1))
kw_audio, kw_events = make_stream(5, np.random.default_rng(2), with_keywords=True)
t_bg, p_bg = window_probs(bg_audio); t_kw, p_kw = window_probs(kw_audio)
print(f"background stream: 30 minutes, {len(t_bg):,} windows; keyword stream: 5 minutes, {len(t_kw):,} windows, {len(kw_events)} keywords")
rows = []
for thr in [0.5, 0.6, 0.7, 0.8, 0.9, 0.95, 0.98, 0.99]:
    fa = len(detect(t_bg, p_bg, thr))
    found, used, hits = detect(t_kw, p_kw, thr), set(), 0
    for (te, k) in kw_events:                                   # a hit: right keyword, from a window that contains it
        j = next((j for j, (td, kd) in enumerate(found) if j not in used and kd == k and te - 1.0 <= td <= te + 0.1), None)
        if j is not None:
            used.add(j); hits += 1
    rows.append(dict(threshold=thr, false_accepts=fa, false_accepts_per_hour=fa / 0.5, hit_rate=hits / len(kw_events)))
det = pd.DataFrame(rows)
print(det.to_string(index=False))

plt.figure(figsize=(6.5, 3.2))

What to notice¶

(Written from the saved run. All numbers except the training times will match yours.)

  1. RAM, not flash, ruled out the larger models. Every candidate up to width 64 fits in 32 KB of RAM, but width 96 needs 48,000 bytes of activations. Flash stays under 64 KB except for width 128 with 3 or 4 blocks (65,576 and 85,160 bytes). The 25 × 10 maps after the first convolution make activations, not weights, the limit, as in session 8.
  2. Bigger was not better. Validation accuracy was 0.672 for width 8, 0.966 for 16, 0.986 for 32 and 0.972 for 64. The search chose width 32 with 3 blocks: test accuracy 0.988 with 7,208 bytes of flash, 16,000 bytes of RAM and 1,304,160 MACs. The width-64 model needs three times the MACs for a lower validation score. Each candidate was trained once, with one seed and six epochs, so small differences such as 0.986 against 0.972 may not be real; a careful search would repeat the runs (Course 1 session 9).
  3. Int8 cost nothing here. Test accuracy was 0.988 in float32, after folding batch normalization, and with simulated int8, and the int8 model agreed with float32 on 100.0% of the test clips. The weights went from 23,316 bytes in float32 to 7,208 bytes of flash. On real speech, int8 usually costs a little accuracy, so check it.
  4. A good clip classifier can still be a poor detector. The model classifies 98.8% of clips correctly, yet on 30 minutes of audio with no keyword (7,496 windows) a threshold of 0.5 gave 37 false accepts, 74 per hour. A threshold of 0.9 gave 6 per hour while detecting 79.6% of the keywords; 0.98 gave no false accept in 30 minutes but detected only 50.0%. No threshold here gives both few false accepts and few misses. The usual fixes are more near-miss sounds in the training data, smoothing the probabilities over time (exercise 1), or a second check by a larger model. Note also that zero false accepts in 30 minutes does not prove a rate below 2 per hour: measuring rates near one per hour needs many hours of audio.
  5. The microcontroller timing is an assumption. At about one int8 MAC per clock cycle at 64 MHz, the chosen model would take 20 ms per inference and keep the processor busy 8% of the time at four inferences per second. Measure on the real board: depthwise layers, which do little arithmetic for each byte they move, may run below that rate.
