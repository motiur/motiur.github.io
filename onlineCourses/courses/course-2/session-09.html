1. By hand first: Newton's method in one dimension¶

Newton's method minimizes the local quadratic model $f(x + d) \approx f(x) + f'(x)d + \frac12 f''(x)d^2$, which gives the step $d = -f'(x)/f''(x)$.

Take $f(x) = e^x - 2x$, so $f'(x) = e^x - 2$ and $f''(x) = e^x$; the minimizer is $x^* = \ln 2 \approx 0.6931$. Starting from $x_0 = 0$, compute $x_1$ on paper, then $x_2$ with a calculator. Then run the cell and watch the error: near the minimizer it is roughly squared at every step, so the number of correct digits roughly doubles.

import math, time
import numpy as np
import matplotlib.pyplot as plt
from scipy import optimize
from scipy.special import expit

t_start = time.time()
np.random.seed(0)

x = 0.0
print(f"step 0: x = {x:.10f}, error {abs(x - math.log(2)):.2e}")
for k in range(1, 6):
    x = x - (math.exp(x) - 2) / math.exp(x)                      # x - f'(x) / f''(x)
    print(f"step {k}: x = {x:.10f}, error {abs(x - math.log(2)):.2e}")

2. Stochastic gradients: unbiased, with variance that falls as $1/B$¶

The training loss is an average, $f(w) = \frac1n\sum_i f_i(w)$. A minibatch of $B$ examples drawn at random gives the gradient estimate $g_B = \frac1B\sum_{i \in \text{batch}} \nabla f_i(w)$. Its average over all possible batches is the full gradient (it is unbiased), and when the batch is drawn with replacement its variance is the single-example variance divided by $B$.

Data for the next sections: a generated binary classification problem with $n = 20{,}000$ examples and 20 standardized features (make_classification), and L2-regularized logistic regression with $\lambda = 10^{-4}$ (the intercept is not penalized). We check both claims at $w = 0$ with 2,000 random batches per batch size.

from sklearn.datasets import make_classification

Xc, yc = make_classification(n_samples=20000, n_features=20, n_informative=10, random_state=0)
Xc = (Xc - Xc.mean(axis=0)) / Xc.std(axis=0)
A = np.hstack([Xc, np.ones((len(Xc), 1))]); ypm = 2 * yc - 1        # last column: intercept; labels -1 and +1
n, p = A.shape; lam = 1e-4
reg = np.ones(p); reg[-1] = 0.0                                     # do not penalize the intercept

def loss(w, idx=None):
    Ai, yi = (A, ypm) if idx is None else (A[idx], ypm[idx])
    return np.mean(np.logaddexp(0, -yi * (Ai @ w))) + 0.5 * lam * np.sum(reg * w * w)
def grad(w, idx=None):
    Ai, yi = (A, ypm) if idx is None else (A[idx], ypm[idx])
    return -(Ai.T @ (yi * expit(-yi * (Ai @ w)))) / len(yi) + lam * reg * w
def hess(w):
    s = expit(A @ w) * expit(-A @ w)
    return (A.T * s) @ A / n + lam * np.diag(reg)

rng = np.random.default_rng(0)
w0, g_full = np.zeros(p), grad(np.zeros(p))
for B in [1, 10, 100]:
    gs = np.array([grad(w0, rng.integers(0, n, B)) for _ in range(2000)])   # batches drawn with replacement
    total_var = gs.var(axis=0).sum()
    print(f"B = {B:3d}: |mean of 2,000 batch gradients - full gradient| = {np.linalg.norm(gs.mean(axis=0) - g_full):.4f} "
          f"(sampling error expected: about {np.sqrt(total_var / 2000):.4f}); total variance {total_var:.4f}; variance x B = {total_var * B:.3f}")
print(f"full gradient norm at w = 0: {np.linalg.norm(g_full):.4f}")

3. Full-batch gradient descent against SGD, per pass over the data¶

One pass over the data costs the same for every method: GD takes one step per pass, SGD with batch size $B$ takes $n/B$ steps. We first find the minimum $f^*$ with Newton's method (section 4 explains it), then plot $f(w) - f^*$ against passes for:

  • GD with $\eta = 1/L$, where $L = \lambda_{\max}(A^\top A/n)/4 + \lambda$ bounds the Hessian;
  • SGD with $B = 10$ and a constant step $\eta = 0.05$;
  • SGD with $B = 100$ and the same constant step (ten times fewer steps per pass, each less noisy);
  • SGD with $B = 10$ and a decaying step $\eta_t = 0.1/(1 + t/500)$, where $t$ counts steps.

With a constant step SGD does not converge: it hovers in a noise ball around the minimum. A decaying step shrinks the ball (Bottou et al. 2018).

w = np.zeros(p)
for k in range(20):                                                 # Newton's method, only to get the reference minimum
    g = grad(w)
    if np.linalg.norm(g) < 1e-13: break
    w = w - np.linalg.solve(hess(w), g)
w_star, f_star = w, loss(w)
L = np.linalg.eigvalsh(A.T @ A / n)[-1] / 4 + lam
print(f"minimum loss f* = {f_star:.10f}; GD step 1/L = {1 / L:.3f}")

passes = 30
def run_gd():
    w, gaps = np.zeros(p), []
    for k in range(passes + 1):
        gaps.append(loss(w) - f_star); w = w - grad(w) / L
    return np.arange(passes + 1), np.array(gaps)

def run_sgd(B, eta0, decay=None, seed=0):
    rng = np.random.default_rng(seed); w, t = np.zeros(p), 0
    xs, gaps, steps = [0.0], [loss(w) - f_star], n // B
    for ep in range(passes):
        order = rng.permutation(n)                                  # shuffle once per pass, then take batches in order
        for k in range(steps):
            eta = eta0 if decay is None else eta0 / (1 + t / decay)
            w = w - eta * grad(w, order[k * B:(k + 1) * B]); t += 1
            if (k + 1) % (steps // 10) == 0:
                xs.append(ep + (k + 1) / steps); gaps.append(loss(w) - f_star)
    return np.array(xs), np.array(gaps)

t0 = time.time()
curves = {"GD, eta = 1/L": run_gd(), "SGD, B = 10, eta = 0.05": run_sgd(10, 0.05), "SGD, B = 100, eta = 0.05": run_sgd(100, 0.05),
          "SGD, B = 10, eta = 0.1/(1 + t/500)": run_sgd(10, 0.1, decay=500)}
print(f"all runs took {time.time() - t0:.1f} s")
print("f - f* after 1, 5, 10 and 30 passes (for SGD, the average over the 10 checks in that pass, since single values jump around)")
for name, (xs, gaps) in curves.items():
    if name.startswith("GD"):
        at = [gaps[q] for q in [1, 5, 10, 30]]
    else:
        at = [gaps[(xs > q - 1 + 1e-9) & (xs <= q + 1e-9)].mean() for q in [1, 5, 10, 30]]
    print(f"{name:36s} | " + "  ".join(f"{v:.2e}" for v in at))

plt.figure(figsize=(7, 3.4))
for name, (xs, gaps) in curves.items():
    plt.semilogy(xs, np.maximum(gaps, 1e-16), "o-" if name.startswith("GD") else "-", ms=3, label=name)
plt.xlabel("passes over the data"); plt.ylabel("f(w) - f*"); plt.title("logistic regression, n = 20,000: GD against SGD", fontsize=10)
plt.legend(fontsize=7); plt.tight_layout(); plt.show()

4. Newton's method on logistic regression¶

Newton's step solves $H d = -\nabla f$, where $H$ is the Hessian, here $A^\top S A / n + \lambda I$ with $S$ the diagonal matrix of $\sigma(z_i)(1-\sigma(z_i))$. Each iteration costs about $nd^2$ operations to form $H$ and $d^3$ to solve with it, and needs $d^2$ numbers of memory. That is cheap for $d = 21$ and impossible for a network with $d = 10^6$ weights.

We check the result against scikit-learn's LogisticRegression. Its objective is $C\sum_i \ell_i + \frac12\|w\|^2$; ours is $\frac1n\sum_i \ell_i + \frac{\lambda}{2}\|w\|^2$, the same problem when $C = 1/(n\lambda)$.

from sklearn.linear_model import LogisticRegression

w, newton_hist = np.zeros(p), []
t0 = time.perf_counter()
for k in range(20):
    g = grad(w); newton_hist.append(loss(w) - f_star)
    print(f"Newton iteration {k}: f - f* = {loss(w) - f_star:.2e}, gradient norm {np.linalg.norm(g):.2e}")
    if np.linalg.norm(g) < 1e-12: break
    w = w - np.linalg.solve(hess(w), g)
t_newton = (time.perf_counter() - t0) / k
skl = LogisticRegression(C=1 / (n * lam), tol=1e-12, max_iter=10000).fit(Xc, yc)
print(f"time per Newton iteration {1000 * t_newton:.1f} ms (d = {p})")
print(f"largest difference from scikit-learn's weights: {np.abs(np.append(skl.coef_.ravel(), skl.intercept_) - w).max():.1e}")
print(f"memory for one Hessian with d = 1,000,000 weights in float32: {1e6**2 * 4 / 1e12:.0f} TB")

5. Quasi-Newton in practice: L-BFGS¶

BFGS builds an approximation to the inverse Hessian from the changes in the gradient between steps; L-BFGS keeps only the last few pairs of changes (10 by default in SciPy), so it needs $O(md)$ memory instead of $O(d^2)$ (Nocedal & Wright 2006). It is SciPy's L-BFGS-B and scikit-learn's default solver for logistic regression. We give it only the loss and the gradient.

lbfgs_hist = []
t0 = time.perf_counter()
res = optimize.minimize(lambda w: (loss(w), grad(w)), np.zeros(p), jac=True, method="L-BFGS-B",
                        callback=lambda wk: lbfgs_hist.append(loss(wk) - f_star), options={"gtol": 1e-10, "ftol": 1e-16})
t_lbfgs = time.perf_counter() - t0
gd_x, gd_gaps = curves["GD, eta = 1/L"]
w, t0, k_gd = np.zeros(p), time.perf_counter(), 0
while loss(w) - f_star > 1e-10 and k_gd < 5000:
    w = w - grad(w) / L; k_gd += 1
t_gd = time.perf_counter() - t0
print(f"L-BFGS: {res.nit} iterations, {res.nfev} loss-and-gradient evaluations, final f - f* = {res.fun - f_star:.1e}, {1000 * t_lbfgs:.0f} ms")
print(f"Newton: {len(newton_hist) - 1} iterations (each with a 21 x 21 Hessian), about {1000 * t_newton * (len(newton_hist) - 1):.0f} ms")
print(f"GD: {k_gd} iterations to reach f - f* < 1e-10, {1000 * t_gd:.0f} ms")

plt.figure(figsize=(6.5, 3.2))
plt.semilogy(np.maximum(newton_hist, 1e-16), "o-", label="Newton")                     # 1e-16: the float64 floor for a loss near 0.55
plt.semilogy(np.arange(1, len(lbfgs_hist) + 1), np.maximum(lbfgs_hist, 1e-16), "s-", ms=3, label="L-BFGS")
plt.semilogy(gd_x, np.maximum(gd_gaps, 1e-16), "-", label="gradient descent")
plt.xlim(-1, 30); plt.xlabel("iteration"); plt.ylabel("f(w) - f*"); plt.title("convergence per iteration (iterations differ in cost)", fontsize=10)
plt.legend(fontsize=8); plt.tight_layout(); plt.show()

6. Newton's method can go the wrong way¶

Newton's method looks for a point where the gradient is zero. It does not know whether that point is a minimum, a maximum or a saddle. Take $f(x) = x^4 - 2x^2$ (session 8): minima at $x = \pm 1$, a local maximum at $x = 0$, and $f''(x) < 0$ for $|x| < 1/\sqrt3$. Start both methods at $x_0 = 0.1$.

f1 = lambda x: x**4 - 2 * x**2
d1 = lambda x: 4 * x**3 - 4 * x
d2 = lambda x: 12 * x**2 - 4
xn, xg = [0.1], [0.1]
for k in range(8):
    xn.append(xn[-1] - d1(xn[-1]) / d2(xn[-1]))                     # Newton
for k in range(60):
    xg.append(xg[-1] - 0.05 * d1(xg[-1]))                            # gradient descent, eta = 0.05
print("Newton:", ", ".join(f"{v:.6f}" for v in xn[:6]), f"... ends at x = {xn[-1]:.6f}, f = {f1(xn[-1]):.4f} (a maximum)")
print(f"gradient descent: ends at x = {xg[-1]:.6f}, f = {f1(xg[-1]):.4f} (a minimum)")

xx = np.linspace(-1.5, 1.5, 300)
plt.figure(figsize=(6.5, 3.2))
plt.plot(xx, f1(xx), color="0.5", label="f(x) = x^4 - 2x^2")
plt.plot(xn, [f1(v) for v in xn], "o-", color="C3", ms=4, label="Newton from 0.1")
plt.plot(xg, [f1(v) for v in xg], "s-", color="C0", ms=3, lw=0.8, label="gradient descent from 0.1")
plt.xlabel("x"); plt.ylabel("f(x)"); plt.title("Newton finds a stationary point, here the maximum", fontsize=10)
plt.legend(fontsize=8); plt.tight_layout(); plt.show()

7. Lagrange multipliers, and maximum entropy gives the softmax¶

To minimize $f(x)$ subject to $g(x) = c$: at the solution the gradient of $f$ is parallel to the gradient of the constraint, $\nabla f = \lambda \nabla g$, where $\lambda$ is the Lagrange multiplier. It also measures how fast the best value changes when $c$ changes.

By hand first: minimize $x^2 + y^2$ subject to $x + 2y = 5$. The condition gives $(2x, 2y) = \lambda(1, 2)$, so $x = \lambda/2$ and $y = \lambda$; then $\lambda/2 + 2\lambda = 5$ gives $\lambda = 2$, the point $(1, 2)$ and the value 5. SciPy's SLSQP solver reports the same multiplier.

Maximum entropy. A die has faces 1 to 6 and an average roll of 4.5. Which distribution $p$ assumes the least beyond that? Maximize the entropy $H(p) = -\sum_i p_i \ln p_i$ subject to $\sum_i p_i = 1$ and $\sum_i i\,p_i = 4.5$. Setting the derivative of $H + \alpha(\sum_i p_i - 1) + \beta(\sum_i i\,p_i - 4.5)$ to zero gives $-\ln p_i - 1 + \alpha + \beta i = 0$, so $p_i \propto e^{\beta i}$: a softmax of the scores $\beta i$. The multiplier $\beta$ plays the role of an inverse temperature and is fixed by the constraint. We solve the problem twice: directly with SLSQP, and through the softmax form with a 1-D root search for $\beta$.

res2 = optimize.minimize(lambda v: v[0]**2 + v[1]**2, [0.0, 0.0], method="SLSQP",
                         constraints=[{"type": "eq", "fun": lambda v: v[0] + 2 * v[1] - 5}], options={"ftol": 1e-12})
print(f"x^2 + y^2 subject to x + 2y = 5: point ({res2.x[0]:.4f}, {res2.x[1]:.4f}), value {res2.fun:.4f}, multiplier {res2.multipliers[0]:.4f}")

faces = np.arange(1, 7)
softmax = lambda s: np.exp(s - s.max()) / np.exp(s - s.max()).sum()
def maxent(mean):
    direct = optimize.minimize(lambda q: np.sum(q * np.log(q)), np.full(6, 1 / 6), method="SLSQP", bounds=[(1e-10, 1)] * 6,
                               constraints=[{"type": "eq", "fun": lambda q: q.sum() - 1},
                                            {"type": "eq", "fun": lambda q: q @ faces - mean}], options={"ftol": 1e-14, "maxiter": 500})
    beta = optimize.brentq(lambda b: softmax(b * faces) @ faces - mean, -10, 10)
    beta = 0.0 if abs(beta) < 1e-12 else beta                         # print 0, not -0
    return direct.x, beta, softmax(beta * faces)

sols = {}
for mean in [2.5, 3.5, 4.5]:
    q_direct, beta, q_soft = sols[mean] = maxent(mean)
    slope = np.polyfit(faces, np.log(q_direct), 1)[0] + 0.0
    slope = 0.0 if abs(slope) < 1e-9 else slope
    print(f"mean {mean}: beta = {beta:+.4f}; softmax form " + " ".join(f"{v:.4f}" for v in q_soft)
          + f"; largest difference from SLSQP {np.abs(q_direct - q_soft).max():.1e}; slope of log p against the face {slope:+.4f}")

fig, ax = plt.subplots(1, 2, figsize=(9, 3.2))
for k, (mean, (q_direct, beta, q_soft)) in enumerate(sols.items()):
    ax[0].bar(faces + (k - 1) * 0.27, q_direct, width=0.27, label=f"mean {mean} (beta = {beta:+.3f})")
    ax[1].plot(faces, np.log(q_direct), "o-", label=f"mean {mean}")
ax[0].set_xlabel("face"); ax[0].set_ylabel("probability"); ax[0].set_title("maximum-entropy die", fontsize=10); ax[0].legend(fontsize=7)
ax[1].set_xlabel("face"); ax[1].set_ylabel("log probability"); ax[1].set_title("log p is a straight line: p is a softmax", fontsize=10); ax[1].legend(fontsize=7)
plt.tight_layout(); plt.show()

8. One look at the SVM dual¶

The hard-margin support vector machine (SVM) minimizes $\frac12\|w\|^2$ subject to $y_i(w^\top x_i + b) \ge 1$. With one multiplier $\alpha_i \ge 0$ per constraint, stationarity gives $w = \sum_i \alpha_i y_i x_i$ and $\sum_i \alpha_i y_i = 0$, and $\alpha_i > 0$ only where the constraint is tight, $y_i(w^\top x_i + b) = 1$: the support vectors (Bishop 2006, chapter 7). The dual problem uses the data only through dot products $x_i^\top x_j$, which is what lets kernels in. scikit-learn's SVC solves the dual and stores $\alpha_i y_i$ in dual_coef_; a very large C makes it a hard margin.

from sklearn.datasets import make_blobs
from sklearn.svm import SVC

Xs, ys = make_blobs(n_samples=40, centers=2, cluster_std=1.0, random_state=6); ys = 2 * ys - 1
svc = SVC(kernel="linear", C=1e6).fit(Xs, ys)
ay = svc.dual_coef_.ravel()                                         # alpha_i * y_i for the support vectors
print(f"{len(svc.support_)} support vectors out of {len(Xs)} points; alpha = {np.round(np.abs(ay), 4)}")
print(f"w from the dual sum(alpha_i y_i x_i) = {np.round(ay @ svc.support_vectors_, 6)}; scikit-learn's w = {np.round(svc.coef_.ravel(), 6)}")
print(f"sum(alpha_i y_i) = {ay.sum():.1e}; y_i (w.x_i + b) for the support vectors: {np.round(ys[svc.support_] * svc.decision_function(svc.support_vectors_), 4)}")
print(f"smallest y_i (w.x_i + b) over all points: {(ys * svc.decision_function(Xs)).min():.4f}")
print(f"runtime so far {time.time() - t_start:.0f} s")

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds, except the timings.)

  1. Newton's error was roughly squared at every step. From $x_0 = 0$: $x_1 = 1$, $x_2 = 0.7357588823$, and the errors were 6.93e-01, 3.07e-01, 4.26e-02, 8.95e-04, 4.00e-07 and 8.02e-14.
  2. Minibatch gradients were unbiased, with variance proportional to $1/B$. The variance times $B$ stayed at 5.109, 5.220 and 5.236 for $B$ = 1, 10 and 100, and the mean of 2,000 batch gradients differed from the full gradient by about the sampling error (for $B = 10$, 0.0157 against 0.0162 expected).
  3. SGD wins early; noise decides later. After one pass, SGD with $B = 10$ was about ten times closer to the minimum than GD (4.75e-03 with a constant step, 3.13e-03 with a decaying step, against 4.51e-02). With a constant step it then stalled at about 5e-03 ($B = 10$) or 2e-04 ($B = 100$, less noise per step). With the decaying step it kept improving, to 8.98e-06 after 30 passes, level with GD (9.18e-06). GD converges linearly and reached 1e-10 after 83 passes (section 5). Against expectation, the decaying SGD was still level with GD after 30 passes; with other step sizes or data this crossover moves.
  4. Newton converged in 5 iterations ($f - f^*$: 1.38e-01, 6.42e-03, 1.00e-04, 3.55e-08, 4.66e-15, 0) and matched scikit-learn's weights to 1.2e-08. L-BFGS needed 17 iterations and 19 gradient evaluations, with no Hessian; GD needed 83 iterations to reach 1e-10. With only 21 weights each method took tens of milliseconds in the saved run (timings vary from run to run). A Hessian for $10^6$ weights would need 4 TB in float32.
  5. Newton converged to a maximum. On $x^4 - 2x^2$ from $x_0 = 0.1$, where $f'' < 0$, Newton jumped to −0.002062 and settled at $x = 0$, the local maximum ($f = 0$). Gradient descent from the same start reached the minimum $x = 1$ ($f = -1$).
  6. Lagrange multipliers. SLSQP found the point (1, 2), value 5 and multiplier 2.0000, as computed by hand. The maximum-entropy die with mean 4.5 came out as 0.0544, 0.0788, 0.1142, 0.1654, 0.2398, 0.3475: a softmax with $\beta = 0.3710$. SLSQP, which knows nothing about softmax, agreed to 6.7e-09, and its log-probabilities lay on a line of slope 0.3710. Mean 3.5 gave $\beta = 0$ (the fair die) and mean 2.5 the mirror image ($\beta = -0.3710$).
  7. The SVM's multipliers pick out the support vectors. Only 3 of the 40 points had $\alpha_i > 0$. The $w$ rebuilt as $\sum_i \alpha_i y_i x_i$ matched scikit-learn's to six decimals, $\sum_i \alpha_i y_i$ was −2.8e-17, and the support vectors sat on the margin (0.9997, 1.0003 and 0.9995).
