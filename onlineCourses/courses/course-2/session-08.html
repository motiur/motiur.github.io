1. By hand first: one dimension¶

Gradient descent (GD) repeats $x \leftarrow x - \eta\, f'(x)$ with step size (learning rate) $\eta$. Take $f(x) = 2x^2$, so $f'(x) = 4x$ and each step multiplies $x$ by $(1 - 4\eta)$.

Starting from $x_0 = 1$, work out $x_1$ and $x_2$ on paper for $\eta = 0.25$, $0.4$ and $0.6$. Which step sizes converge? What is the largest step size that still converges? Then run the cell.

import math, time
import numpy as np
import matplotlib.pyplot as plt
from scipy import optimize
from scipy.special import expit

t_start = time.time()
np.random.seed(0)

for eta in [0.25, 0.4, 0.5, 0.6]:
    x, xs = 1.0, []
    for t in range(5):
        x = x - eta * 4 * x                     # f'(x) = 4x
        xs.append(x)
    print(f"eta = {eta:4.2f}: factor 1 - 4*eta = {1 - 4 * eta:+.1f}; x1..x5 = " + ", ".join(f"{v:.4g}" for v in xs))
print("limit: |1 - 4*eta| < 1, that is 0 < eta < 2/4 = 0.5 (here the curvature f''(x) = 4 plays the role of lambda_max)")

2. Gradient descent on 2-D quadratics: conditioning¶

Take $f(x) = \frac12(\lambda_1 x_1^2 + \lambda_2 x_2^2)$ with $\lambda_1 = 1$ and $\lambda_2 = \kappa$. The Hessian is $\text{diag}(1, \kappa)$, so the condition number $\kappa = \lambda_{\max}/\lambda_{\min}$. Each GD step multiplies coordinate $i$ by $(1 - \eta\lambda_i)$, so GD converges only if $\eta < 2/\lambda_{\max}$.

The best fixed step is $\eta = 2/(\lambda_{\min} + \lambda_{\max})$. Then both coordinates shrink by the same factor, $(\kappa - 1)/(\kappa + 1)$, per step, and the number of steps to shrink the error by $10^6$ is $\ln(10^{-6})/\ln\frac{\kappa - 1}{\kappa + 1}$. We start every run at $x_0 = (-10, 1)$.

def gd_quadratic(lams, eta, x0, steps):
    xs = [np.array(x0, dtype=float)]
    for t in range(steps):
        xs.append(xs[-1] - eta * lams * xs[-1])           # the gradient of 0.5 * sum(lams * x^2) is lams * x
    return np.array(xs)

x0 = np.array([-10.0, 1.0])
paths = {}
print("kappa | best eta | factor per step | steps to shrink the error by 1e6: GD (theory)")
for kappa in [1, 10, 100]:
    lams = np.array([1.0, kappa])
    eta = 2 / (lams.min() + lams.max())
    xs = gd_quadratic(lams, eta, x0, 2000)
    err = np.linalg.norm(xs, axis=1) / np.linalg.norm(x0)
    rate = (kappa - 1) / (kappa + 1)
    theory = 1 if rate == 0 else math.ceil(math.log(1e-6) / math.log(rate))
    print(f"{kappa:5d} | {eta:8.4f} | {rate:15.4f} | {int(np.argmax(err <= 1e-6)):5d} ({theory})")
    paths[kappa] = (lams, xs)

fig, ax = plt.subplots(1, 3, figsize=(9, 3.2))
g1, g2 = np.meshgrid(np.linspace(-11, 2, 200), np.linspace(-1.6, 1.6, 200))
for a, (kappa, (lams, xs)) in zip(ax, paths.items()):
    a.contour(g1, g2, 0.5 * (lams[0] * g1**2 + lams[1] * g2**2), levels=np.geomspace(0.05, 60, 12), colors="0.7", linewidths=0.6)
    a.plot(xs[:61, 0], xs[:61, 1], "o-", ms=2, lw=0.8, color="C3")
    a.set_title(f"kappa = {kappa}: first 60 steps", fontsize=10); a.set_xlabel("x1")
ax[0].set_ylabel("x2 (axes not to scale)")
plt.tight_layout(); plt.show()

3. Step sizes around the limit $2/\lambda_{\max}$¶

For $\kappa = 10$ the limit is $2/10 = 0.2$. We compare four step sizes over 100 steps: $1/\lambda_{\max} = 0.1$, the best step $2/11 \approx 0.182$, and $0.99$ and $1.01$ times the limit. Watch the steep coordinate: its factor $1 - 10\eta$ is $-0.98$ just below the limit and $-1.02$ just above it.

lams = np.array([1.0, 10.0])
f = lambda xs: 0.5 * (lams[0] * xs[:, 0] ** 2 + lams[1] * xs[:, 1] ** 2)
runs = {}
print(f"f(x0) = {f(x0[None])[0]:.1f}")
for label, eta in [("0.1 = 1/lambda_max", 0.1), ("0.182 = 2/(1 + 10), best", 2 / 11), ("0.198 = 0.99 x limit", 0.198), ("0.202 = 1.01 x limit", 0.202)]:
    runs[label] = fx = f(gd_quadratic(lams, eta, x0, 100))
    print(f"eta {label:26s}: factors {1 - eta * lams[0]:+.3f} and {1 - eta * lams[1]:+.3f}; f after 100 steps {fx[-1]:.3g}")

plt.figure(figsize=(6.5, 3.2))

4. Convex or not? Check along a line¶

A function is convex if every chord lies on or above the graph: $f(\theta a + (1-\theta) b) \le \theta f(a) + (1-\theta) f(b)$ for all points $a, b$ and $0 \le \theta \le 1$. For a convex function every local minimum is global. A convex function is convex along every straight line, so one line where the inequality fails proves non-convexity.

  • Logistic regression on two moons: the loss is convex in the weights (its Hessian $X^\top S X / n$, with $S$ diagonal and nonnegative, is positive semidefinite). We check the Hessian at random points and the chord along a line between two random weight vectors.
  • A small neural network (one hidden layer of 8 tanh units, trained by scikit-learn): if we reverse the order of the hidden units, the network computes the same function, so the loss is the same. If the loss were convex, the midpoint between the two weight vectors would have a loss no larger than that. We measure it.
from sklearn.datasets import make_moons
from sklearn.neural_network import MLPClassifier

Xm, ym = make_moons(n_samples=200, noise=0.2, random_state=0)
Am = np.hstack([Xm, np.ones((len(Xm), 1))])                       # inputs plus a column of ones (intercept)
lr_loss = lambda w: np.mean(np.logaddexp(0, -(2 * ym - 1) * (Am @ w)))   # logistic loss, labels -1 and +1

rng = np.random.default_rng(0)
min_eig = min(np.linalg.eigvalsh((Am.T * (expit(Am @ w) * expit(-Am @ w))) @ Am / len(Am)).min()
              for w in rng.normal(0, 3, size=(5, 3)))
print(f"logistic loss: smallest Hessian eigenvalue at 5 random points {min_eig:.4f} (never negative)")
wa, wb = rng.normal(0, 3, 3), rng.normal(0, 3, 3)
ts = np.linspace(0, 1, 41)
lr_line = np.array([lr_loss((1 - t) * wa + t * wb) for t in ts])
print(f"logistic loss along a line: ends {lr_line[0]:.3f} and {lr_line[-1]:.3f}, midpoint {lr_line[20]:.3f} "
      f"(chord value {(lr_line[0] + lr_line[-1]) / 2:.3f})")

mlp = MLPClassifier(hidden_layer_sizes=(8,), activation="tanh", solver="lbfgs", max_iter=2000, random_state=0).fit(Xm, ym)
W1, W2 = mlp.coefs_; b1, b2 = mlp.intercepts_
def nn_loss(W1, b1, W2, b2):                                        # mean cross-entropy of the network
    p = np.clip(expit(np.tanh(Xm @ W1 + b1) @ W2 + b2).ravel(), 1e-12, 1 - 1e-12)
    return -np.mean(ym * np.log(p) + (1 - ym) * np.log(1 - p))
perm = np.arange(8)[::-1]                                           # reverse the order of the hidden units
P = (W1[:, perm], b1[perm], W2[perm], b2)
nn_line = np.array([nn_loss((1 - t) * W1 + t * P[0], (1 - t) * b1 + t * P[1], (1 - t) * W2 + t * P[2], b2) for t in ts])
print(f"network: training accuracy {mlp.score(Xm, ym):.3f}; loss {nn_loss(W1, b1, W2, b2):.4f} and with the units reversed "
      f"{nn_loss(*P):.4f}; at the midpoint {nn_line[20]:.3f}; largest on the line {nn_line.max():.3f}")

fig, ax = plt.subplots(1, 2, figsize=(9, 3.2))
for a, line, title in [(ax[0], lr_line, "logistic regression: convex"), (ax[1], nn_line, "neural network: not convex")]:
    a.plot(ts, line, label="loss along the line"); a.plot([0, 1], [line[0], line[-1]], "k--", lw=1, label="chord")
    a.set_xlabel("t  (weights = (1 - t) a + t b)"); a.set_ylabel("training loss"); a.set_title(title, fontsize=10); a.legend(fontsize=8)
plt.tight_layout(); plt.show()

5. Feature scaling changes the conditioning¶

Breast cancer data (569 patients, 30 features): mean area is in the hundreds, smoothness around 0.1. We fit L2-regularized logistic regression with GD, once on the raw features and once on standardized features (each feature shifted to mean 0 and scaled to standard deviation 1).

To compare fairly, both runs minimize the same function: the penalty $\frac{\lambda}{2}\sum_j (s_j w_j)^2$ is written on the standardized weights ($s_j$ is the standard deviation of feature $j$, $\lambda = 0.01$), so the raw run is the same problem in different units. The step is $\eta = 1/L$, where $L$ bounds the largest Hessian eigenvalue: $L = \lambda_{\max}(A^\top A/n)/4 + \lambda \max_j s_j^2$, since $\sigma(z)(1-\sigma(z)) \le 1/4$. We count iterations until the loss is within $10^{-6}$ of the minimum, with at most 20,000 iterations.

from sklearn.datasets import load_breast_cancer

Xb, yb = load_breast_cancer(return_X_y=True); yb = 2 * yb - 1           # labels -1 and +1
mu, sd = Xb.mean(axis=0), Xb.std(axis=0); lam = 0.01
print(f"feature ranges: mean area {Xb[:, 3].min():.0f} to {Xb[:, 3].max():.0f}; mean smoothness {Xb[:, 4].min():.3f} to {Xb[:, 4].max():.3f}")

def make_problem(Z, pen):
    A = np.hstack([Z, np.ones((len(Z), 1))])                            # last weight is the intercept (not penalized)
    def f_grad(w):
        z = yb * (A @ w)
        f = np.mean(np.logaddexp(0, -z)) + 0.5 * lam * np.sum(pen * w[:-1] ** 2)
        g = -(A.T @ (yb * expit(-z))) / len(A); g[:-1] += lam * pen * w[:-1]
        return f, g
    ev = np.linalg.eigvalsh(A.T @ A / len(A))
    return dict(A=A, f_grad=f_grad, pen=pen, L=ev[-1] / 4 + lam * pen.max(), cond_data=ev[-1] / ev[0])

probs = {"raw": make_problem(Xb, sd**2), "standardized": make_problem((Xb - mu) / sd, np.ones(Xb.shape[1]))}

# the minimum, found on the well-conditioned problem, then mapped back to raw units
res = optimize.minimize(probs["standardized"]["f_grad"], np.zeros(31), jac=True, method="L-BFGS-B",
                        options={"gtol": 1e-12, "ftol": 1e-15, "maxiter": 10000})
w_std = res.x
w_raw = np.append(w_std[:-1] / sd, w_std[-1] - np.sum(w_std[:-1] * mu / sd))
f_star = res.fun
print(f"minimum loss {f_star:.8f} (standardized); the same weights in raw units give {probs['raw']['f_grad'](w_raw)[0]:.8f}")

def hessian_cond(p, w):                                             # condition number of the Hessian at w
    A = p["A"]; s = expit(A @ w) * expit(-A @ w)
    H = (A.T * s) @ A / len(A); H[:-1, :-1] += lam * np.diag(p["pen"])
    ev = np.linalg.eigvalsh(H); return ev[-1] / ev[0]
print(f"condition number of the Hessian at the minimum: raw {hessian_cond(probs['raw'], w_raw):.3g}, "
      f"standardized {hessian_cond(probs['standardized'], w_std):.3g}")

def run_gd(p, beta=0.0, max_iter=20000, tol=1e-6):
    w, v, eta, gaps = np.zeros(31), np.zeros(31), 1 / p["L"], []
    for it in range(max_iter):
        f, g = p["f_grad"](w); gaps.append(f - f_star)
        if f - f_star < tol: break
        v = beta * v - eta * g; w = w + v                               # heavy ball; beta = 0 is plain GD
    return np.array(gaps)

hist = {}
for name, p in probs.items():
    for beta in [0.0, 0.9]:
        gaps = hist[name, beta] = run_gd(p, beta)
        done = f"{len(gaps) - 1} iterations" if gaps[-1] < 1e-6 else f"not converged after 20,000 iterations, gap {gaps[-1]:.3g}"
        print(f"{name:12s} | cond(A^T A/n) {p['cond_data']:.2g} | step 1/L = {1 / p['L']:.3g} | "
              f"{'GD' if beta == 0 else 'momentum 0.9':12s}: {done}")

6. Momentum¶

Heavy-ball momentum (Polyak 1964) keeps a running velocity: $v \leftarrow \beta v - \eta \nabla f(x)$, then $x \leftarrow x + v$. On a quadratic with Hessian eigenvalues between $\mu$ and $L$, the best choice, $\eta = 4/(\sqrt{L} + \sqrt{\mu})^2$ and $\beta = \left(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\right)^2$, shrinks the error by about $\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}$ per step instead of $\frac{\kappa - 1}{\kappa + 1}$. For $\kappa = 100$ that is $9/11 \approx 0.818$ instead of $99/101 \approx 0.980$. The right panel repeats section 5 for the plot.

lams = np.array([1.0, 100.0]); kappa = 100
eta_gd = 2 / (1 + 100)
eta_hb = 4 / (np.sqrt(lams.max()) + np.sqrt(lams.min())) ** 2
beta_hb = ((np.sqrt(kappa) - 1) / (np.sqrt(kappa) + 1)) ** 2
x, v, err_hb = x0.copy(), np.zeros(2), [1.0]
for t in range(1000):
    v = beta_hb * v - eta_hb * lams * x; x = x + v
    err_hb.append(np.linalg.norm(x) / np.linalg.norm(x0))
err_hb = np.array(err_hb)
err_gd = np.linalg.norm(gd_quadratic(lams, eta_gd, x0, 1000), axis=1) / np.linalg.norm(x0)
print(f"kappa = 100: heavy ball with eta = {eta_hb:.4f}, beta = {beta_hb:.4f}")
print(f"steps to shrink the error by 1e6: GD {int(np.argmax(err_gd <= 1e-6))}, heavy ball {int(np.argmax(err_hb <= 1e-6))} "
      f"(rates per step: {99 / 101:.3f} and {9 / 11:.3f}, so about {math.log(1e-6) / math.log(99 / 101):.0f} and {math.log(1e-6) / math.log(9 / 11):.0f} steps)")

fig, ax = plt.subplots(1, 2, figsize=(9, 3.3))
ax[0].semilogy(err_gd, label="GD, best fixed step"); ax[0].semilogy(err_hb, label="heavy-ball momentum")
ax[0].set_xlim(0, 800); ax[0].set_ylim(1e-9, 3); ax[0].set_xlabel("step"); ax[0].set_ylabel("relative error ||x_t|| / ||x_0||")
ax[0].set_title("quadratic, kappa = 100", fontsize=10); ax[0].legend(fontsize=8)
for (name, beta), gaps in hist.items():
    ax[1].loglog(np.arange(1, len(gaps) + 1), np.maximum(gaps, 1e-12), label=f"{name}, {'GD' if beta == 0 else 'momentum 0.9'}")
ax[1].set_xlabel("iteration (log scale)"); ax[1].set_ylabel("loss minus minimum"); ax[1].set_title("logistic regression, breast cancer", fontsize=10)

plt.tight_layout(); plt.show()

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. The step-size limit is $2/\lambda_{\max}$. For $f(x) = 2x^2$, $\eta = 0.25$ reached the minimum in one step (factor 0), $\eta = 0.4$ converged while oscillating (factor −0.6), $\eta = 0.5$ bounced between 1 and −1 for ever, and $\eta = 0.6$ diverged: −1.4, 1.96, −2.744, …
  2. Conditioning sets the speed. With the best fixed step, GD needed 1, 69 and 691 steps for $\kappa$ = 1, 10 and 100, exactly the theory's $\ln(10^{-6})/\ln\frac{\kappa-1}{\kappa+1}$. The $\kappa = 100$ path zig-zags across the valley and creeps along it.
  3. A bigger step is not always faster. For $\kappa = 10$, after 100 steps $f$ was 3.53e-08 at $\eta = 0.1$, 2.04e-16 at the best $\eta = 0.182$, 0.0879 at $\eta = 0.198$ (just below the limit) and 262 at $\eta = 0.202$ (just above it; it started at 55).
  4. Convexity can be tested along a line. The logistic loss had a positive semidefinite Hessian at 5 random points (smallest eigenvalue 0.0017) and stayed below its chord (1.073 at the midpoint against 1.500). The network's loss was 0.0167 at both ends, because reversing the hidden units does not change the function, but 1.784 at the midpoint and up to 3.050 on the line, so it is not convex.
  5. Feature scaling changed the conditioning, not the problem. Both runs had the same minimum, 0.09959138. On raw features, $\kappa(A^\top A/n)$ was 2.4e12, the Hessian at the minimum had condition number 4.16e11 and the step was 2.38e-06; after 20,000 iterations GD was still 0.262 above the minimum (with momentum, 0.243). On standardized features the Hessian's condition number was 22.9 and the step 0.3; GD converged in 898 iterations and momentum in 129, although momentum's loss did not fall at every step (see the bump in the right-hand plot).
  6. Momentum helps most when $\kappa$ is large. On the $\kappa = 100$ quadratic the heavy ball needed 85 steps against 691 for GD. That is more than the 69 that its rate 9/11 alone suggests: with these settings the error also carries a factor that grows linearly with the step count.
  7. These are small problems. Neural network losses are not convex, yet the same two quantities, the step-size limit and the conditioning, still matter there: Course 3 session 3 shows full-batch GD pushing the largest Hessian eigenvalue up to about $2/\eta$ (the edge of stability).
