Mathematics for Machine Learning

The mathematics machine learning actually uses, taught through ML questions and checked in NumPy: vectors and matrices, least squares, eigenvalues, SVD and PCA, gradients and automatic differentiation, probability and estimation, optimization, numerical stability, information theory, and graphs from PageRank to graph neural networks.

  • Linear algebra
  • SVD & PCA
  • Calculus & autodiff
  • Probability
  • Optimization
  • Numerical methods
Start session 1 Course document (PDF) Folder on GitHub

Sessions

  1. 01

    Vectors, matrices and NumPy

    Represent data as vectors and matrices, compute dot products, norms and cosine similarities by hand and in NumPy, run a nearest-neighbour search with loops and with one matrix product, and draw what 2 × 2 matrices do to the plane.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  2. 02

    Linear systems, rank and least squares

    Solve linear systems and decide from the rank whether they have one, no or many solutions, derive least squares by hand, fit linear regression with the normal equations, `lstsq` and QR, and see what a duplicated feature does to each.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  3. 03

    Eigenvalues, SVD and PCA

    Compute eigenvectors by hand, by power iteration and with NumPy, compress an image with the truncated SVD and check Eckart–Young, and run PCA on the digits from the SVD of the centred data.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  4. 04

    Calculus for ML: gradients, Jacobians and the chain rule

    Compute gradients and Jacobians by hand, check three matrix-calculus rules, derive the gradient of the logistic-regression loss and verify it with central differences, and choose the finite-difference step size.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  5. 05

    Automatic differentiation and backpropagation

    Compute derivatives symbolically, numerically and automatically, build forward mode with dual numbers and a scalar reverse-mode engine, count their costs, and check vectorized backpropagation against the engine and PyTorch on a small network.

    Read notebook Colab Kaggle .ipynb Runs fully on CPU
  6. 06

    Probability for ML

    Compute expectations, variances and conditional probabilities by hand and by simulation, watch averages converge, work through Bayes' rule with a medical test, sample a 2-D Gaussian with its Cholesky factor and draw its covariance ellipses, and see a confounder create correlation.

    Read notebook Colab Kaggle .ipynb Runs fully on CPU
  7. 07

    Statistics and estimation: MLE, MAP and uncertainty

    Derive maximum likelihood and MAP estimates for a coin and a Gaussian, fit ridge regression as a MAP estimate, and put a bootstrap confidence interval on a classifier's test accuracy.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  8. 08

    Optimization I: gradient descent and convexity

    Run gradient descent on quadratics and on logistic regression, find the step-size limit $2/\lambda_{\max}$, test convexity, and measure how conditioning, feature scaling and momentum change the number of steps.

    Read notebook Colab Kaggle .ipynb Runs fully on CPU
  9. 09

    Optimization II: SGD, Newton's method and constraints

    Compare full-batch gradient descent, SGD, Newton's method and L-BFGS on logistic regression, watch Newton fail on a non-convex function, and solve constrained problems with Lagrange multipliers, recovering the softmax form from maximum entropy.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  10. 10

    Numerical methods for ML

    Measure the precision and range of float64, float32, float16 and bfloat16, break naive softmax, log-sum-exp, softplus and variance formulas and fix them, and compare normal equations, QR and conjugate gradient on ill-conditioned and large sparse systems.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  11. 11

    Information theory for ML

    Compute entropy, cross-entropy, KL divergence and mutual information by hand and in NumPy, compare forward and reverse KL, and measure the perplexity of unigram and bigram character models on a short text.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell
  12. 12

    Graphs and matrices: from PageRank to graph neural networks

    Represent graphs as adjacency and Laplacian matrices, find stationary distributions of random walks, compute PageRank by power iteration, cluster two moons spectrally, and write one graph convolution as a matrix product and as message passing.

    Read notebook Colab Kaggle .ipynb 1 NOT RUN cell

Before you start

One notebook per session. Read them with their saved outputs on the course website or on GitHub, or open them in Google Colab or Kaggle Notebooks and run them from the top.

  • Every cell without a NOT RUN label was run once, top to bottom, on a CPU in November 2026 (Python 3.13, NumPy 2.5, SciPy 1.18, scikit-learn 1.9 and matplotlib 3.11, plus PyTorch 2.15 in sessions 5 and 10), and the outputs are saved in the notebooks. A second, independent run reproduced every printed number; only timings differ.
  • Each notebook starts with a small example to work by hand, then checks it in code. The runnable parts use scikit-learn's built-in data (wine, digits, diabetes, breast cancer, a sample image and the two-moons generator), a short text, or data generated in the notebook, so each notebook finishes in under half a minute on a CPU.
  • Cells marked TODO are exercises for students. Cells marked NOT RUN need a GPU, a download or a library that is not installed here. They were written from the libraries' documented interfaces and have not been executed, so run each one before recording (the table below says what each needs).
  • Nothing extra needs installing for the runnable cells on Google Colab or Kaggle.
  • Results that went against expectation are stated in each notebook's "What to notice" cell and in the course document. Examples: cosine similarity did not beat Euclidean distance on the original digits, 0.981 against 0.983 (session 1); with a duplicated feature the normal equations raised an error for only 2 of 10 features and returned meaningless weights without warning for the other 8 (session 2); power iteration needed about 200 steps on the digits covariance (session 3); a correlation that should have been near 0 came out as 0.027 by chance, so the notebook repeats the simulation (session 6); heavy-ball momentum needed 85 steps where its rate alone suggests 69 (session 8); SGD with a decaying step was still level with gradient descent after 30 passes (session 9); conjugate gradients needed only 2.5 times as many iterations when √κ grew tenfold (session 10); two estimators of the same mutual information disagreed by about 0.3 bits (session 11); spectral clustering scored only 0.650 on noisier moons although the true split had the smaller normalized cut (session 12).
