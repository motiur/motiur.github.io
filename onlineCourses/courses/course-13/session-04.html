1. A synthetic region of fields¶

A crop type map labels every pixel with what grows there. The labels for training come from field surveys: someone visits a field and writes down the crop. Pixels of one field share everything (the farmer, the planting date, the soil), and neighbouring fields are alike too. This section builds a region that has both properties.

The region is 96 × 96 pixels cut into 260 irregular fields. Each field grows one of five classes, chosen from probabilities that change smoothly over the region (think of irrigation access and land height), so classes come in clusters:

  • Boro only (dry-season rice), Aman only (monsoon rice), Boro then Aman (two rice crops in one year), Aus (an early-season rice, rare here), and trees (green all year).

The proportions, calendars and signal values are made-up assumptions for teaching, built around the three rice seasons. Real fields are messier than their class name, so we add that too: many "Boro only" fields fill with weeds in the monsoon, and many "Aman only" fields carry a short green cover in the dry season, more often in some parts of the region than others. Planting dates also shift by several weeks from one part of the region to another, and by a couple of weeks from field to field.

import time
import numpy as np
import matplotlib.pyplot as plt
import torch
import torch.nn as nn
import torch.nn.functional as F
from scipy.ndimage import gaussian_filter
from scipy.spatial import cKDTree
from scipy.spatial.distance import pdist
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import KFold, GroupKFold
from sklearn.metrics import f1_score, accuracy_score
from sklearn.neighbors import NearestNeighbors

torch.set_num_threads(1)
torch.manual_seed(0)
t_start = time.time()
rng = np.random.default_rng(4)
H = W = 96
CLASSES = ["Boro only", "Aman only", "Boro then Aman", "Aus", "trees"]

def smooth_map(sigma):
    f = gaussian_filter(rng.normal(size=(H, W)), sigma, mode="reflect")
    return (f - f.mean()) / f.std()

n_fields = 260
seeds = rng.uniform(0, H, (n_fields, 2))
rr, cc = np.mgrid[0:H, 0:W]
_, field_id = cKDTree(seeds).query(np.c_[rr.ravel(), cc.ravel()])
field_id = field_id.reshape(H, W)                                  # irregular (Voronoi) fields
sr, sc = np.clip(seeds.astype(int), 0, H - 1).T
irrig, low = smooth_map(14)[sr, sc], smooth_map(14)[sr, sc]       # two hidden landscape factors per field
logits = np.stack([0.0 + 1.2 * irrig + 1.0 * low, 0.3 - 1.2 * irrig - 0.5 * low, 0.8 + 1.2 * irrig - 1.0 * low,
                   -1.3 - 0.3 * irrig + 0.2 * low, -0.9 + 0.0 * irrig - 0.6 * low], 1)
p = np.exp(logits); p /= p.sum(1, keepdims=True)
field_class = np.array([rng.choice(5, p=pi) for pi in p])
crop = field_class[field_id]
block = (sr // 24) * 4 + (sc // 24)                                # 16 spatial blocks of 24 x 24 pixels
field_block = block                                                 # each field belongs to the block of its centre
delay_map, dim_map, weed_map = smooth_map(25), smooth_map(25), smooth_map(18)   # regional delay, dimming, weediness
print("fields per class:", {CLASSES[k]: int((field_class == k).sum()) for k in range(5)})
print("pixels per class:", {CLASSES[k]: int((crop == k).sum()) for k in range(5)})

2. Two signals over a year: NDVI and radar¶

Each pixel gets 36 values of NDVI (10-day composites; session 3) and 36 values of radar backscatter in the VH polarization (in decibels, dB), like Sentinel-1. Radar sees through clouds and responds to water and plant structure: a flooded field is very dark (about −23 dB here), bare soil is in between, and a growing rice canopy gets brighter. NDVI in the monsoon still carries leftover cloud errors after compositing, which pull it down at random.

Variation comes at three levels: the region (planting delay, dimming), the field (its own planting date and peak) and the pixel (noise and leftover clouds).

DOY = 5 + 10 * np.arange(36)
dl = lambda t, up, down, k=8.0: 1 / (1 + np.exp(-(t - up) / k)) - 1 / (1 + np.exp(-(t - down) / k))
seasons = {"boro": (50, 115), "aman": (235, 310), "aus": (140, 190)}
CAL = {0: ["boro"], 1: ["aman"], 2: ["boro", "aman"], 3: ["aus"]}

ndvi = np.zeros((H * W, 36)); vh = np.zeros((H * W, 36))
fid, rows, cols = field_id.ravel(), rr.ravel(), cc.ravel()
for f in range(n_fields):
    pix = np.where(fid == f)[0]
    c = field_class[f]
    shift = 30 * delay_map[sr[f], sc[f]] + rng.normal(0, 18)          # regional + field planting shift (days)
    peak = 0.80 - 0.06 * dim_map[sr[f], sc[f]] + rng.normal(0, 0.06)
    if c == 4:                                                         # trees
        nd = 0.72 - 0.10 * np.cos(2 * np.pi * (DOY - 200) / 365) + rng.normal(0, 0.05)
        v = -12.0 + 0 * DOY
    else:
        nd, v = 0.18 + 0 * DOY, -17.0 + 0 * DOY
        for s in CAL[c]:
            up, down = seasons[s][0] + shift, seasons[s][1] + shift
            g = dl(DOY, up, down)
            flood = np.exp(-((DOY - (up - 22)) / 12.0) ** 2)                # flooded around transplanting
            nd = nd + (peak - 0.18) * g - 0.22 * flood * (1 - g)
            v = v + 4.0 * g - 6.0 * flood * (1 - g)
        if rng.random() < 1 / (1 + np.exp(-(1.0 + 1.5 * weed_map[sr[f], sc[f]]))):
            if c == 0:      # Boro-only field: weeds grow in the monsoon
                gw = dl(DOY, 225 + shift + rng.normal(0, 10), 300 + shift)
                nd = nd + 0.55 * rng.uniform(0.6, 1.0) * gw; v = v + 3.85 * gw
            elif c == 1:    # Aman-only field: a short green cover in the dry season
                gw = dl(DOY, 45 + shift + rng.normal(0, 10), 105 + shift)
                nd = nd + 0.55 * rng.uniform(0.6, 1.0) * gw; v = v + 3.3 * gw
    ndvi[pix] = nd + rng.normal(0, 0.03, (len(pix), 36))
    vh[pix] = v + rng.normal(0, 1.0, (len(pix), 36))
monsoon = (DOY >= 160) & (DOY <= 290)
hit = (rng.random(ndvi.shape) < 0.4) & monsoon                          # leftover cloud errors in the monsoon
ndvi[hit] -= rng.uniform(0.1, 0.5, hit.sum())
shifts = 30 * delay_map[sr, sc]
print(f"regional planting shift over the fields: 5th percentile {np.percentile(shifts, 5):+.0f} days, "
      f"95th percentile {np.percentile(shifts, 95):+.0f} days")
y_all = crop.ravel()
X_feat = np.hstack([ndvi, (vh + 17) / 4])                              # 72 features for the random forest
X_seq = np.stack([ndvi, (vh + 17) / 4], 1).astype(np.float32)          # (pixels, 2 channels, 36 dates) for the CNN

fig, ax = plt.subplots(1, 3, figsize=(9, 3.1))
cmap = plt.matplotlib.colors.ListedColormap(["#1b9e77", "#d95f02", "#7570b3", "#e7298a", "#66a61e"])
ax[0].imshow(crop, cmap=cmap, vmin=-0.5, vmax=4.5)
for v_ in (24, 48, 72):
    ax[0].axvline(v_ - 0.5, color="w", lw=0.8); ax[0].axhline(v_ - 0.5, color="w", lw=0.8)
ax[0].set_title("crop map, 16 blocks", fontsize=9); ax[0].set_xticks([]); ax[0].set_yticks([])
for k in range(5):
    ax[1].plot(DOY, ndvi[y_all == k].mean(0), color=cmap(k), label=CLASSES[k])
    ax[2].plot(DOY, vh[y_all == k].mean(0), color=cmap(k))
ax[1].set_xlabel("day of year"); ax[1].set_ylabel("mean NDVI"); ax[1].legend(fontsize=6)
ax[2].set_xlabel("day of year"); ax[2].set_ylabel("mean VH backscatter (dB)")
ax[1].set_title("NDVI by class", fontsize=9); ax[2].set_title("radar by class", fontsize=9)
plt.tight_layout(); plt.show()

3. Two models: a random forest and a temporal CNN¶

  • Random forest on the 72 values (36 NDVI, 36 radar). Trees do not know that date 10 follows date 9, but they cope well with noise and need little tuning.
  • Temporal CNN (after Pelletier et al. 2019): 1-D convolutions slide along time, so the network can learn shapes such as "a dip then a rise" wherever they happen, which helps when planting dates shift. Three convolution layers (16 filters, width 5) with batch normalization and dropout, then two dense layers.

To keep the notebook fast, each fold trains on a random sample of 2,000 training pixels; the scores are computed on all held-out pixels.

class TempCNN(nn.Module):
    def __init__(self, n_in=2, n_cls=5, h=16, T=36):
        super().__init__()
        layers = []
        for i in range(3):
            layers += [nn.Conv1d(n_in if i == 0 else h, h, 5, padding=2), nn.BatchNorm1d(h), nn.ReLU(), nn.Dropout(0.2)]
        self.conv = nn.Sequential(*layers)
        self.head = nn.Sequential(nn.Flatten(), nn.Linear(h * T, 64), nn.ReLU(), nn.Dropout(0.3), nn.Linear(64, n_cls))
    def forward(self, x):
        return self.head(self.conv(x))

def fit_cnn(Xs, ys, epochs=20, seed=0):
    torch.manual_seed(seed); g = torch.Generator().manual_seed(seed)
    m = TempCNN(); opt = torch.optim.Adam(m.parameters(), lr=2e-3)
    Xt, yt = torch.tensor(Xs), torch.tensor(ys)
    m.train()
    for ep in range(epochs):
        perm = torch.randperm(len(yt), generator=g)
        for i in range(0, len(yt), 64):
            idx = perm[i:i + 64]
            loss = F.cross_entropy(m(Xt[idx]), yt[idx])
            opt.zero_grad(); loss.backward(); opt.step()
    m.eval()
    return m

def predict_cnn(m, Xs):
    with torch.no_grad():
        return m(torch.tensor(Xs)).argmax(1).numpy()

def run_cv(splitter, groups, n_train=2000, seed=0):
    # out-of-fold predictions of both models for every pixel
    pred_rf, pred_cnn = np.zeros_like(y_all), np.zeros_like(y_all)
    rs = np.random.default_rng(seed)
    for tr, te in splitter.split(X_feat, y_all, groups):
        sub = rs.choice(tr, min(n_train, len(tr)), replace=False)
        rf = RandomForestClassifier(n_estimators=100, n_jobs=1, random_state=0).fit(X_feat[sub], y_all[sub])
        pred_rf[te] = rf.predict(X_feat[te])
        pred_cnn[te] = predict_cnn(fit_cnn(X_seq[sub], y_all[sub]), X_seq[te])
    return pred_rf, pred_cnn

4. Random, field-level and spatial block cross-validation¶

Three ways to split the same pixels into 4 folds:

  • random pixel split: pixels of one field land in both training and test folds;
  • field-level split (GroupKFold by field): every field is entirely in training or entirely in test;
  • spatial block split (GroupKFold by 24 × 24 block, whole fields assigned by their centre): test fields are far from training fields, as when a map is used in a new area (Roberts et al. 2017).

We report overall accuracy and the macro F1 score (the average of the per-class F1 scores, so the rare class counts as much as the common ones).

pix_block = field_block[fid]
schemes = {"random pixels": (KFold(4, shuffle=True, random_state=0), None),
           "field-level": (GroupKFold(4), fid),
           "spatial blocks": (GroupKFold(4), pix_block)}
oof, table = {}, {}
for name, (sp, g) in schemes.items():
    t0 = time.time()
    oof[name] = run_cv(sp, g)
    for model, pr in zip(["random forest", "temporal CNN"], oof[name]):
        table[name, model] = (accuracy_score(y_all, pr), f1_score(y_all, pr, average="macro"))
    print(f"{name:15s} RF: accuracy {table[name, 'random forest'][0]:.3f}, macro F1 {table[name, 'random forest'][1]:.3f} | "
          f"CNN: accuracy {table[name, 'temporal CNN'][0]:.3f}, macro F1 {table[name, 'temporal CNN'][1]:.3f}  ({time.time() - t0:.0f} s)")

6. Where can the map be trusted? The area of applicability¶

Meyer & Pebesma (2021) propose a dissimilarity index (DI): the distance from a new pixel's features to the nearest training pixel, divided by the average distance between training pixels. Pixels whose DI is larger than what the training data themselves show under cross-validation are outside the area of applicability, and their predictions deserve less trust. Below is a simplified version (standardized features, no importance weights) for the spatial block split.

def di_split(splitter, groups, n_train=2000, seed=0):
    rs = np.random.default_rng(seed)
    inside_acc, outside_acc, outside_share = [], [], []
    pred_rf = oof["spatial blocks"][0]
    for tr, te in splitter.split(X_feat, y_all, groups):
        sub = rs.choice(tr, min(n_train, len(tr)), replace=False)
        mu, sd = X_feat[sub].mean(0), X_feat[sub].std(0) + 1e-9
        Z, Zt = (X_feat[sub] - mu) / sd, (X_feat[te] - mu) / sd
        d_bar = pdist(Z[rs.choice(len(Z), 500, replace=False)]).mean()     # average distance between training pixels
        d_te = NearestNeighbors(n_neighbors=1).fit(Z).kneighbors(Zt)[0][:, 0] / d_bar
        di_tr = np.zeros(len(sub))                                     # training DI, across training blocks
        for b in np.unique(groups[sub]):
            inb = groups[sub] == b
            di_tr[inb] = NearestNeighbors(n_neighbors=1).fit(Z[~inb]).kneighbors(Z[inb])[0][:, 0] / d_bar
        q1, q3 = np.percentile(di_tr, [25, 75])
        out = d_te > q3 + 1.5 * (q3 - q1)                              # upper whisker as the threshold
        ok = pred_rf[te] == y_all[te]
        inside_acc.append(ok[~out].mean()); outside_acc.append(ok[out].mean() if out.any() else np.nan)
        outside_share.append(out.mean())
    return np.mean(inside_acc), np.nanmean(outside_acc), np.mean(outside_share)

ins, outs, share = di_split(GroupKFold(4), pix_block)
print(f"spatial block CV, random forest: {share:.3f} of test pixels fall outside the area of applicability")
print(f"accuracy inside {ins:.3f}, outside {outs:.3f}")
print(f"runtime so far {time.time() - t_start:.0f} s")

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. Random pixel splits mostly measure memory of fields. Under random 4-fold cross-validation the random forest scored accuracy 0.983 (macro F1 0.950) and the temporal CNN 0.995 (0.987). Holding out whole fields dropped them to 0.906 (0.809) and 0.955 (0.839); spatial blocks to 0.885 (0.784) and 0.944 (0.831). Pixels of one field are near copies, so a random split tests the model on fields it has already seen.
  2. Spatial blocks were only a little harsher than field-level splits. Most of the optimism came from sharing fields between training and test; holding out whole regions removed a further 2.1 points of accuracy for the random forest and 1.1 for the CNN, even though planting shifted from −42 to +50 days across the region (5th to 95th percentile).
  3. The rare class collapses. Aus has 8 fields (319 pixels). Its F1 was 0.78 (random forest) and 0.95 (CNN) under random splits, but only 0.25 to 0.30 for both models under field-level and block splits. Overall accuracy hides this; per-class and macro F1 show it.
  4. Errors come as whole fields. Under the block split, 11.5% of fields had more than half their pixels wrong and 79.2% had none wrong (random split: 1.9% and 91.5%). Map errors come in clumps, so a map has about as many independent test cases as fields, not pixels.
  5. The temporal CNN beat the random forest by 5 to 6 points under the honest splits. Its convolutions recognize the same shape at shifted dates, which helps when planting dates move by weeks. This is one synthetic setting: on real data the gap between model families is often small and preprocessing matters as much (Rußwurm & Körner 2020).
  6. The area of applicability flagged the worst pixels. Under the block split, 5.8% of test pixels fell outside it, and only 0.242 of them were classified correctly, against 0.913 inside. The dissimilarity index is a cheap warning that the map is extrapolating.
