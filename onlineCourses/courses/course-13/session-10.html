1. Annual maximum rainfall¶

Engineers ask questions like "how high must this embankment be?" and "how big a drain does this town need?". They need the size of rare extremes, which a short record may not contain. Extreme value theory gives the shape that the largest of many values tends to follow. If we keep only the largest daily rain of each year (the annual maximum), the generalized extreme value (GEV) distribution is the natural model (Coles 2001):

$$F(z) = \exp\left\{-\left[1 + \xi\,\frac{z - \mu}{\sigma}\right]^{-1/\xi}\right\},$$

with location $\mu$, scale $\sigma$ and shape $\xi$. The shape sets the tail: $\xi > 0$ is a heavy tail with no upper limit, $\xi = 0$ is the Gumbel distribution, and $\xi < 0$ has an upper limit. Daily rainfall maxima usually have $\xi$ near zero or a little above.

The data are synthetic: 50 annual maxima (1975–2024) drawn from a GEV with $\mu = 110$ mm, $\sigma = 35$ mm and $\xi = 0.15$, standing in for a station record. Because we know the truth, we can check every estimate.

import time
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats, optimize

t_start = time.time()
np.random.seed(0)
rng = np.random.default_rng(0)

XI, MU, SIGMA = 0.15, 110.0, 35.0
true_gev = stats.genextreme(c=-XI, loc=MU, scale=SIGMA)   # careful: SciPy's shape is c = -xi
years = np.arange(1975, 2025)
amax = true_gev.rvs(len(years), random_state=rng)
order = np.argsort(amax)[::-1]
print(f"{len(amax)} annual maxima: median {np.median(amax):.0f} mm, smallest {amax.min():.0f} mm, largest {amax.max():.0f} mm in {years[order[0]]}, "
      f"next {amax[order[1]]:.0f} mm in {years[order[1]]}")

T = np.array([10, 50, 100])
return_level = lambda dist, T: dist.ppf(1 - 1 / np.asarray(T, dtype=float))   # exceeded with probability 1/T per year
print("true return levels:  " + ", ".join(f"{t}-year {z:.0f} mm" for t, z in zip(T, return_level(true_gev, T))))

2. Fitting the GEV by maximum likelihood¶

We write the negative log-likelihood of the GEV ourselves (Course 2 session 7 covers maximum likelihood) and minimize it, then compare with SciPy's genextreme.fit. SciPy's shape parameter is $c = -\xi$: a heavy tail has negative $c$ in SciPy. Mixing up the sign turns a heavy tail into a bounded one.

A return level $z_T$ is exceeded in any one year with probability $1/T$: $z_T = F^{-1}(1 - 1/T)$. We also fit a Gumbel distribution ($\xi = 0$), a common simpler choice, to see what assuming a lighter tail does.

def gev_nll(theta, x):
    """Negative log-likelihood of the GEV; theta = (xi, mu, log sigma)."""
    xi, mu, log_s = theta
    s = np.exp(log_s); z = (x - mu) / s
    if abs(xi) > 0.5:
        return 1e10                                           # keep the shape in a sensible range for 50 values
    if abs(xi) < 1e-6:
        return len(x) * log_s + z.sum() + np.exp(-z).sum()   # the Gumbel limit
    t = 1 + xi * z
    if np.any(t <= 0):
        return 1e10                                           # a data point outside the distribution's range
    return len(x) * log_s + (1 + 1 / xi) * np.log(t).sum() + (t ** (-1 / xi)).sum()

def fit_gev(x, start=None):
    if start is None:                                         # start from the Gumbel method-of-moments values
        s0 = np.sqrt(6 * np.var(x)) / np.pi
        start = (0.1, np.mean(x) - 0.5772 * s0, np.log(s0))
    res = optimize.minimize(gev_nll, start, args=(x,), method="Nelder-Mead",
                            options={"xatol": 1e-5, "fatol": 1e-8, "maxiter": 4000})
    xi, mu, log_s = res.x
    return xi, mu, np.exp(log_s)

xi_hat, mu_hat, s_hat = fit_gev(amax)
c_scipy, loc_scipy, scale_scipy = stats.genextreme.fit(amax)
print(f"our fit:    xi = {xi_hat:.3f}, mu = {mu_hat:.1f}, sigma = {s_hat:.1f}   (truth 0.150, 110.0, 35.0)")
print(f"SciPy fit:  c = {c_scipy:.3f} (so xi = {-c_scipy:.3f}), loc = {loc_scipy:.1f}, scale = {scale_scipy:.1f}")
fitted = stats.genextreme(c=-xi_hat, loc=mu_hat, scale=s_hat)
gumbel = stats.gumbel_r(*stats.gumbel_r.fit(amax))
print("return level    true    GEV fit   Gumbel fit   largest of 50 years")
for t, z_true, z_fit, z_gum in zip(T, return_level(true_gev, T), return_level(fitted, T), return_level(gumbel, T)):
    print(f"{t:4d}-year      {z_true:6.0f}    {z_fit:6.0f}      {z_gum:6.0f}          {amax.max():6.0f}")

3. How sure are we? Bootstrap intervals and record length¶

The fitted return levels come from only 50 numbers, so they are uncertain (Course 2 session 7 introduced the bootstrap). We use a parametric bootstrap: simulate 1,000 new 50-year records from the fitted GEV, refit each, and take the 2.5th and 97.5th percentiles of the return levels. Then we ask how the uncertainty depends on the record length, by drawing records of 20, 50 and 100 years from the true distribution and refitting each 300 times.

def bootstrap_levels(params, n_years, B, seed):
    """Return levels (10, 50, 100 years) refitted on B simulated records of n_years from GEV(params)."""
    r = np.random.default_rng(seed)
    xi, mu, s = params
    dist = stats.genextreme(c=-xi, loc=mu, scale=s)
    out = np.empty((B, len(T)))
    for b in range(B):
        x = dist.rvs(n_years, random_state=r)
        f = fit_gev(x, start=(xi, mu, np.log(s)))
        out[b] = return_level(stats.genextreme(c=-f[0], loc=f[1], scale=f[2]), T)
    return out

t0 = time.time()
boot = bootstrap_levels((xi_hat, mu_hat, s_hat), len(amax), B=1000, seed=1)
lo, hi = np.percentile(boot, [2.5, 97.5], axis=0)
print(f"parametric bootstrap, 1,000 refits in {time.time() - t0:.0f} s")
for t, z_fit, a, b, z_true in zip(T, return_level(fitted, T), lo, hi, return_level(true_gev, T)):

4. What "a 100-year event" means¶

A 100-year event has a 1% chance in each year, independently of the years before. Over a 30-year period, such as the life of an embankment or a loan, the chance of at least one is $1 - 0.99^{30}$. We check by simulating 100,000 thirty-year periods from the true distribution.

z100 = return_level(true_gev, 100)
sims = true_gev.rvs((100000, 30), random_state=np.random.default_rng(5)) > z100
counts = sims.sum(axis=1)
print(f"P(at least one 100-year event in 30 years): formula {1 - 0.99 ** 30:.3f}, simulation {np.mean(counts >= 1):.3f}")
print(f"P(two or more in 30 years): simulation {np.mean(counts >= 2):.3f}; P(at least one in 100 years): formula {1 - 0.99 ** 100:.3f}")
gaps = np.diff(np.nonzero(true_gev.rvs(200000, random_state=np.random.default_rng(6)) > z100)[0])
print(f"years between 100-year events in a long simulation: mean {gaps.mean():.0f}, but {np.mean(gaps <= 10):.0%} of the gaps are 10 years or less")

P(at least one 100-year event in 30 years): formula 0.260, simulation 0.261

5. Acting on a forecast: the cost–loss model¶

A user can protect at cost $C$ (cover the harvested grain, move the cattle, open a cyclone shelter early) or not; if the bad event happens without protection, the loss is $L$. With an event probability $p$, protecting costs $C$ and not protecting costs $pL$ on average, so it pays to protect when $p > C/L$. Different users have different $C/L$, so one probability serves them all, while a yes/no warning fixes one threshold for everybody.

The economic value (Richardson 2000) compares a forecast with two references: climatology (always protect or never, whichever is cheaper on average) and a perfect forecast: $$V = \frac{E_{\text{climate}} - E_{\text{forecast}}}{E_{\text{climate}} - E_{\text{perfect}}},$$ where $E$ is the average expense per day. $V = 1$ is perfect and $V \le 0$ means the forecast is worth nothing to that user.

Synthetic forecasts: on 4,000 days, the true chance of a damaging rain event varies from day to day (mean 0.15), and the event happens or not by that chance. We compare three forecasts from the same system: the reliable probability, an overconfident version (pushed towards 0 and 1), and a yes/no warning issued when the probability is above 0.5.

rng = np.random.default_rng(7)
n_days = 4000
p_true = rng.beta(0.6, 3.4, n_days)                           # the real chance on each day (mean 0.15)
event = rng.random(n_days) < p_true
logit = lambda p: np.log(p / (1 - p))
p_over = 1 / (1 + np.exp(-(2.0 * logit(np.clip(p_true, 1e-6, 1 - 1e-6)) + 1.2)))   # overconfident: too close to 0 and 1
yes_no = (p_true > 0.5).astype(float)
base = event.mean()
forecasts = {"reliable probability": p_true, "overconfident probability": p_over, "yes/no warning (p > 0.5)": yes_no}

brier = lambda f: np.mean((f - event) ** 2)
print(f"event frequency {base:.3f}; Brier score of climatology {brier(np.full(n_days, base)):.4f}")
for name, f in forecasts.items():
    print(f"{name:27s}: mean forecast {f.mean():.3f}, Brier score {brier(f):.4f}, Brier skill score {1 - brier(f) / brier(np.full(n_days, base)):.3f}")

def value(f, alpha):
    """Economic value for a user with cost/loss ratio alpha (loss L = 1), acting when f > alpha."""
    act = f > alpha
    e_fc = np.mean(np.where(act, alpha, event * 1.0))
    e_clim = min(alpha, base)
    e_perfect = base * alpha
    return (e_clim - e_fc) / (e_clim - e_perfect)

alphas = np.linspace(0.01, 0.95, 95)
curves = {name: np.array([value(f, a) for a in alphas]) for name, f in forecasts.items()}
print("value V for users with cost/loss ratio C/L:")
print("C/L:                        " + "  ".join(f"{a:5.2f}" for a in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7]))
for name, f in forecasts.items():
    print(f"{name:27s} " + "  ".join(f"{value(f, a):5.2f}" for a in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7]))
for name, c in curves.items():
    useful = alphas[c > 0]
    print(f"{name}: V > 0 for C/L from {useful.min():.2f} to {useful.max():.2f}; highest V {c.max():.2f} at C/L = {alphas[c.argmax()]:.2f}")

fig, ax = plt.subplots(1, 2, figsize=(9, 3.4))
bins = np.linspace(0, 1, 11)
for (name, f), mk in zip(list(forecasts.items())[:2], ["o-", "s--"]):
    idx = np.clip(np.digitize(f, bins) - 1, 0, 9)
    keep = [k for k in range(10) if np.sum(idx == k) >= 20]
    ax[0].plot([f[idx == k].mean() for k in keep], [event[idx == k].mean() for k in keep], mk, label=name)
ax[0].plot([0, 1], [0, 1], "k:", lw=1)
ax[0].set_xlabel("forecast probability"); ax[0].set_ylabel("observed frequency"); ax[0].set_title("reliability diagram", fontsize=10)
ax[0].legend(fontsize=7)
for name, c in curves.items():
    ax[1].plot(alphas, c, label=name)
ax[1].set_ylim(-0.2, 1); ax[1].axhline(0, color="gray", lw=0.8)
ax[1].set_xlabel("user's cost/loss ratio C/L"); ax[1].set_ylabel("economic value V"); ax[1].set_title("who gains from which forecast", fontsize=10)
ax[1].legend(fontsize=7)
plt.tight_layout(); plt.show()
print(f"runtime so far {time.time() - t_start:.0f} s")

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. Mind the sign of SciPy's shape. Our maximum-likelihood fit gave $\xi = 0.112$, $\mu = 112.9$ and $\sigma = 40.1$ (truth 0.15, 110 and 35). SciPy's genextreme.fit gave the same fit with $c = -0.112$.
  2. A short record can hold an event rarer than its length. The largest of the 50 maxima, 440 mm in 2001, is above the true 100-year level of 342 mm. The GEV fit gave 10-, 50- and 100-year levels of 215, 309 and 354 mm (true 204, 296 and 342). The Gumbel fit, which assumes a lighter tail, gave 308 mm for the 100-year level, 10% too low.
  3. Rare levels are very uncertain. The 95% bootstrap intervals were 183–253 mm (10-year), 230–419 mm (50-year) and 248–528 mm (100-year), widths of 71, 188 and 279 mm; the truth was inside all three. With 20 years of data, estimates of the 100-year level ranged from 193 to 685 mm; with 100 years, from 256 to 447 mm. More data shrink this epistemic uncertainty (about the parameters), but not the aleatoric year-to-year randomness of the maxima themselves.
  4. "100-year" is a probability, not a schedule. The chance of at least one 100-year event in 30 years was 0.260 by the formula and 0.261 in the simulation; two or more, 0.036; at least one in 100 years, 0.634. The gaps between events averaged 97 years, but 10% of them were 10 years or less.
  5. Probabilities serve more users than a yes/no warning. Brier scores: reliable 0.1017, overconfident 0.1090, yes/no 0.1388, climatology 0.1291. The yes/no warning was worse than climatology on the Brier score, yet it still had value for users with $C/L$ from 0.13 to 0.64. The reliable probability had value from 0.01 to 0.92, the overconfident one only from 0.04 to 0.51. Users with cheap protection and big losses gained most from the reliable probability: at $C/L = 0.05$, $V$ was 0.29, against 0.18 (overconfident) and −1.76 (yes/no). All three curves peaked near $C/L = 0.15$, the event frequency, at 0.51 (reliable), 0.48 (overconfident) and 0.18 (yes/no).
  6. Miscalibration costs value through wrong thresholds, not wrong ranking. For $C/L$ from 0.1 to 0.3 the overconfident forecast was as valuable as the reliable one (0.38, 0.40 and 0.26 at $C/L$ = 0.1, 0.2 and 0.3, against 0.40, 0.39 and 0.26): it ranks the days in the same order, because it is a monotone distortion of the same probabilities. It lost value only for users whose threshold falls where its numbers are most wrong, which recalibration (the second TODO) can repair.
