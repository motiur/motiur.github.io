1. Synthetic leaves: a "lab" set and a "field" set¶

Real leaf-disease datasets such as PlantVillage were photographed leaf by leaf on plain backgrounds under even light. Phone photos from a farmer's field look different: soil, grass and other leaves behind the leaf, uneven light, blur. We build both kinds of image ourselves, 32 × 32 pixels, so we know exactly what changes between them.

Four classes, drawn on an oval leaf with veins:

  • healthy;
  • spots: round brown spots with darker rims (loosely like rice brown spot);
  • streaks: spindle-shaped grey lesions with brown margins along the leaf (loosely like rice blast);
  • blight: yellow-straw drying from the tip and the edges (loosely like bacterial leaf blight).

These are made-up patterns, not real symptoms. In the lab set, the background colour and the brightness follow the class 90% of the time (healthy leaves on light grey, blight on dark grey, and so on), the kind of accident that happens when each disease is photographed in a different session. In the field set, backgrounds are random soil, grass or other colours, with clutter, random light, colour casts, blur and noise.

H, CLASSES = 32, ["healthy", "spots", "streaks", "blight"]
yy, xx = (np.mgrid[0:H, 0:H] + 0.5) / H * 2 - 1                  # pixel centres in [-1, 1]
LAB_BG = np.array([[0.78, 0.78, 0.76], [0.62, 0.70, 0.84], [0.84, 0.77, 0.60], [0.33, 0.33, 0.35]])
LAB_GAIN = np.array([1.10, 0.95, 1.00, 0.85])                    # brightness of each lab session

def natural_background(rng):
    # soil, grass, concrete or a random colour, with smooth texture and pixel noise
    base = [np.array([0.45, 0.33, 0.20]), np.array([0.26, 0.42, 0.16]), np.array([0.58, 0.58, 0.60]),
            rng.uniform(0.2, 0.8, 3)][rng.integers(0, 4)]
    low = gaussian_filter(np.kron(rng.normal(size=(4, 4, 3)), np.ones((8, 8, 1))), (3, 3, 0))
    return np.clip(base + 0.10 * low / (low.std() + 1e-6) + 0.03 * rng.normal(size=(H, H, 3)), 0, 1)

def leaf_image(rng, cls, field, bg_class=None):
    th = rng.uniform(0, np.pi); c, s = np.cos(th), np.sin(th)
    if field:
        cx, cy = rng.uniform(-0.25, 0.25, 2); a = rng.uniform(0.55, 0.9); b = a * rng.uniform(0.4, 0.6)
    else:
        cx, cy = rng.normal(0, 0.05, 2); a = rng.uniform(0.72, 0.82); b = a * rng.uniform(0.48, 0.56)
    u = ((xx - cx) * c + (yy - cy) * s) / a                     # leaf coordinates: u along, v across
    v = (-(xx - cx) * s + (yy - cy) * c) / b
    r2 = u ** 2 + v ** 2
    mask = r2 < 1.0
    img = np.broadcast_to(np.array([0.22, 0.52, 0.16]) + rng.normal(0, 0.025, 3), (H, H, 3)).copy()
    vein = (np.abs(v) < 0.07) | ((np.abs(((u + 0.8 * np.abs(v)) * 3.0) % 1.0 - 0.5) < 0.06) & (np.abs(v) < 0.8))
    img[vein] += np.array([0.06, 0.08, 0.04])
    if cls == 1:                                                # round brown spots
        for _ in range(rng.integers(4, 8)):
            pu, pv = rng.uniform(-0.75, 0.75), rng.uniform(-0.7, 0.7)
            d = np.sqrt(((u - pu) * a) ** 2 + ((v - pv) * b) ** 2); rad = rng.uniform(0.10, 0.15)
            img[d < rad] = [0.30, 0.18, 0.08]; img[d < 0.6 * rad] = [0.48, 0.32, 0.15]
    elif cls == 2:                                              # spindle streaks along the leaf
        for _ in range(rng.integers(2, 5)):
            pu, pv = rng.uniform(-0.6, 0.6), rng.uniform(-0.55, 0.55)
            d = np.sqrt(((u - pu) * a / 0.32) ** 2 + ((v - pv) * b / 0.085) ** 2)
            img[d < 1.0] = [0.42, 0.26, 0.12]; img[d < 0.6] = [0.66, 0.66, 0.60]
    elif cls == 3:                                              # drying from the tip and the edges
        edge = u * np.sign(rng.uniform(-1, 1)) + 0.25 * np.sin(7 * v + rng.uniform(0, 6))
        dry = (edge > rng.uniform(0.15, 0.4)) | (r2 > rng.uniform(0.62, 0.75))
        img[dry] = np.array([0.80, 0.72, 0.36]) + rng.normal(0, 0.02, 3)
    img = np.clip(img + 0.02 * rng.normal(size=img.shape), 0, 1)
    if field:
        bg = natural_background(rng)
        for _ in range(rng.integers(0, 3)):                     # clutter: other leaves or straw
            t2 = rng.uniform(0, np.pi); ox, oy = rng.uniform(-1.1, 1.1, 2)
            u2 = ((xx - ox) * np.cos(t2) + (yy - oy) * np.sin(t2)) / rng.uniform(0.3, 0.6)
            v2 = (-(xx - ox) * np.sin(t2) + (yy - oy) * np.cos(t2)) / rng.uniform(0.1, 0.25)
            bg[u2 ** 2 + v2 ** 2 < 1] = (np.array([0.24, 0.47, 0.18]) * rng.uniform(0.7, 1.2)
                                         if rng.random() < 0.6 else np.array([0.75, 0.68, 0.45]))
        out = np.where(mask[..., None], img, bg) * rng.uniform(0.6, 1.3) + rng.normal(0, 0.06, 3)
        sig = rng.uniform(0, 1.2)
        if sig > 0.3:
            out = gaussian_filter(out, (sig, sig, 0))
        out = out + 0.03 * rng.normal(size=out.shape)
    else:
        r, k_other = rng.random(), rng.integers(0, 4)           # background follows the class 90% of the time
        k = bg_class if bg_class is not None else (cls if r < 0.9 else k_other)
        out = np.where(mask[..., None], img, LAB_BG[k] + rng.normal(0, 0.02, 3)) * (LAB_GAIN[k] + rng.normal(0, 0.03))
        out = out + 0.01 * rng.normal(size=out.shape)
    return np.clip(out, 0, 1).astype(np.float32), mask

def make_set(n_per_class, field, seed, swap=False):
    rng = np.random.default_rng(seed)
    X, Y, M = [], [], []
    for cls in range(4):
        for _ in range(n_per_class):
            im, m = leaf_image(rng, cls, field, bg_class=(cls + 1) % 4 if swap else None)
            X.append(im); Y.append(cls); M.append(m)
    return np.stack(X), np.array(Y), np.stack(M)

X_lab, y_lab, _ = make_set(100, False, 2)           # new lab photos: 400

2. A small CNN trained on lab photos¶

A three-layer convolutional network (8, 16 and 32 channels; about 6,300 parameters) that pools each feature map two ways, by its mean and by its maximum, so a few small lesions are not averaged away. We train it for 30 epochs with Adam on the 1,600 lab images and test it three ways:

  • new lab photos (the usual test set, made the same way as the training set);
  • the same lab leaves on the next class's background colour (a swap test: if accuracy falls, the model was reading the background);
  • field photos.
to_t = lambda X: torch.tensor(X).permute(0, 3, 1, 2).contiguous()     # (n, H, W, 3) -> (n, 3, H, W)
T_tr, Y_tr, Mk_tr = to_t(X_tr), torch.tensor(y_tr), torch.tensor(M_tr)[:, None]
T_lab, T_swap, T_fld = to_t(X_lab), to_t(X_swap), to_t(X_fld)

class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.c1, self.c2, self.c3 = nn.Conv2d(3, 8, 3, padding=1), nn.Conv2d(8, 16, 3, padding=1), nn.Conv2d(16, 32, 3, padding=1)
        self.fc = nn.Linear(64, 4)
    def forward(self, x):
        x = F.max_pool2d(F.relu(self.c1(x)), 2)
        x = F.max_pool2d(F.relu(self.c2(x)), 2)
        x = F.relu(self.c3(x))
        return self.fc(torch.cat([x.mean(dim=(2, 3)), x.amax(dim=(2, 3))], 1))

rng_bank = np.random.default_rng(7)
BANK = to_t(np.stack([natural_background(rng_bank) for _ in range(1500)]).astype(np.float32))
def gauss_kernel(sig):
    k1 = torch.exp(-torch.arange(-2, 3, dtype=torch.float32) ** 2 / (2 * sig ** 2)); k1 = k1 / k1.sum()
    return (k1[:, None] * k1[None, :]).expand(3, 1, 5, 5).contiguous()
KERNELS = {0.6: gauss_kernel(0.6), 1.0: gauss_kernel(1.0)}

def augment(x, m, g, bg=False, jitter=False):
    if bg:      # background randomization: paste the leaf onto a random natural background
        x = torch.where(m, x, BANK[torch.randint(0, len(BANK), (len(x),), generator=g)])
    if jitter:  # brightness, colour cast, blur and noise
        n = len(x)
        x = x * (0.6 + 0.7 * torch.rand(n, 1, 1, 1, generator=g)) + 0.06 * torch.randn(n, 3, 1, 1, generator=g)
        which = torch.randint(0, 3, (n,), generator=g)
        for code_, sig in ((1, 0.6), (2, 1.0)):
            sel = which == code_
            if sel.any():
                x[sel] = F.conv2d(F.pad(x[sel], (2, 2, 2, 2), mode="replicate"), KERNELS[sig], groups=3)
        x = x + 0.03 * torch.randn(x.shape, generator=g)
    return x.clamp(0, 1)

def train(T, bg=False, jitter=False, epochs=30, seed=0):
    torch.manual_seed(seed); g = torch.Generator().manual_seed(seed)
    model = SmallCNN(); opt = torch.optim.Adam(model.parameters(), lr=3e-3)
    for ep in range(epochs):
        perm = torch.randperm(len(Y_tr), generator=g)
        for i in range(0, len(perm), 64):
            idx = perm[i:i + 64]
            xb = augment(T[idx], Mk_tr[idx], g, bg, jitter) if (bg or jitter) else T[idx]
            loss = F.cross_entropy(model(xb), Y_tr[idx])
            opt.zero_grad(); loss.backward(); opt.step()
    return model

def probs(model, T):
    with torch.no_grad():
        return F.softmax(model(T), 1).numpy()

acc = lambda p, y: float((p.argmax(1) == y).mean())
results, field_probs = {}, {}
t0 = time.time()
base = train(T_tr)
p_lab, p_swap, p_fld = probs(base, T_lab), probs(base, T_swap), probs(base, T_fld)

3. Fixes: background randomization, then colour jitter and blur¶

Shortcut learning (Geirhos et al. 2020) means the model found an easier rule than the one we wanted: here, "light grey background means healthy". Two standard fixes change the training images so that the shortcut stops working:

  1. Background randomization: cut each leaf out of its lab photo (easy on a plain background; here we know the mask) and paste it onto a random soil, grass or coloured background.
  2. Colour jitter and blur: random brightness (×0.6 to ×1.3), colour casts, blur and noise, so that light and camera quality stop carrying information.

We chose the augmentation ranges to cover our field conditions. With real data you would look at a small set of field photos to choose them, and you would never tune them on the field test set itself.

for name, kw in [("+ background randomization", dict(bg=True)),
                 ("+ background, colour jitter and blur", dict(bg=True, jitter=True))]:
    t0 = time.time()
    m = train(T_tr, **kw)
    p_lab, p_swap, p_fld = probs(m, T_lab), probs(m, T_swap), probs(m, T_fld)
    results[name] = (acc(p_lab, y_lab), acc(p_swap, y_lab), acc(p_fld, y_fld))
    field_probs[name] = p_fld

4. Fix 3: a leaf mask¶

Another idea is to remove the background altogether: find the leaf, grey out everything else, and do the same at test time. A cheap leaf finder is the excess green index $\mathrm{ExG} = 2g - r - b$ on chromatic coordinates (each channel divided by the sum of the three; Woebbecke et al. 1995), thresholded with Otsu's method, keeping the largest connected region and filling its holes. On a plain lab background it finds the leaf easily. In a field full of grass and other leaves it can fail, so we also test with the true mask, which only a perfect segmentation model would give.

def otsu(v, bins=64):
    hist, edges = np.histogram(v, bins); mids = (edges[:-1] + edges[1:]) / 2
    w0 = np.cumsum(hist); w1 = w0[-1] - w0
    m0 = np.cumsum(hist * mids) / np.maximum(w0, 1); m1 = (np.sum(hist * mids) - np.cumsum(hist * mids)) / np.maximum(w1, 1)
    return mids[np.argmax(w0 * w1 * (m0 - m1) ** 2)]       # threshold that best separates two groups

def exg_mask(img):
    s = img.sum(2) + 1e-6
    exg = (2 * img[..., 1] - img[..., 0] - img[..., 2]) / s
    lab_, n = label(exg > otsu(exg))
    if n > 1:
        lab_ = lab_ == (np.argmax(np.bincount(lab_.ravel())[1:]) + 1)
    return binary_fill_holes(lab_ > 0)

def grey_out(X, masks):
    return np.where(masks[..., None], X, 0.5).astype(np.float32)

5. Knowing when to say "not sure"¶

Even the best model above makes many mistakes in the field. A deployed app can abstain: when its top softmax probability is below a threshold, it says "not sure" and sends the farmer to a person. This is selective classification (Geifman & El-Yaniv 2017). The accuracy–coverage curve shows the trade-off: coverage is the fraction of photos the app answers, accuracy is measured on those answered photos only. Softmax probabilities are not calibrated probabilities (Course 3 session 12), so the threshold must be chosen on field data, not taken at face value.

def accuracy_coverage(p, y):
    order = np.argsort(-p.max(1))                       # most confident first
    correct = (p.argmax(1) == y)[order]
    cov = np.arange(1, len(y) + 1) / len(y)
    return cov, np.cumsum(correct) / np.arange(1, len(y) + 1)

6. The real data (NOT RUN here)¶

PlantVillage (Hughes & Salathé 2015) is in TensorFlow Datasets as plant_village: 54,303 leaf images in 38 classes, with a single train split, so you must make your own test split. The first cell loads a sample as NumPy arrays. The second fine-tunes a small ImageNet-pretrained network with torchvision (transfer learning; Course 3 session 4 covers vision backbones). What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. Lab accuracy hides the field problem. The baseline CNN (6,292 parameters, 30 epochs) scored 0.978 on new lab photos but 0.398 on field photos, where chance is 0.250.
  2. Part of the drop is a background shortcut. When the same lab leaves were put on the next class's background, the baseline fell from 0.978 to 0.848, and for 0.152 of the leaves it predicted the class that owns that background. The rest of the field drop comes from everything else that changed: light, colour casts, blur, clutter, leaf size and position.
  3. Changing the training images helped. Background randomization kept lab accuracy (0.980), made the swap test harmless (0.965) and raised field accuracy to 0.537. Adding colour jitter and blur raised field accuracy to 0.740, but lab accuracy fell to 0.900: the model gave up cues that only work in the lab.
  4. Against expectation, the leaf mask did worse than background randomization. Field accuracy was 0.480 with the excess-green mask and 0.532 even with the true mask at test time. The excess-green mask keeps green pixels only, so its overlap (IoU) with the true leaf was 0.999 for healthy leaves but 0.485 for blight, whose yellow drying tissue is the symptom itself. The masked model recognized 0.27 of field blight photos, against 0.92 for the background-randomized model. In the field, grass and weeds are green too, and the mask IoU fell to 0.528.
  5. Abstaining helps a model that is roughly right, not a shortcut model. For the best model, answering only the 60% most confident field photos (top probability at least 0.81) raised accuracy from 0.740 to 0.827, and the 40% most confident gave 0.875. For the baseline, confidence hardly helped (0.398 at full coverage, 0.450 at 40%): a model that learned the wrong rule is confidently wrong.
