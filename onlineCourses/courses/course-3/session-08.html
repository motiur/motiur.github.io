1. Setup: the data and a distance to the data¶

The data are a 2-D swiss roll (a spiral), scaled to a spread of about 1 in each direction. Session 9 uses exactly the same function and the same distance, so you can compare diffusion with flow matching directly.

To score samples we use the sliced Wasserstein distance (SWD): project both point sets onto 500 random directions, sort each projection, and compare the sorted values. It is 0 for identical sets. Two independent samples of real data do not give exactly 0, so we print that noise floor first: no model can be expected to beat it.

import math, time
import numpy as np
import torch, torch.nn as nn, torch.nn.functional as F
import matplotlib.pyplot as plt
from sklearn.datasets import make_swiss_roll

torch.set_num_threads(1)                    # small models run fastest on one thread
torch.manual_seed(0); np.random.seed(0)

def swiss_roll_2d(n, seed):
    X, _ = make_swiss_roll(n_samples=n, noise=0.5, random_state=seed)
    return (X[:, [0, 2]] / 7.0).astype(np.float32)

def swd(a, b, n_proj=500, seed=0):
    rng = np.random.default_rng(seed); th = rng.standard_normal((2, n_proj)); th /= np.linalg.norm(th, axis=0)
    pa, pb = np.sort(np.asarray(a) @ th, axis=0), np.sort(np.asarray(b) @ th, axis=0)
    return float(np.sqrt(((pa - pb) ** 2).mean()))

Xtrain = torch.from_numpy(swiss_roll_2d(20000, 0)); Xtest = swiss_roll_2d(2000, 1)
floor = np.mean([swd(swiss_roll_2d(2000, s), Xtest) for s in [2, 3, 4]])
print(f"{len(Xtrain)} training points, {len(Xtest)} test points")
print(f"noise floor: SWD between two real samples of 2,000 points = {floor:.3f}")

2. The forward process and its closed form¶

We use $T = 100$ steps with a linear schedule, $\beta_t$ from 0.001 to 0.2. (Ho et al. 2020 used 0.0001 to 0.02 over 1,000 steps; ours has the same sum of the β values in fewer steps.) With $\alpha_t = 1 - \beta_t$ and $\bar\alpha_t = \prod_{s \le t} \alpha_s$:

  • one step: $x_t = \sqrt{\alpha_t}\, x_{t-1} + \sqrt{\beta_t}\, \varepsilon$
  • closed form: $x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \varepsilon$

The check below runs the one-step process 30 times and confirms that the result has the mean and spread the closed form predicts.

T = 100
betas = torch.linspace(1e-3, 0.2, T)
abar = torch.cat([torch.ones(1), torch.cumprod(1 - betas, 0)])        # abar[0] = 1 (clean data), abar[t] for t = 1..T
for t in [1, 10, 25, 50, 100]:
    print(f"t = {t:3d}: abar = {abar[t]:.5f}, signal coefficient {abar[t].sqrt():.3f}, noise coefficient {(1 - abar[t]).sqrt():.3f}")

3. Train a noise-prediction network (DDPM)¶

The network takes a noisy point $x_t$ and the time $t$ (as sine and cosine features) and predicts the noise $\varepsilon$ that was added. The loss is the simple DDPM loss $\|\varepsilon - \varepsilon_\theta(x_t, t)\|^2$ with $t$ drawn uniformly (Ho et al. 2020). The n_class option is used in section 5.

class Net(nn.Module):
    def __init__(self, h=128, n_freq=8, n_class=0):
        super().__init__()
        self.register_buffer("freqs", torch.exp(torch.linspace(0, math.log(200), n_freq)))
        self.cls = nn.Embedding(n_class + 1, 16) if n_class else None              # index n_class means "no label"
        self.net = nn.Sequential(nn.Linear(2 + 2 * n_freq + (16 if n_class else 0), h), nn.SiLU(),
                                 nn.Linear(h, h), nn.SiLU(), nn.Linear(h, h), nn.SiLU(), nn.Linear(h, 2))
    def forward(self, x, t, c=None):                                                # t in [0, 1]
        a = t[:, None] * self.freqs[None]
        feats = [x, torch.sin(a), torch.cos(a)] + ([self.cls(c)] if self.cls is not None else [])
        return self.net(torch.cat(feats, 1))

def train_ddpm(data, labels=None, n_class=0, steps=5000, B=512, lr=2e-3, seed=0, p_uncond=0.2):
    torch.manual_seed(seed); model = Net(n_class=n_class)
    opt = torch.optim.Adam(model.parameters(), lr=lr); sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, steps)
    for step in range(steps):
        i = torch.randint(0, len(data), (B,)); x0 = data[i]
        t = torch.randint(1, T + 1, (B,)); eps = torch.randn_like(x0)
        xt = abar[t].sqrt()[:, None] * x0 + (1 - abar[t]).sqrt()[:, None] * eps         # closed form: no simulation
        c = None
        if n_class:
            c = labels[i].clone(); c[torch.rand(B) < p_uncond] = n_class                 # condition dropout (section 5)
        loss = F.mse_loss(model(xt, t / T, c), eps)
        opt.zero_grad(); loss.backward(); opt.step(); sched.step()
    return model, loss.item()

t0 = time.time()
model, last_loss = train_ddpm(Xtrain)
print(f"trained in {time.time() - t0:.0f}s, final batch loss {last_loss:.3f}")

trained in 20s, final batch loss 0.255

4. Sampling: DDPM and DDIM with the same network¶

One function covers both samplers (Song, Meng & Ermon 2021). At each step it predicts the clean point $\hat x_0 = (x_t - \sqrt{1-\bar\alpha_t}\,\hat\varepsilon)/\sqrt{\bar\alpha_t}$ and jumps to an earlier time $s$:

$x_s = \sqrt{\bar\alpha_s}\,\hat x_0 + \sqrt{1 - \bar\alpha_s - \sigma^2}\,\hat\varepsilon + \sigma z$, with $\sigma = \eta \sqrt{(1-\bar\alpha_s)/(1-\bar\alpha_t)}\sqrt{1 - \bar\alpha_t/\bar\alpha_s}$.

  • $\eta = 1$ with all 100 steps is DDPM's ancestral sampler; with fewer steps it is its strided version.
  • $\eta = 0$ is DDIM: no noise is added after the start, so the sampler is a deterministic map from $x_T$ to $x_0$.

Because training only used $q(x_t \mid x_0)$, any subsequence of times works with the same network. We average the SWD over three sampling seeds.

@torch.no_grad()
def sample(model, n, n_steps, eta, seed=0, c=None, scale=None, n_class=0, x_start=None):
    g = torch.Generator().manual_seed(seed)
    ts = torch.linspace(T, 0, n_steps + 1).round().long()                # e.g. 100, 90, ..., 10, 0
    x = torch.randn(n, 2, generator=g) if x_start is None else x_start.clone()
    for t, s in zip(ts[:-1], ts[1:]):
        tt = torch.full((n,), t.item() / T)
        if scale is None:
            eps = model(x, tt, c)
        else:                                                             # classifier-free guidance (section 5)
            e_c, e_u = model(x, tt, c), model(x, tt, torch.full((n,), n_class))
            eps = e_u + scale * (e_c - e_u)
        x0_hat = (x - (1 - abar[t]).sqrt() * eps) / abar[t].sqrt()
        sigma = eta * ((1 - abar[s]) / (1 - abar[t])).sqrt() * (1 - abar[t] / abar[s]).sqrt()
        x = abar[s].sqrt() * x0_hat + (1 - abar[s] - sigma ** 2).clamp(min=0).sqrt() * eps + sigma * torch.randn(n, 2, generator=g)
    return x.numpy()

DDIM is a deterministic map from noise to data, so it can also be run backwards: encode real points into noise and decode them again (the probability-flow ODE view of Song et al. 2021). DDPM cannot do this, because it adds fresh noise at every step.

@torch.no_grad()
def ddim_invert(model, x0, n_steps=100):
    ts = torch.linspace(0, T, n_steps + 1).round().long(); x = x0.clone()
    for s, t in zip(ts[:-1], ts[1:]):                       # from less noise (s) to more noise (t)
        eps = model(x, torch.full((len(x),), max(s.item(), 1) / T))
        x0_hat = (x - (1 - abar[s]).sqrt() * eps) / abar[s].sqrt()
        x = abar[t].sqrt() * x0_hat + (1 - abar[t]).sqrt() * eps
    return x

pts = torch.from_numpy(Xtest[:500])
z = ddim_invert(model, pts)
back = torch.from_numpy(sample(model, 500, 100, 0.0, x_start=z))
print(f"encoded noise: mean {z.mean():.2f}, std {z.std():.2f} (should be close to 0 and 1)")
print(f"DDIM round trip data -> noise -> data: mean error {(back - pts).norm(dim=1).mean():.3f} (data spread is about 1)")
a, b = sample(model, 5, 20, 0.0, seed=7), sample(model, 5, 20, 0.0, seed=7)
print("same starting noise, DDIM twice: identical outputs?", np.allclose(a, b))

5. Classifier-free guidance on a three-class mixture¶

Three overlapping Gaussian clusters (spread 0.8, centres 1.5 from the origin). We know the true densities, so for any point we can compute the true class probability $p(c \mid x)$ exactly.

One network is trained with the class label, but 20% of the time the label is replaced by a "no label" token (condition dropout, Ho & Salimans 2022). At sampling time the two predictions are mixed with a guidance scale $s$:

$\tilde\varepsilon = \varepsilon(x, \varnothing) + s\,[\varepsilon(x, c) - \varepsilon(x, \varnothing)]$

$s = 0$ ignores the label, $s = 1$ is the plain conditional model, and $s > 1$ pushes harder toward the class. (Ho & Salimans write the same rule as $(1+w)\,\varepsilon(x,c) - w\,\varepsilon(x,\varnothing)$, so $s = 1 + w$.) We measure

  • class confidence: the mean true $p(c \mid x)$ of the samples (higher is more faithful to the label);
  • spread: the samples' standard deviation divided by the true 0.8 (1.0 is right; lower is less diverse);
  • off the data: the share of samples more than 3 standard deviations from their class centre (1.1% for real data).
K, R0, S0 = 3, 1.5, 0.8
centers = torch.tensor([[R0 * math.cos(a), R0 * math.sin(a)] for a in np.deg2rad([90, 210, 330])], dtype=torch.float32)
gen = torch.Generator().manual_seed(5)
labels = torch.randint(0, K, (20000,), generator=gen); Xc = centers[labels] + S0 * torch.randn(20000, 2, generator=gen)
def true_posterior(x):
    return torch.softmax(-((x[:, None] - centers[None]) ** 2).sum(-1) / (2 * S0 ** 2), dim=1)
print(f"real data: mean p(c|x) of the true class {true_posterior(Xc)[torch.arange(20000), labels].mean():.3f}")

t0 = time.time(); cmodel, _ = train_ddpm(Xc, labels, n_class=K)
print(f"conditional model trained in {time.time() - t0:.0f}s")

def guided(scale, n=1000, seed=1):
    out = []
    for c in range(K):
        xs = torch.tensor(sample(cmodel, n, 50, 0.0, seed=seed + c, c=torch.full((n,), c), scale=scale, n_class=K))
        out.append((c, xs))
    return out

print("scale   class confidence   spread   off the data")
cfg = {}
for scale in [0.0, 1.0, 2.0, 3.0, 5.0, 7.0]:
    res = guided(scale); cfg[scale] = res
    conf = np.mean([true_posterior(xs)[:, c].mean().item() for c, xs in res])
    spread = np.mean([xs.std(0).mean().item() / S0 for c, xs in res])
    off = np.mean([((xs - centers[c]).norm(dim=1) / S0 > 3).float().mean().item() for c, xs in res])
    print(f"{scale:5.1f}   {conf:16.3f}   {spread:6.2f}   {off:11.1%}")

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. The closed form is exact. Thirty single noising steps left a residual with mean 0.007 and standard deviation 1.004, as the closed form predicts. That is why training never simulates the chain: it jumps straight to any $t$.
  2. DDPM with all 100 steps came close to the data: SWD 0.063, against a noise floor of 0.046 for two real samples.
  3. Fewer steps cost quality for both samplers: at 10 steps DDPM scored 0.196 and DDIM 0.173; at 2 steps 0.623 and 0.640.
  4. Against expectation, DDIM was not clearly better than DDPM here. DDIM was slightly better at 10 and 20 steps (0.173 vs 0.196, 0.107 vs 0.113) and slightly worse at 5, 50 and 100 steps. The DDIM paper reports a large advantage for images at 10 to 50 steps; this 2-D problem, scored with SWD, did not reproduce it. One likely reason is that the extra noise left by a few-step DDPM sampler hurts image-quality scores much more than it hurts a 2-D distance, but we have not tested that here.
  5. What DDIM does give is a deterministic, invertible map. The same starting noise gave identical samples twice, and a round trip data → noise → data returned points with a mean error of 0.031 (the data spread is about 1). The encoded noise had standard deviation 0.95, close to the 1.0 it should have.
  6. Guidance trades diversity for faithfulness, then leaves the data. Scale 1 matched the real data (class confidence 0.861 against 0.863; spread 0.98; 1.0% of points beyond 3 standard deviations, against 1.1% expected). Scale 2 raised confidence to 0.993 and cut the spread to 0.75: more faithful, less diverse. From scale 3 upward the samples were pushed away from the other classes and off the data: 5.2% beyond 3 standard deviations at scale 3, 14.9% at 5 and 30.6% at 7. The spread number rises again at large scales because points scatter outward, not because diversity comes back. Scale 0 ignored the label (confidence 0.317, about one third).
  7. These are 2-D toy results with a small network. They show the mechanics, not the sizes of the effects in image models.
