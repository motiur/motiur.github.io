1. Setup: an image as a function¶

A coordinate network maps a pixel position $(x, y) \in [-1, 1]^2$ to a colour. We use scikit-learn's built-in photo, cropped to a square and averaged down to 64 × 64 pixels. Three quarters of the pixels are used for training; the other quarter, scattered across the image, tests how well each network fills in pixels it never saw. PSNR (peak signal-to-noise ratio) is $10 \log_{10}(1/\text{MSE})$ for colours in [0, 1]; higher is better, and +6 dB means the root-mean-square error is about halved.

import math, time
import numpy as np
import torch, torch.nn as nn, torch.nn.functional as F
import matplotlib.pyplot as plt
from sklearn.datasets import load_sample_image

torch.set_num_threads(1)                    # small models run fastest on one thread
torch.manual_seed(0)

img = load_sample_image("china.jpg")[21:405, 128:512] / 255.0                 # a 384 x 384 crop
img = img.reshape(64, 6, 64, 6, 3).mean((1, 3)).astype(np.float32)            # average 6 x 6 blocks -> 64 x 64
coords = torch.stack(torch.meshgrid(torch.linspace(-1, 1, 64), torch.linspace(-1, 1, 64), indexing="ij"), -1).view(-1, 2)
colors = torch.from_numpy(img).view(-1, 3)
perm = torch.randperm(4096, generator=torch.Generator().manual_seed(0)); tr, te = perm[:3072], perm[3072:]
psnr = lambda a, b: (10 * torch.log10(1 / F.mse_loss(a, b))).item()
print(f"image {img.shape}, {len(tr)} training pixels, {len(te)} held-out pixels")

image (64, 64, 3), 3072 training pixels, 1024 held-out pixels

2. ReLU, Fourier features and SIREN at the same step budget¶

  • ReLU MLP on raw $(x, y)$: 3 hidden layers of 128 units.
  • Fourier features (Tancik et al. 2020): first map $v \mapsto [\cos(2\pi B v), \sin(2\pi B v)]$ with 128 random frequencies $B \sim N(0, \sigma^2)$, then the same ReLU MLP. $\sigma$ sets the highest frequencies the network can easily represent; we try $\sigma = 1$ and $\sigma = 10$.
  • SIREN (Sitzmann et al. 2020): every layer is $\sin(\omega_0 (W x + b))$ with $\omega_0 = 30$ and the paper's special initialization, trained with its learning rate of $10^{-4}$.

Each model takes 500 full-batch Adam steps.

class ReLUMLP(nn.Module):
    def __init__(self, d_in=2, h=128, n_hidden=3):
        super().__init__(); layers = [nn.Linear(d_in, h), nn.ReLU()]
        for _ in range(n_hidden - 1): layers += [nn.Linear(h, h), nn.ReLU()]
        self.net = nn.Sequential(*layers, nn.Linear(h, 3))
    def forward(self, x): return self.net(x)

class FourierMLP(nn.Module):
    def __init__(self, sigma, m=128, h=128):
        super().__init__(); self.register_buffer("B", torch.randn(m, 2) * sigma); self.mlp = ReLUMLP(2 * m, h)
    def forward(self, x):
        proj = 2 * math.pi * x @ self.B.T
        return self.mlp(torch.cat([torch.cos(proj), torch.sin(proj)], 1))

class Sine(nn.Module):
    def __init__(self, d_in, d_out, w0=30.0, first=False):
        super().__init__(); self.w0, self.lin = w0, nn.Linear(d_in, d_out)
        bound = 1 / d_in if first else math.sqrt(6 / d_in) / w0          # SIREN initialization
        nn.init.uniform_(self.lin.weight, -bound, bound)
    def forward(self, x): return torch.sin(self.w0 * self.lin(x))

class Siren(nn.Module):
    def __init__(self, h=128, n_hidden=3):
        super().__init__()
        self.net = nn.Sequential(Sine(2, h, first=True), *[Sine(h, h) for _ in range(n_hidden - 1)])
        self.out = nn.Linear(h, 3); nn.init.uniform_(self.out.weight, -math.sqrt(6 / h) / 30, math.sqrt(6 / h) / 30)
    def forward(self, x): return self.out(self.net(x))

def fit(model, lr, steps=500):
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for step in range(steps):
        loss = F.mse_loss(model(coords[tr]), colors[tr]); opt.zero_grad(); loss.backward(); opt.step()
    with torch.no_grad(): out = model(coords)
    return out, psnr(out[tr], colors[tr]), psnr(out[te], colors[te])

t0 = time.time(); fits = {}
for name, make, lr in [("ReLU MLP", lambda: ReLUMLP(), 1e-3), ("Fourier, sigma 1", lambda: FourierMLP(1.0), 1e-3),
                       ("Fourier, sigma 10", lambda: FourierMLP(10.0), 1e-3), ("SIREN", lambda: Siren(), 1e-4)]:
    torch.manual_seed(0); out, p_tr, p_te = fit(make(), lr); fits[name] = out
    print(f"{name:18s} training pixels PSNR {p_tr:5.2f} dB | held-out pixels PSNR {p_te:5.2f} dB")
print(f"four networks fitted in {time.time() - t0:.0f}s")

3. Volume rendering in a 2-D world¶

A full NeRF needs posed photographs and hours on a GPU. The same mathematics works one dimension lower: a flat world of coloured discs, cameras on a circle around it, and 1-D images (a row of 64 pixels per camera). Each pixel is a ray $r(t) = o + t\,d$. With samples $t_1 < \dots < t_N$ spaced $\delta$ apart, density $\sigma_i$ and colour $c_i$ at each sample, volume rendering (Mildenhall et al. 2020) gives

$C = \sum_i T_i\,\alpha_i\,c_i + T_{N+1}\,c_{\text{background}}$, with $\alpha_i = 1 - e^{-\sigma_i \delta}$ and $T_i = \prod_{j<i} (1 - \alpha_j) = e^{-\sum_{j<i} \sigma_j \delta}$.

$\alpha_i$ is the chance that the ray stops in segment $i$, $T_i$ the chance that it gets that far, and the background (white here) receives what is left. Every operation is differentiable, so the field can be trained from images alone. The ground-truth images are rendered from the true scene with 1,024 samples per ray.

DISCS = torch.tensor([[-0.35, 0.15, 0.30, 0.90, 0.15, 0.15],          # centre x, centre y, radius, red, green, blue
                      [0.35, 0.30, 0.22, 0.15, 0.75, 0.25],
                      [0.10, -0.40, 0.25, 0.15, 0.30, 0.90]])
SIGMA_IN, BG = 25.0, torch.ones(3)                                    # density inside a disc; white background

def true_field(p):                                                    # p: (..., 2) -> density (...), colour (..., 3)
    inside = ((p[..., None, :] - DISCS[:, :2]).norm(dim=-1) < DISCS[:, 2]).float()
    col = (inside[..., None] * DISCS[:, 3:]).sum(-2) / inside.sum(-1, keepdim=True).clamp(min=1)
    return SIGMA_IN * inside.sum(-1), col

def cameras(angles_deg, radius=2.0, fov_deg=44, W=64):                # cameras on a circle, looking at the centre
    a = torch.deg2rad(torch.tensor(angles_deg, dtype=torch.float32))
    pos = radius * torch.stack([torch.cos(a), torch.sin(a)], 1); fwd = -pos / radius
    phi = torch.deg2rad(torch.linspace(-fov_deg / 2, fov_deg / 2, W)); c, s = torch.cos(phi), torch.sin(phi)
    dirs = torch.stack([c[None] * fwd[:, :1] - s[None] * fwd[:, 1:], s[None] * fwd[:, :1] + c[None] * fwd[:, 1:]], -1)
    return pos[:, None].expand(-1, W, -1).reshape(-1, 2), dirs.reshape(-1, 2)

def render(field, origins, dirs, n_samples, t_near=1.0, t_far=3.0, stratified=False):
    delta = (t_far - t_near) / n_samples
    t = torch.linspace(t_near, t_far, n_samples + 1)[:-1].expand(len(origins), n_samples)
    t = t + (torch.rand_like(t) if stratified else 0.5) * delta           # a random point in each bin, or its centre
    sigma, col = field(origins[:, None] + t[..., None] * dirs[:, None])
    alpha = 1 - torch.exp(-sigma * delta)
    T = torch.cumprod(torch.cat([torch.ones(len(origins), 1), 1 - alpha[:, :-1] + 1e-10], 1), 1)
    w = T * alpha                                                         # weight of each sample in the pixel colour
    return (w[..., None] * col).sum(1) + (1 - w.sum(1, keepdim=True)) * BG, w, t

train_angles = [float(a) for a in range(0, 360, 18)]                     # 20 training cameras, 18 degrees apart
test_angles = [9.0, 99.0, 189.0, 279.0]                                  # 4 held-out cameras, halfway between
o_tr, d_tr = cameras(train_angles); o_te, d_te = cameras(test_angles)
with torch.no_grad():
    C_tr = render(true_field, o_tr, d_tr, 1024)[0]; C_te = render(true_field, o_te, d_te, 1024)[0]
print(f"{len(train_angles)} training views and {len(test_angles)} held-out views, 64 pixels each")
print(f"share of training pixels whose ray misses every disc (pure background): {(C_tr == 1).all(1).float().mean():.2f}")

4. Fit a radiance field, with and without positional encoding¶

The field is a small MLP from a point $p = (x, y)$ to a density (softplus times 10, so it can reach large values quickly) and a colour (sigmoid). There is no view direction, because our discs look the same from every side. NeRF's positional encoding maps each coordinate to $(\sin(2^k \pi p), \cos(2^k \pi p))$ for $k = 0, \dots, L-1$; we use $L = 6$. Each step renders 128 random training rays with 32 jittered samples per ray, compares the colours with the training images, and backpropagates through the rendering.

class Field(nn.Module):
    def __init__(self, L=6, h=64, encode=True):
        super().__init__(); self.L, self.encode = L, encode
        self.net = nn.Sequential(nn.Linear(2 + 4 * L if encode else 2, h), nn.ReLU(), nn.Linear(h, h), nn.ReLU(),
                                 nn.Linear(h, h), nn.ReLU(), nn.Linear(h, 4))
    def forward(self, p):
        x = p
        if self.encode:
            ang = p[..., None] * (2.0 ** torch.arange(self.L)) * math.pi            # (..., 2, L)
            x = torch.cat([p, torch.sin(ang).flatten(-2), torch.cos(ang).flatten(-2)], -1)
        out = self.net(x)
        return 10 * F.softplus(out[..., 0]), torch.sigmoid(out[..., 1:])

def train_field(encode, steps=1000, B=128, n_samples=32):
    torch.manual_seed(0); field = Field(encode=encode)
    opt = torch.optim.Adam(field.parameters(), lr=5e-3); sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, steps)
    for step in range(steps):
        i = torch.randint(0, len(o_tr), (B,))
        loss = F.mse_loss(render(field, o_tr[i], d_tr[i], n_samples, stratified=True)[0], C_tr[i])
        opt.zero_grad(); loss.backward(); opt.step(); sched.step()
    return field

t0 = time.time(); fields, renders = {}, {}
for name, encode in [("positional encoding", True), ("raw coordinates", False)]:
    fields[name] = train_field(encode)
    with torch.no_grad():
        p_tr = render(fields[name], o_tr, d_tr, 128)[0]; renders[name] = render(fields[name], o_te, d_te, 128)
    print(f"{name:20s} training views PSNR {psnr(p_tr, C_tr):5.2f} dB | held-out views PSNR {psnr(renders[name][0], C_te):5.2f} dB")
print(f"two fields trained in {time.time() - t0:.0f}s")

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. Spectral bias is real. After the same 500 steps, the ReLU MLP was blurry (20.54 dB on held-out pixels, 21.21 dB on training pixels), while Fourier features with $\sigma = 1$ and SIREN reached 24.45 and 24.61 dB on held-out pixels.
  2. Too much bandwidth overfits. Fourier features with $\sigma = 10$ fitted the training pixels best (42.81 dB) but gave only 10.41 dB on the held-out pixels: it memorized each pixel and filled the gaps with high-frequency noise. The scale $\sigma$ must match the detail in the signal.
  3. Positional encoding made the radiance field work. With it, the field reached 39.28 dB on training views and 26.85 dB on the four held-out views; with raw coordinates it stayed blurry at 19.93 and 19.72 dB. The same spectral bias appears inside NeRF.
  4. The weights along the central ray peak where the ray enters the blue disc, in the same place for the learned and the true scene, and sum to 1.000, so no background shows through an opaque disc. 24% of the training pixels see only background.
  5. The inside of each learned disc is patchy. Rendering only depends on what the cameras can see, so the images constrain the surfaces but not the inside of opaque objects. This is one reason a radiance field is not a mesh: surfaces must be extracted from it.
  6. This is a 2-D world with 1-D images, known camera positions, no view-dependent colour and 20 cameras. A real NeRF works in 3-D, needs camera poses from structure-from-motion, and trains for much longer.
