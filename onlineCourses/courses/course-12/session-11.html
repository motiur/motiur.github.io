1. A test set with groups¶

A sign recognizer (sessions 4–6) is tested on 1,370 recorded signs. Most come from right-handed adults, because they were easiest to recruit; fewer come from left-handed adults, older adults and children, and some videos were filmed in dim light. The data are synthetic: each group's true accuracy is set in the code, so we can check whether our methods recover it. A real evaluation would use a test set recorded, with consent, together with partners from each group.

Before running the cell: what will the overall accuracy hide?

import time
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

t_start = time.time()
rng = np.random.default_rng(0)

# group: (number of test signs, true accuracy). Synthetic: chosen to look like an unbalanced real test set.
GROUPS = {"adult, right-handed": (1000, 0.92), "adult, left-handed": (120, 0.85), "older adult": (150, 0.88),
          "child": (60, 0.80), "dim light": (40, 0.74)}
N_CLASSES = 20
rows = []
for g, (n, acc) in GROUPS.items():
    truth = rng.integers(0, N_CLASSES, n)
    correct = rng.random(n) < acc
    wrong = (truth + rng.integers(1, N_CLASSES, n)) % N_CLASSES          # a different class when the model is wrong
    rows.append(pd.DataFrame({"group": g, "truth": truth, "pred": np.where(correct, truth, wrong)}))
test = pd.concat(rows, ignore_index=True)
test["correct"] = test["truth"] == test["pred"]

print(f"{len(test)} test signs; overall accuracy {test['correct'].mean():.3f}")
print(test.groupby("group", sort=False)["correct"].agg(n="size", accuracy="mean").round(3).to_string())

2. Accuracy per group, with bootstrap intervals¶

An accuracy measured on 40 examples is much less certain than one measured on 1,000. The percentile bootstrap (Course 2 session 7) resamples each group's test results with replacement many times, recomputes the accuracy each time, and takes the 2.5th and 97.5th percentiles as a 95% interval. Since the data are synthetic, we can also check whether each interval contains the true accuracy.

def bootstrap_ci(x, B=5000, rng=rng):
    x = np.asarray(x, float)
    means = x[rng.integers(0, len(x), size=(B, len(x)))].mean(axis=1)
    return np.percentile(means, [2.5, 97.5])

summary = []
for g, (n, true_acc) in GROUPS.items():
    c = test.loc[test["group"] == g, "correct"].to_numpy()
    lo, hi = bootstrap_ci(c)
    summary.append((g, n, c.mean(), lo, hi, true_acc))
    print(f"{g:20s} n = {n:4d}: accuracy {c.mean():.3f}, 95% interval {lo:.3f} to {hi:.3f} (width {hi - lo:.3f}); "
          f"true value {true_acc:.2f} {'inside' if lo <= true_acc <= hi else 'OUTSIDE'}")
lo, hi = bootstrap_ci(test["correct"].to_numpy())
print(f"{'overall':20s} n = {len(test):4d}: accuracy {test['correct'].mean():.3f}, 95% interval {lo:.3f} to {hi:.3f}")

fig, ax = plt.subplots(figsize=(7.5, 3.2))
for i, (g, n, a, l, h, t) in enumerate(summary):
    ax.errorbar(a, i, xerr=[[a - l], [h - a]], fmt="o", color="C0", capsize=4)
    ax.plot(t, i, "kx")
ax.axvline(test["correct"].mean(), color="C1", ls="--", label="overall accuracy")
ax.set_yticks(range(len(summary))); ax.set_yticklabels([f"{s[0]} (n={s[1]})" for s in summary], fontsize=8)
ax.invert_yaxis(); ax.set_xlabel("accuracy (dot: measured, bar: 95% bootstrap interval, x: true value)")
ax.set_title("the overall number hides the groups, and small groups are uncertain", fontsize=10); ax.legend(fontsize=8)
plt.tight_layout(); plt.show()

3. How many test examples does a fair comparison need?¶

Suppose the recognizer is truly 90% accurate for one group and 85% for another: a 5-point gap. With how many test examples per group would we reliably detect that gap? We simulate many evaluations for each sample size, run a two-sided test of the difference between two proportions at the 5% level each time, and count how often it finds the gap: the power. A common target is 80%. The normal-approximation formula for the sample size per group is

$$n \approx \frac{(z_{0.975} + z_{0.8})^2\,[p_1(1-p_1) + p_2(1-p_2)]}{(p_1 - p_2)^2}.$$

from scipy import stats

p1, p2, sims = 0.90, 0.85, 4000
z_a, z_b = stats.norm.ppf(0.975), stats.norm.ppf(0.80)
n_formula = (z_a + z_b) ** 2 * (p1 * (1 - p1) + p2 * (1 - p2)) / (p1 - p2) ** 2
sizes = [50, 100, 200, 400, 700, 1000, 1500]
power = []
sim_rng = np.random.default_rng(1)
for n in sizes:
    a, b = sim_rng.binomial(n, p1, sims) / n, sim_rng.binomial(n, p2, sims) / n
    pooled = (a + b) / 2
    z = (a - b) / np.sqrt(pooled * (1 - pooled) * 2 / n)
    power.append(np.mean(np.abs(z) > z_a))
for n, pw in zip(sizes, power):
    print(f"{n:5d} test examples per group: the gap is detected in {pw:.3f} of {sims} simulated evaluations")
print(f"formula: about {n_formula:.0f} per group for 80% power; the 'child' group above has 60, the 'dim light' group 40")

plt.figure(figsize=(6.5, 3.2))
plt.plot(sizes, power, "o-")
plt.axhline(0.8, color="0.5", ls=":", lw=1); plt.axvline(n_formula, color="C1", ls="--", lw=1, label=f"formula: {n_formula:.0f}")
plt.xlabel("test examples per group"); plt.ylabel("power (share of evaluations that detect the gap)")
plt.title("detecting a 90% vs 85% gap needs hundreds of examples per group", fontsize=10); plt.legend(fontsize=8)
plt.tight_layout(); plt.show()

4. The System Usability Scale¶

Accuracy is not experience. After users try a system, the System Usability Scale (SUS; Brooke 1996) asks ten questions, answered from 1 (strongly disagree) to 5 (strongly agree). Odd items are positive ("I thought the system was easy to use") and even items negative ("I found the system unnecessarily complex"). The score is

$$\text{SUS} = 2.5 \times \Big[\sum_{\text{odd}} (\text{answer} - 1) + \sum_{\text{even}} (5 - \text{answer})\Big],$$

from 0 to 100. It is not a percentage. We simulate 12 participants who each try two versions of a caption app (session 3), and compare them with a paired bootstrap, because the same people rated both. The questions themselves must be accessible: in Bangla, in sign language for Deaf participants, and readable by a screen reader.

def sus_score(answers):
    answers = np.asarray(answers)
    return 2.5 * ((answers[..., 0::2] - 1).sum(-1) + (5 - answers[..., 1::2]).sum(-1))

print("by hand: all answers 3 gives", sus_score([3] * 10), "; the best possible answers give", sus_score([5, 1] * 5))

sus_rng = np.random.default_rng(2)
n_people = 12
liking = sus_rng.normal(0, 0.8, n_people)                       # some people like apps more than others
def answer_sheet(effect):
    lean = liking[:, None] + effect + sus_rng.normal(0, 0.7, (n_people, 10))
    sign = np.tile([1, -1], 5)                                    # agree with positive items, disagree with negative ones
    return np.clip(np.round(3 + sign * lean), 1, 5).astype(int)
sus_a, sus_b = sus_score(answer_sheet(0.0)), sus_score(answer_sheet(0.5))   # version B is truly a little better
diff = sus_b - sus_a
boot = diff[sus_rng.integers(0, n_people, size=(5000, n_people))].mean(axis=1)
print(f"version A: mean SUS {sus_a.mean():.1f}; version B: {sus_b.mean():.1f}")
print(f"paired difference B - A: {diff.mean():.1f} points, 95% bootstrap interval {np.percentile(boot, 2.5):.1f} to {np.percentile(boot, 97.5):.1f}")
print("individual differences:", diff.astype(int).tolist())

5. A per-group error report¶

A short table like this belongs in every report and model card (Mitchell et al. 2019): each group, its number of test examples, its accuracy with an interval, its gap to the best-served group, and a note when the interval is too wide to say much. The groups should be chosen with users and partners, not only by the developer.

report = pd.DataFrame(summary, columns=["group", "test examples", "accuracy", "low", "high", "true"]).drop(columns="true")
best = report["accuracy"].max()
report["95% interval"] = report.apply(lambda r: f"{r['low']:.3f} to {r['high']:.3f}", axis=1)
report["gap to best"] = (report["accuracy"] - best).round(3)
report["note"] = np.where(report["high"] - report["low"] > 0.10, "interval wider than 10 points: collect more data", "")
report["accuracy"] = report["accuracy"].round(3)
print(report[["group", "test examples", "accuracy", "95% interval", "gap to best", "note"]].to_string(index=False))
worst = report.loc[report["accuracy"].idxmin()]
print(f"\noverall accuracy {test['correct'].mean():.3f}; worst group '{worst['group']}' {worst['accuracy']:.3f} "
      f"({worst['95% interval']}), on only {worst['test examples']} examples")
print(f"runtime so far {time.time() - t_start:.0f} s")

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. The overall number hides the groups. Overall accuracy was 0.907 (interval 0.891 to 0.923), but that is mostly the right-handed adults, 1,000 of the 1,370 test signs, who measured 0.930. Every other group measured lower: left-handed adults 0.842, older adults 0.853, children 0.817 and dim light 0.875.
  2. Small groups are uncertain. The 95% interval was 0.031 wide for 1,000 examples, but 0.133 for 120, 0.113 for 150 and 0.200 for both 60 and 40. The report flags four of the five groups for more data.
  3. Against what we built in, the truly worst group looked fine. The dim-light group's true accuracy is 0.74, yet its 40 examples measured 0.875, and its interval (0.775 to 0.975) missed the truth. Each 95% interval misses about one time in 20, so with five groups the chance that at least one misses is $1 - 0.95^5 \approx 0.23$. On this run the report named children (0.817) as the worst-served group. Small test sets can hide exactly the people a system fails.
  4. Detecting a 5-point gap needs hundreds of examples per group. With 50 per group, a test found the 90% against 85% gap in only 0.119 of the simulated evaluations; with 400, 0.575; with 700, 0.804, matching the formula's 683; with 1,000, 0.920. The child and dim-light groups (60 and 40 examples) are about ten times too small to compare reliably.
  5. Usability is measured on people, and averages hide them too. All-neutral answers give a SUS of 50 and the best answers 100. Version B scored 63.1 against 51.9 for A, a paired difference of 11.2 points (interval 6.9 to 15.8), yet one of the 12 participants rated B lower (a difference of −2). Ask that person why.
