The 2026 paper¶

Chen, Chewi, Daskalakis and Rakhlin, High-Accuracy Sampling for Diffusion Models and Log-Concave Distributions (ICML 2026 Outstanding Paper). For diffusion models with accurate score estimates, and for log-concave distributions using only gradient evaluations, they give samplers that reach accuracy δ in a number of steps that grows like polylog(1/δ) instead of a power of 1/δ. Their tool is First-Order Rejection Sampling (FORS), which imitates rejection sampling while using only gradient queries.

This lab is a toy illustration, not a reproduction, and it does not implement FORS. It shows the problem FORS solves: the unadjusted Langevin algorithm (ULA) has a bias that only a smaller step can reduce; the Metropolis-adjusted Langevin algorithm (MALA) removes the bias but needs density values, which a diffusion model does not provide; and rejection sampling is exact but needs density values and a bound, and becomes very slow in high dimension.

1. Two log-concave targets in 2-D¶

A density $\pi(x) \propto e^{-f(x)}$ is log-concave when $f$ is convex. Target A is a correlated Gaussian, $f(x) = \frac12 x^TAx$ with covariance $\Sigma = A^{-1}$; its variances along the two principal directions are 1.9 and 0.1, so it is narrow in one direction (condition number 19). Target B adds a convex softplus term, which makes it skewed and non-Gaussian; we get its exact mean and covariance by numerical integration on a fine grid.

import time
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)
Sigma = np.array([[1.0, 0.9], [0.9, 1.0]])
A = np.linalg.inv(Sigma)
lam, V = np.linalg.eigh(A)                       # curvatures: 0.526 (wide direction) and 10 (narrow direction)
var_true = 1 / lam                               # true variances along the principal directions: 1.9 and 0.1
fA = lambda x: 0.5 * np.sum((x @ A) * x, axis=1)
gA = lambda x: x @ A
print(f"target A: curvatures {np.round(lam, 3)}, variances {np.round(var_true, 3)}, condition number {lam[1] / lam[0]:.0f}")

B = np.array([[1.0, 0.5], [0.5, 1.0]])
c = np.array([3.0, 1.0])
softplus = lambda z: np.logaddexp(0.0, z)
sigmoid = lambda z: 1.0 / (1.0 + np.exp(-z))
fB = lambda x: 0.5 * np.sum((x @ B) * x, axis=1) + softplus(x @ c)
gB = lambda x: x @ B + sigmoid(x @ c)[:, None] * c

grid = np.linspace(-8, 8, 1601)
G1, G2 = np.meshgrid(grid, grid, indexing="ij")
pts = np.stack([G1.ravel(), G2.ravel()], axis=1)
wts = np.exp(-fB(pts) - np.max(-fB(pts)))
Z_grid = wts.sum()
wts /= Z_grid
mean_B = wts @ pts
cov_B = (pts - mean_B).T @ ((pts - mean_B) * wts[:, None])
print(f"target B (by numerical integration): mean {np.round(mean_B, 4)}, covariance {np.round(cov_B, 4).tolist()}")

2. The unadjusted Langevin algorithm and its bias¶

ULA discretizes the Langevin diffusion: $x \leftarrow x - h\nabla f(x) + \sqrt{2h}\,\xi$ with $\xi \sim N(0, I)$. It needs only gradients, but its stationary distribution is not exactly $\pi$. For target A the stationary covariance can be computed exactly: $\Sigma_h = (A - \tfrac{h}{2}A^2)^{-1}$, so along a direction with curvature $\lambda$ the variance is inflated by the factor $1/(1 - h\lambda/2)$. The narrow direction ($\lambda = 10$) suffers most.

We run 10,000 independent chains from $N(0, 4I)$ and measure the worst relative error of the two principal variances. The dashed lines are the exact theory for ULA on target A.

N_CHAINS = 10000
CHECKS = np.unique(np.round(np.geomspace(1, 2000, 40)).astype(int))

def principal_error(x):
    # worst relative error of the variances along target A's two principal directions
    v = np.var(x @ V, axis=0)
    return np.max(np.abs(v / var_true - 1))

def ula(grad, h, steps, seed=0, track=None):
    rng = np.random.default_rng(seed)
    x = 2.0 * rng.standard_normal((N_CHAINS, 2))
    errs = []
    for k in range(1, steps + 1):
        x = x - h * grad(x) + np.sqrt(2 * h) * rng.standard_normal(x.shape)
        if track is not None and k in CHECKS:
            errs.append(track(x))
    return x, np.array(errs)

def ula_theory(h, ks):
    s_h = 1 / (lam * (1 - h * lam / 2))                     # stationary variances of ULA
    s_k = s_h + (1 - h * lam)[None, :] ** (2 * ks[:, None]) * (4.0 - s_h)
    return np.max(np.abs(s_k / var_true - 1), axis=1)

t0 = time.time()
ula_runs = {}
LATE = CHECKS >= 500                                       # checkpoints from step 500 to 2,000
print(f"Monte Carlo noise: a variance estimated from {N_CHAINS} chains has relative standard error about {np.sqrt(2 / N_CHAINS):.3f}")
print(" h      narrow variance (theory, sim)   wide variance (theory, sim)   error floor (median, steps 500-2,000)")
for h in [0.01, 0.03, 0.1, 0.15]:
    x, errs = ula(gA, h, 2000, track=principal_error)
    ula_runs[h] = errs
    s_h = 1 / (lam * (1 - h * lam / 2))
    v = np.var(x @ V, axis=0)
    print(f"{h:5.2f}   {s_h[1]:8.4f} {v[1]:8.4f}               {s_h[0]:8.4f} {v[0]:8.4f}             {np.median(errs[LATE]):.3f}")
print(f"true:   {var_true[1]:8.4f}                        {var_true[0]:8.4f}      ({time.time() - t0:.0f} s)")

3. MALA: a Metropolis correction removes the bias¶

MALA uses the ULA step as a proposal $y$ and accepts it with probability $\min\Big(1, \dfrac{\pi(y)\,q(x \mid y)}{\pi(x)\,q(y \mid x)}\Big)$, where $q(y \mid x) = N(y;\, x - h\nabla f(x),\, 2hI)$. This makes $\pi$ exactly stationary for any step size $h$. The price: the ratio $\pi(y)/\pi(x) = e^{f(x) - f(y)}$ needs values of $f$, not just gradients. A diffusion model only gives the score (a gradient), so MALA cannot be used there directly.

def mala(f, grad, h, steps, seed=0, track=None):
    rng = np.random.default_rng(seed)
    x = 2.0 * rng.standard_normal((N_CHAINS, 2))
    fx, gx = f(x), grad(x)
    errs, accepted = [], 0.0
    for k in range(1, steps + 1):
        y = x - h * gx + np.sqrt(2 * h) * rng.standard_normal(x.shape)
        fy, gy = f(y), grad(y)
        log_ratio = (fx - fy
                     - np.sum((x - y + h * gy) ** 2, axis=1) / (4 * h)     # log q(x | y)
                     + np.sum((y - x + h * gx) ** 2, axis=1) / (4 * h))    # minus log q(y | x)
        ok = np.log(rng.random(len(x))) < log_ratio
        x = np.where(ok[:, None], y, x)
        fx, gx = np.where(ok, fy, fx), np.where(ok[:, None], gy, gx)
        accepted += ok.mean()
        if track is not None and k in CHECKS:
            errs.append(track(x))
    return x, np.array(errs), accepted / steps

t0 = time.time()
_, mala_errs, acc = mala(fA, gA, 0.15, 2000, track=principal_error)
print(f"MALA h = 0.15: acceptance rate {acc:.3f}, error floor (median, steps 500-2,000) {np.median(mala_errs[LATE]):.3f}")
_, errs_03, acc_03 = mala(fA, gA, 0.3, 500, track=principal_error)
print(f"MALA h = 0.30: acceptance rate {acc_03:.3f}, error after 500 steps {errs_03[-1]:.3f}  (h above 2/10: proposals overshoot)")

def first_below(errs, level):
    hit = np.nonzero(np.array(errs) < level)[0]
    return CHECKS[hit[0]] if len(hit) else None
for name, errs in [(f"ULA h = {h}", e) for h, e in ula_runs.items()] + [("MALA h = 0.15", mala_errs)]:
    k = first_below(errs, 0.10)
    print(f"{name:15s} first checkpoint with error below 10%: {k if k else 'never (within 2,000 steps)'}")
print(f"({time.time() - t0:.0f} s)")

plt.figure(figsize=(8, 3.5))
for i, (h, errs) in enumerate(ula_runs.items()):
    if h == 0.15:
        continue
    plt.loglog(CHECKS, errs, color=f"C{i}", label=f"ULA h = {h}")
    plt.loglog(CHECKS, ula_theory(h, CHECKS), color=f"C{i}", ls="--", lw=1)
plt.loglog(CHECKS, mala_errs, color="k", lw=2, label="MALA h = 0.15")
plt.axhline(np.sqrt(2 / N_CHAINS), color="gray", ls=":", label="Monte Carlo noise level")
plt.xlabel("steps"); plt.ylabel("worst relative variance error")
plt.title("Target A: ULA stalls at a bias floor, MALA does not (dashed: ULA theory)")
plt.legend(); plt.grid(alpha=0.3); plt.show()

5. Rejection sampling: exact, but at what cost?¶

Draw $x$ from a proposal $g$ and accept it with probability $\tilde\pi(x)/(M g(x))$, where $\tilde\pi = e^{-f}$ and $M \ge \max_x \tilde\pi(x)/g(x)$. Accepted points are exact samples. The acceptance rate is $Z/M$, where $Z = \int \tilde\pi$. It needs density values and a valid bound $M$.

s = 1.5                                                   # proposal N(0, s^2 I)
log_g = lambda x: -0.5 * np.sum(x ** 2, axis=1) / s**2 - np.log(2 * np.pi * s**2)
log_M = np.max(-fB(pts) - log_g(pts))                     # bound found on the grid
rng = np.random.default_rng(1)
prop = s * rng.standard_normal((200000, 2))
keep = np.log(rng.random(len(prop))) < (-fB(prop) - log_g(prop) - log_M)
samples = prop[keep]
Z = Z_grid * np.exp(np.max(-fB(pts))) * (grid[1] - grid[0]) ** 2
print(f"acceptance rate {keep.mean():.4f}   theory Z/M = {Z / np.exp(log_M):.4f}   accepted {len(samples)} samples")
print(f"mean error {np.round(samples.mean(0) - mean_B, 4)}   covariance error {np.linalg.norm(np.cov(samples.T) - cov_B):.4f}")

# In d dimensions: target N(0, I_d), proposal N(0, 1.2^2 I_d). Then M = 1.2^d and the acceptance rate is 1.2^(-d).
print("\n dimension   acceptance (simulated)   acceptance (theory 1.2^-d)")
for dim in [1, 2, 5, 10, 20]:
    zz = 1.2 * rng.standard_normal((200000, dim))
    accept_prob = np.exp(-0.5 * np.sum(zz**2, axis=1) * (1 - 1 / 1.2**2))    # pi(z) / (M g(z)) with M = 1.2^d
    acc_d = np.mean(rng.random(len(zz)) < accept_prob)
    print(f"{dim:10d}   {acc_d:22.4f}   {1.2 ** -dim:24.4f}")
for dim in [50, 100]:
    print(f"{dim:10d}   {'(not simulated)':>22s}   {1.2 ** -dim:24.2e}")

6. What the cost of accuracy looks like¶

For ULA on target A we can work out the cost exactly. To make the bias in the narrow direction at most δ we need $h\lambda_{\max}/(2 - h\lambda_{\max}) \le \delta$, so $h \approx 2\delta/\lambda_{\max}$. Then the wide direction needs about $\ln(1/\delta)/(2h\lambda_{\min})$ steps to forget the start. So the step count grows like $(1/\delta)\ln(1/\delta)$: a power of $1/\delta$. For MALA, Dwivedi et al. (2019) proved a bound that grows only like $\log(1/\delta)$ for strongly log-concave targets, from a warm start; FORS reaches polylog(1/δ) with gradients alone.

print("  delta      ULA step size h    ULA steps needed     (ln 1/delta)^2")
for delta in [1e-1, 1e-2, 1e-3, 1e-4, 1e-6]:
    h = 2 * delta / (lam[1] * (1 + delta))                 # bias in the narrow direction equals delta
    k = np.log(1.1 / delta) / (-2 * np.log(1 - h * lam[0]))  # start error 1.1 in the wide direction shrinks to delta
    print(f"{delta:8.0e}   {h:14.2e}   {k:16.3g}   {np.log(1 / delta) ** 2:14.1f}")

What to notice¶

  • ULA's bias is real and predictable. At h = 0.1 the variance along the narrow direction settled at 0.2003 (theory 0.2000, truth 0.1). The error floors were 0.047, 0.177, 0.999 and 2.998 for h = 0.01, 0.03, 0.1 and 0.15, close to the exact values 5.3%, 17.6%, 100% and 300%.
  • MALA removes the bias. At h = 0.15, where ULA is off by 300%, MALA's error floor was 0.015, the Monte Carlo noise level for 10,000 chains (0.014). MALA was below 10% error by step 23; ULA got there only with h = 0.01, at step 234, and never with larger steps.
  • Unbiased is not the same as fast. At h = 0.3 (above 2/10, the stability limit of the narrow direction) MALA accepted only 20.2% of proposals and was still at error 30.8 after 500 steps, because chains far from the centre almost never move.
  • On the skewed target the bias also moves the mean. ULA at h = 0.2 shifted the mean of $x_1$ by −0.0388, more than four times the Monte Carlo noise of about 0.009, and the covariance by 0.19 (Frobenius norm). MALA's errors were 0.0157 (under two noise standard deviations) and 0.0166.
  • Rejection sampling is exact but scales badly. Its acceptance rate, 0.2988, matched Z/M = 0.2977, and its samples matched the target. With a Gaussian proposal only 1.2 times wider than the target, acceptance falls as $1.2^{-d}$: 0.0262 at d = 20 and about 1e-8 at d = 100.
  • The cost of accuracy. For ULA on target A, the steps needed grow like a power of 1/δ: about 125 for δ = 0.1, 2,250 for 0.01 and 442,000 for 1e-4, while $(\ln 1/\delta)^2$ is only 85 at δ = 1e-4. That gap is what polylog(1/δ) samplers close. We did not implement FORS; this notebook only shows the problem it solves.
  • A single checkpoint can look better than it is: MALA's error happened to be 0.0003 at step 2,000, far below the noise level, so the notebook reports medians over many checkpoints.
