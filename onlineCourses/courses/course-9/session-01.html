1. The 2026 work behind this lab¶

This session is about the year as a whole rather than one paper: the 2026 conference awards (ICLR in April, CVPR in June, ICML and ACL in July), the International AI Safety Report 2026 (3 February 2026), the Stanford AI Index 2026 (April 2026) and METR's Time Horizon 1.1 update (29 January 2026). Each makes claims you will want to repeat, and each claim rests on a different kind of evidence.

The lab is a toy illustration, not a reproduction of any of these: it simulates benchmark results so that you can practise the statistics needed to read the claims. The simulations know the true answer, which real evaluations never do. Real benchmarks also have problems the toy leaves out, such as test questions leaking into training data.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
from scipy.optimize import brentq

np.random.seed(0)
rng = np.random.default_rng(0)
pd.set_option("display.width", 200, "display.max_colwidth", 70)

2. How noisy is one benchmark score?¶

A benchmark score is an average of n right-or-wrong answers, so it carries sampling noise. If each answer is right with probability p, the standard error is $\sqrt{p(1-p)/n}$ and a 95% interval is about $\hat p \pm 1.96$ standard errors (the Wald interval). The Wilson interval is a small correction that behaves better near 0% and 100%.

def wald(acc, n, z=1.96):
    se = np.sqrt(acc * (1 - acc) / n)
    return acc - z * se, acc + z * se

def wilson(acc, n, z=1.96):
    centre = (acc + z**2 / (2 * n)) / (1 + z**2 / n)
    half = z * np.sqrt(acc * (1 - acc) / n + z**2 / (4 * n**2)) / (1 + z**2 / n)
    return centre - half, centre + half

for name, acc in [("model A", 0.78), ("model B", 0.80)]:
    lo, hi = wald(acc, 500)
    wlo, whi = wilson(acc, 500)
    print(f"{name}: {100*acc:.0f}% on 500 questions | Wald 95% CI {100*lo:.1f} to {100*hi:.1f} "
          f"(half-width {100*(hi-lo)/2:.1f} points) | Wilson {100*wlo:.1f} to {100*whi:.1f}")

ns = np.logspace(np.log10(50), 4, 60)
fig, ax = plt.subplots(figsize=(7, 3.2))
ax.plot(ns, 100 * 1.96 * np.sqrt(0.8 * 0.2 / ns))
ax.axhline(2, ls="--", c="gray", lw=1)
ax.set_xscale("log")
ax.set_xlabel("number of questions n")
ax.set_ylabel("95% half-width (points)")
ax.set_title("Sampling noise of a benchmark score at 80% accuracy")
plt.show()
n_needed = int(np.ceil(1.96**2 * 0.8 * 0.2 / 0.01**2))
print(f"questions needed for a +-1 point interval at 80% accuracy: {n_needed}")

3. Two models on the same questions: a paired comparison¶

Two models are usually tested on the same questions. Hard questions are hard for both, so their errors are correlated, and comparing two separate intervals throws that information away. A paired comparison works with the per-question differences instead.

The simulation gives each of 500 questions a hidden difficulty and gives each model a skill, chosen so that the true accuracies are 78% (model A) and 80% (model B). Model B really is better here, by 2 points.

n_q = 500
difficulty = rng.normal(0, 1.5, n_q)                     # one hidden difficulty per question

def p_correct(skill, diff):
    return 1 / (1 + np.exp(-(skill - diff)))

def skill_for(acc):                                       # the skill that gives this expected accuracy
    return brentq(lambda s: p_correct(s, difficulty).mean() - acc, -10, 10)

skill_A, skill_B = skill_for(0.78), skill_for(0.80)
a = (rng.random(n_q) < p_correct(skill_A, difficulty)).astype(int)
b = (rng.random(n_q) < p_correct(skill_B, difficulty)).astype(int)
print(f"measured accuracy: A {100*a.mean():.1f}%, B {100*b.mean():.1f}%, difference {100*(b.mean()-a.mean()):.1f} points")
print(f"questions where the two models disagree: {np.sum(a != b)} of {n_q}")

n_boot = 10_000
idx = rng.integers(0, n_q, (n_boot, n_q))
paired = 100 * (b[idx].mean(1) - a[idx].mean(1))          # resample questions, keep each question's pair together
idx2 = rng.integers(0, n_q, (n_boot, n_q))
unpaired = 100 * (b[idx2].mean(1) - a[idx].mean(1))       # resample the two models independently
n01, n10 = np.sum((a == 0) & (b == 1)), np.sum((a == 1) & (b == 0))
p_mcnemar = stats.binomtest(int(n01), int(n01 + n10), 0.5).pvalue
print(f"paired bootstrap 95% CI for B - A:   {np.percentile(paired, 2.5):.1f} to {np.percentile(paired, 97.5):.1f} points")
print(f"unpaired bootstrap 95% CI for B - A: {np.percentile(unpaired, 2.5):.1f} to {np.percentile(unpaired, 97.5):.1f} points")
print(f"McNemar exact test on the disagreements: B right and A wrong {n01}, A right and B wrong {n10}, p = {p_mcnemar:.3f}")

One benchmark run is one draw. How often would a 500-question benchmark show this real 2-point gain as a clear win? Repeat the whole experiment 1,000 times with fresh questions and fresh answers, and count how often the 95% interval for B − A excludes zero.

reps = 1000
D = rng.normal(0, 1.5, (reps, n_q))
A = (rng.random((reps, n_q)) < p_correct(skill_A, D)).astype(float)
B = (rng.random((reps, n_q)) < p_correct(skill_B, D)).astype(float)
diff = B.mean(1) - A.mean(1)
se_paired = (B - A).std(1, ddof=1) / np.sqrt(n_q)
se_unpaired = np.sqrt(A.var(1, ddof=1) / n_q + B.var(1, ddof=1) / n_q)
print(f"average measured gain: {100*diff.mean():.2f} points (true gain 2.0)")
print(f"runs where the paired 95% CI excludes 0:   {np.mean(diff - 1.96 * se_paired > 0):.3f}")
print(f"runs where the unpaired 95% CI excludes 0: {np.mean(diff - 1.96 * se_unpaired > 0):.3f}")
print(f"runs where B scored below A:               {np.mean(diff < 0):.3f}")

4. Try 20 prompts, report the best¶

A common way a result gets inflated without anyone lying: try many variants (prompts, seeds, hyperparameters) on the same test set and report the best one. Here all 20 prompt variants have exactly the same true accuracy (78%). Variant 0 is the "default". We pick the best variant on test set 1 and then check it on a fresh test set 2.

n_variants, n_rep = 20, 2000
gain_on_set1, gain_on_set2 = np.empty(n_rep), np.empty(n_rep)
for r in range(n_rep):
    d1, d2 = rng.normal(0, 1.5, n_q), rng.normal(0, 1.5, n_q)
    acc1 = (rng.random((n_variants, n_q)) < p_correct(skill_A, d1)).mean(1)
    best = acc1.argmax()
    gain_on_set1[r] = 100 * (acc1[best] - acc1[0])        # "our best prompt beats the default by ..."
    acc2 = (rng.random((2, n_q)) < p_correct(skill_A, d2)).mean(1)   # re-test the chosen variant and the default
    gain_on_set2[r] = 100 * (acc2[0] - acc2[1])
print(f"reported gain of the best of {n_variants} variants on test set 1: mean {gain_on_set1.mean():.2f} points, "
      f"at least 3 points in {np.mean(gain_on_set1 >= 3):.2f} of runs")
print(f"the same chosen variant on fresh test set 2: mean gain {gain_on_set2.mean():.2f} points")

fig, ax = plt.subplots(figsize=(7, 3.2))
bins = np.arange(-6, 8.5, 0.5)
ax.hist(gain_on_set1, bins=bins, alpha=0.7, label="best of 20, on the set used to choose it")
ax.hist(gain_on_set2, bins=bins, alpha=0.7, label="same variant, on a fresh set")
ax.set_xlabel("gain over the default prompt (points)")
ax.set_ylabel("number of runs")
ax.set_title("No variant is really better, yet 'the best' looks better")
ax.legend(fontsize=8)
plt.show()

reported gain of the best of 20 variants on test set 1: mean 2.89 points, at least 3 points in 0.48 of runs
the same chosen variant on fresh test set 2: mean gain 0.04 points

5. A claims ledger for this course¶

For each 2026 result this course uses, write down what is claimed, where, and what kind of evidence stands behind it:

  • preprint: posted (for example on arXiv), not yet peer reviewed;
  • peer-reviewed: accepted at a conference after review; reviewers read the paper but usually do not rerun it;
  • award: a committee judged it important and well done; this is still not a replication;
  • formally verified: a proof checked by a proof assistant such as Lean (the statement must still be formalized correctly);
  • organisation report: a report or blog from a research group or panel, not peer reviewed in the usual way.

The last column says whether we know of an independent reproduction. We have not checked any, so it says so.

What to notice¶

  • One score on 500 questions has a 95% interval of about ±3.5 points: 78% gives 74.4 to 81.6 and 80% gives 76.5 to 83.5. The intervals overlap, so the two headline numbers alone cannot separate the models. A ±1-point interval at 80% needs 6,147 questions.
  • In the single simulated run, model B's true advantage was 2 points, but the measured gap was only 0.8 points, and both bootstrap intervals contain zero (paired −3.8 to 5.2, unpaired −4.2 to 5.8). Pairing narrowed the interval by only about one point here, because in this toy the two models disagree on a quarter of the questions (124 of 500). The more two models agree, the more pairing helps.
  • Over 1,000 repeated benchmarks, the paired interval detected the real 2-point gain in only 15.4% of runs (unpaired: 10.0%), and B scored below A in 17.5% of runs. A 500-question benchmark is too small for 2-point claims.
  • Choosing the best of 20 identical prompts gave an average "gain" of 2.89 points on the set used to choose it, and at least 3 points in about half of the runs (0.48). On a fresh set the same choice gained 0.04 points. Selection alone manufactures gains, and a held-out set removes them.
  • In the ledger, five claims are peer-reviewed, three are organisation reports, one is a preprint and one rests on a Lean proof check. None is marked as independently reproduced, because we have not checked.
