1. The 2026 work behind this lab¶

Bergsträßer, Cotterell and Lin, "Transformers are Inherently Succinct" (ICLR 2026 Outstanding Paper, arXiv 2510.19315) measures expressive power by succinctness: how large a description must be to define a language. The authors prove that fixed-precision transformers can describe some languages exponentially more succinctly than linear temporal logic (LTL) formulas and recurrent networks, and doubly exponentially more succinctly than finite automata, and that checking basic properties of a transformer (is its language empty? do two transformers accept the same strings?) is EXPSPACE-complete. Li and Cotterell, "Characterizing the Expressivity of Local Attention in Transformers" (ACL 2026, arXiv 2605.00768) matches attention patterns with fragments of LTL: global attention with a fragment that has one past operator, while local (windowed) attention adds a second temporal operator; neither contains the other, so a hybrid is strictly more expressive.

This lab is a toy illustration, not a reproduction. It uses a classic textbook family of languages ("the k-th symbol from the end is a") where the gap between automata and attention is easy to see. The papers' constructions are more involved, and their transformers have fixed numerical precision, which our hand-built head does not respect (section 4 shows the precision it needs).

    return len(word) >= k and word[-k] == "a"

def random_words(n, k, max_len, rng=rng):
    return ["".join(rng.choice(["a", "b"], size=rng.integers(k, max_len + 1))) for _ in range(n)]

2. Automata: how many states does $L_k$ need?¶

A nondeterministic automaton (NFA) for $L_k$ needs only $k+1$ states: wait in state 0, guess "this a is the k-th from the end", then count $k-1$ more symbols. A deterministic automaton (DFA) must remember the last $k$ symbols. We build the DFA with the subset construction, shrink it with Moore's partition refinement (merge states that no suffix can tell apart), and count. As a cross-check, for small $k$ we count Myhill–Nerode classes by brute force: words that no suffix of length up to $k$ can tell apart.

def minimal_dfa_size(k):
    def nfa_step(S, sym):
        out = set()
        for q in S:
            if q == 0:
                out.add(0)
                if sym == "a":
                    out.add(1)
            elif q < k:
                out.add(q + 1)
        return frozenset(out)
    start = frozenset({0})
    states, todo, delta = {start}, [start], {}
    while todo:                                                     # subset construction, reachable part only
        S = todo.pop()
        for sym in "ab":
            T = nfa_step(S, sym)
            delta[S, sym] = T
            if T not in states:
                states.add(T)
                todo.append(T)
    block = {S: int(k in S) for S in states}                       # Moore: split accepting from rejecting, then refine
    while True:
        sig = {S: (block[S], block[delta[S, "a"]], block[delta[S, "b"]]) for S in states}
        ids = {v: i for i, v in enumerate(sorted(set(sig.values())))}
        new = {S: ids[sig[S]] for S in states}
        if len(set(new.values())) == len(set(block.values())):
            break
        block = new
    return len(states), len(set(block.values()))

def nerode_classes(k):                                              # brute force over all words of length k
    words = ["".join(w) for w in itertools.product("ab", repeat=k)]
    suffixes = [""] + ["".join(z) for m in range(1, k + 1) for z in itertools.product("ab", repeat=m)]
    return len({tuple(in_L(w + z, k) for z in suffixes) for w in words})

3. A short LTL formula¶

Linear temporal logic with past operators describes properties of a word read up to its last position. $Y\varphi$ ("yesterday") holds if $\varphi$ held one position earlier; $P\varphi$ ("sometime in the past") holds if $\varphi$ held at some earlier position. $L_k$ is $Y^{k-1}a$: $k-1$ copies of $Y$ and one letter, so the formula grows linearly in $k$ while the DFA grows exponentially. We check the formula against the definition on random words.

def holds(f, word, i):
    op = f[0]
    if op in ("a", "b"):
        return word[i] == op
    if op == "Y":
        return i > 0 and holds(f[1], word, i - 1)
    if op == "P":
        return any(holds(f[1], word, j) for j in range(i))
    if op == "or":
        return holds(f[1], word, i) or holds(f[2], word, i)
    raise ValueError(op)

def ltl_Lk(k):
    f = ("a",)
    for _ in range(k - 1):
        f = ("Y", f)
    return f

def formula_size(f):
    return 1 + sum(formula_size(g) for g in f[1:])

for k in [1, 3, 6, 10]:
    words = random_words(2000, 1, 30)
    agree = np.mean([holds(ltl_Lk(k), w, len(w) - 1) == in_L(w, k) for w in words])
    print(f"k = {k:2d}: formula size {formula_size(ltl_Lk(k)):2d}, agrees with the definition on {agree:.3f} of 2,000 random words")

4. An attention head written by hand¶

Give position $j$ the 2-D code $(\cos j\omega, \sin j\omega)$; with the rotated query below, this gives a relative-position score in the spirit of rotary position embeddings, which rotate queries and keys (Course 3, session 1). The key of position $j$ is its code; the query of the last position is its own code rotated back by $(k-1)\omega$ and scaled by a sharpness $\beta$; the value is 1 for "a" and 0 for "b". The head's attention then peaks at position $n-k$, and it accepts if its output is above 0.5.

The head has the same 12 numbers for every $k$ (the frequency $\omega$ of the position code, a 2 × 2 query matrix, a 2 × 2 key matrix, two values and a threshold); only the rotation angle inside the query matrix depends on $k$. The catch is precision: to tell neighbouring positions apart in words of length up to $n_{max}$, $\omega$ must be small and $\beta$ large, so the numbers must be stored more and more precisely as words get longer.

def make_head(k, n_max):
    omega = 2 * np.pi / (n_max + 1)
    beta = 4 * np.log(n_max) / (1 - np.cos(omega))                  # sharp enough to beat n_max - 1 neighbours
    c, s = np.cos(-(k - 1) * omega), np.sin(-(k - 1) * omega)
    W_q, W_k = beta * np.array([[c, -s], [s, c]]), np.eye(2)
    values = {"a": 1.0, "b": 0.0}
    return dict(omega=omega, beta=beta, W_q=W_q, W_k=W_k, values=values, threshold=0.5)

def head_accepts(head, word):
    pos = np.arange(len(word))
    codes = np.stack([np.cos(pos * head["omega"]), np.sin(pos * head["omega"])], 1)
    scores = (codes @ head["W_k"].T) @ (head["W_q"] @ codes[-1])
    w = np.exp(scores - scores.max())
    w = w / w.sum()
    return float(w @ np.array([head["values"][ch] for ch in word])) > head["threshold"]

n_max = 64
print(f"words of length k to {n_max}:")
for k in range(1, 11):
    head = make_head(k, n_max)
    words = random_words(1000, k, n_max)
    acc = np.mean([head_accepts(head, w) == in_L(w, k) for w in words])
    print(f"k = {k:2d}: accuracy {acc:.3f} | numbers in the head 12 | minimal DFA states {sizes[k]}")

print("\nprecision the head needs:")
for n in [16, 64, 256, 1024]:

    print(f"words up to length {n:4d}: beta = {h['beta']:12.1f}, relative score gap {gap:.2e}, about {np.log2(1 / gap):.1f} bits")

5. Local and global attention on two languages¶

Two languages: $L_2$ (the 2nd symbol from the end is "a", formula $Y a$) and contains-a (some position is "a", formula $a \lor P a$). Two one-head recognizers:

  • a local head that can look only at the last $w = 4$ positions (with positions inside the window);
  • a global head that can look at every position but has no position information, so it sees the earlier symbols only as a bag.

The local head handles $L_2$ but misses an "a" that lies outside its window. The global head handles contains-a, but no choice of weights lets it separate "bab" (in $L_2$) from "abb" (not in $L_2$): both have the same last symbol and the same bag of symbols. We check that with random weights.

W = 4
def local_head(word, lang):
    window = word[-W:]
    if lang == "L2":
        return len(window) >= 2 and window[-2] == "a"               # within the window positions are known
    return "a" in window                                             # it cannot see further back

def global_head(word, lang, Wq=None, Wk=None, Wv=None):
    if lang == "contains-a":
        return word.count("a") / len(word) > 0                       # uniform attention: the share of "a" is above 0
    onehot = np.array([[1.0, 0.0] if ch == "a" else [0.0, 1.0] for ch in word])
    q = Wq @ onehot[-1]
    scores = onehot @ Wk.T @ q
    w = np.exp(scores - scores.max()); w = w / w.sum()
    return w @ (onehot @ Wv.T)                                       # the head's output vector

words = random_words(3000, 2, 40)
for lang, truth in [("L2", lambda w: in_L(w, 2)), ("contains-a", lambda w: "a" in w)]:
    acc_local = np.mean([local_head(w, lang) == truth(w) for w in words])
    print(f"{lang:10s}: local head (window {W}) accuracy {acc_local:.3f}", end="")
    if lang == "contains-a":
        far = ["a" + "b" * m for m in range(W, 40)]                   # the only "a" is outside the window
        print(f" (on {len(far)} words whose only a is far back: {np.mean([local_head(w, lang) for w in far]):.3f} accepted)", end="")
        print(f" | global head accuracy {np.mean([global_head(w, lang) == truth(w) for w in words]):.3f}")
    else:
        print()

max_diff = 0.0
for trial in range(1000):
    Wq, Wk, Wv = (rng.normal(0, 3, (2, 2)) for _ in range(3))
    max_diff = max(max_diff, np.abs(global_head("bab", "L2", Wq, Wk, Wv) - global_head("abb", "L2", Wq, Wk, Wv)).max())
print(f"global head without positions, 1,000 random weight settings: largest output difference between 'bab' and 'abb' = {max_diff:.1e}")

6. Can gradient descent find a solution?¶

Train a small causal transformer (one layer, width 32, two heads, sinusoidal position codes) on $L_3$, with words of length 6 to 16, then test it on longer words. The hand-built head of section 4 works up to the length it was designed for.

K = 3
def sinusoid(n, d):
    pos, i = torch.arange(n)[:, None].float(), torch.arange(0, d, 2).float()
    pe = torch.zeros(n, d)
    pe[:, 0::2], pe[:, 1::2] = torch.sin(pos / 10000 ** (i / d)), torch.cos(pos / 10000 ** (i / d))
    return pe

class TinyTransformer(nn.Module):
    def __init__(self, d=32, layers=1, heads=2):
        super().__init__()
        self.d, self.emb = d, nn.Embedding(2, d)
        layer = nn.TransformerEncoderLayer(d, heads, 2 * d, dropout=0.0, batch_first=True, norm_first=True)
        self.enc = nn.TransformerEncoder(layer, layers, enable_nested_tensor=False)
        self.out = nn.Linear(d, 1)
    def forward(self, x):
        n = x.shape[1]
        causal = torch.triu(torch.full((n, n), float("-inf")), 1)
        return self.out(self.enc(self.emb(x) + sinusoid(n, self.d), mask=causal)[:, -1]).squeeze(-1)

g = torch.Generator().manual_seed(0)
def batch(n, bs):
    x = torch.randint(0, 2, (bs, n), generator=g)                    # symbol 0 is "a", 1 is "b"
    return x, (x[:, -K] == 0).float()

t0 = time.time()
model = TinyTransformer()
opt = torch.optim.Adam(model.parameters(), lr=3e-3)
for step in range(1500):
    x, y = batch(int(torch.randint(6, 17, (1,), generator=g)), 128)
    loss = F.binary_cross_entropy_with_logits(model(x), y)
    opt.zero_grad(); loss.backward(); opt.step()
print(f"trained for 1,500 steps in {time.time() - t0:.0f} s, final training loss {loss.item():.4f}")

lengths = [6, 8, 12, 16, 20, 24, 32, 48, 64]
acc_trained, acc_hand = [], []
head = make_head(K, 64)
with torch.no_grad():
    for n in lengths:

        acc_trained.append(((model(x) > 0).float() == y).float().mean().item())

        print(f"length {n:2d}: trained transformer {acc_trained[-1]:.3f} | hand-built head {acc_hand[-1]:.3f}")

What to notice¶

  • The minimal DFA for $L_k$ had exactly $2^k$ states for every $k$ from 1 to 10 (1,024 states at $k = 10$), and the brute-force Myhill–Nerode count agreed for $k \le 6$. The NFA needed $k + 1$ states and the LTL formula $Y^{k-1}a$ had size $k$. One family of languages, three description sizes: exponential, linear, linear.
  • The hand-built attention head recognized $L_k$ perfectly for every $k$ from 1 to 10 on words up to length 64, always with the same 12 numbers. But the precision it needs grows with word length: about 3.9 bits for words up to length 16, 7.7 bits for 64, 11.7 bits for 256 and 15.7 bits for 1,024 (β grew from 164 to about 1.5 million). The theorems fix the precision, which is why the papers' constructions are harder than this one.
  • The local head (window 4) was perfect on $L_2$ but accepted none of the 36 words whose only "a" lay outside its window. The global head without positions was perfect on contains-a but gave the same output for "bab" and "abb" (largest difference 1.8e-15 over 1,000 random weight settings), so it cannot recognize $L_2$. Each fails where the other succeeds: a one-layer toy version of the incomparability that Li and Cotterell prove in general.
  • Gradient descent found a solution that works only where it was trained. The trained transformer was perfect on lengths 6 to 16 and close to chance on longer words (0.514 at length 20, 0.513 at 32, 0.498 at 64, with an unexplained 0.869 at 24), while the hand-built head stayed at 1.000. Being able to represent a solution does not mean training will find it, or find one that generalizes.
