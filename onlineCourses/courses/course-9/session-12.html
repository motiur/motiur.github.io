1. Setup: data and four splits¶

The 8×8 digits (pixel values in [0, 1]) are split four ways: train (897 images), validation (300, used only to fit the temperature in section 4), calibration (300, used only for conformal prediction in section 6) and test (300). Keeping these roles separate matters: a calibration step that sees the test set is no longer an honest test.

import math, time

tr, va, ca, te = perm[:897], perm[897:1197], perm[1197:1497], perm[1497:]

2. Adversarial examples: FGSM and PGD¶

FGSM (Goodfellow et al. 2015) takes one step of size $\varepsilon$ in the direction of the sign of the loss gradient: $x' = x + \varepsilon\,\text{sign}(\nabla_x L)$. PGD (Madry et al. 2018) starts at a random point inside the $\varepsilon$-box and takes several smaller steps, projecting back into the box (and into [0, 1]) after each one. Both change every pixel by at most $\varepsilon$ (an $L_\infty$ attack). PGD is the stronger attack, so robust accuracy should be measured with it.

def fgsm(model, x, y, eps):
    x = x.clone().requires_grad_(True)
    grad, = torch.autograd.grad(F.cross_entropy(model(x), y), x)
    return (x + eps * grad.sign()).clamp(0, 1).detach()

def pgd(model, x, y, eps, steps=20):
    if eps == 0: return x
    alpha = 2.5 * eps / steps
    xa = (x + torch.empty_like(x).uniform_(-eps, eps)).clamp(0, 1)               # random start inside the box
    for _ in range(steps):
        xa.requires_grad_(True)
        grad, = torch.autograd.grad(F.cross_entropy(model(xa), y), xa)
        xa = torch.min(torch.max(xa.detach() + alpha * grad.sign(), x - eps), x + eps).clamp(0, 1)   # step, then project
    return xa.detach()

def train(seed, epochs=100, adv_eps=0.0):
    torch.manual_seed(seed); model = make(); opt = torch.optim.Adam(model.parameters(), 1e-3)
    for epoch in range(epochs):
        for idx in tr[torch.randperm(len(tr))].split(64):
            x, y = X[idx], Y[idx]
            if adv_eps > 0: x = pgd(model, x, y, adv_eps, steps=7)                 # train on PGD examples (Madry et al.)
            loss = F.cross_entropy(model(x), y); opt.zero_grad(); loss.backward(); opt.step()
    return model

t0 = time.time(); model = train(seed=0)
print(f"standard model trained in {time.time() - t0:.0f}s, clean test accuracy {accuracy(model, X[te], Y[te]):.3f}")
EPS = [0.0, 0.02, 0.05, 0.1, 0.15, 0.2]

    attack["standard", "PGD", eps] = accuracy(model, pgd(model, X[te], Y[te], eps), Y[te])
    print(f"{eps:5.2f}   {attack['standard', 'FGSM', eps]:13.3f}   {attack['standard', 'PGD', eps]:15.3f}")

3. Adversarial training¶

4. Calibration and temperature scaling¶

A classifier is calibrated if, among the inputs where it says 0.8, it is right 80% of the time. Expected calibration error (ECE) groups test points into 15 bins by confidence and averages |accuracy − confidence| weighted by bin size (Guo et al. 2017). Temperature scaling divides all logits by one number $T$, fitted to minimize negative log-likelihood (NLL) on the validation set. Dividing by $T > 0$ never changes which class has the largest logit, so accuracy cannot change.

def ece(probs, y, n_bins=15):
    conf, pred = probs.max(1); correct = (pred == y).float(); total = 0.0
    edges = torch.linspace(0, 1, n_bins + 1)
    for lo, hi in zip(edges[:-1], edges[1:]):
        m = (conf > lo) & (conf <= hi)
        if m.any(): total += m.float().mean() * (correct[m].mean() - conf[m].mean()).abs()
    return float(total)
nll = lambda probs, y: F.nll_loss(torch.log(probs.clamp_min(1e-12)), y).item()

with torch.no_grad(): logits_va, logits_te = model(X[va]), model(X[te])
Ts = torch.exp(torch.linspace(math.log(0.25), math.log(10), 400))
T_best = Ts[torch.stack([F.cross_entropy(logits_va / T, Y[va]) for T in Ts]).argmin()].item()
print(f"temperature fitted on the validation set: T = {T_best:.2f}")
for name, T in [("before (T = 1)", 1.0), (f"after (T = {T_best:.2f})", T_best)]:
    p = F.softmax(logits_te / T, 1)
    print(f"{name:16s} accuracy {(p.argmax(1) == Y[te]).float().mean():.3f} | mean confidence {p.max(1)[0].mean():.3f} | NLL {nll(p, Y[te]):.3f} | ECE {ece(p, Y[te]):.3f}")

def reliability(ax, probs, y, title, n_bins=15):
    conf, pred = probs.max(1); correct = (pred == y).float(); edges = torch.linspace(0, 1, n_bins + 1)
    for lo, hi in zip(edges[:-1], edges[1:]):
        m = (conf > lo) & (conf <= hi)
        if m.any():
            ax.bar(lo.item(), correct[m].mean().item(), width=1 / n_bins, align="edge", edgecolor="k", color="C0", alpha=0.7)
            ax.text(lo.item() + 0.5 / n_bins, 0.02, str(int(m.sum())), ha="center", fontsize=6, rotation=90)
    ax.plot([0, 1], [0, 1], "k--", lw=1); ax.set_xlabel("confidence"); ax.set_ylabel("accuracy in the bin"); ax.set_title(title, fontsize=9)

6. Conformal prediction sets¶

Split conformal prediction turns any classifier into sets that contain the true label with probability at least $1 - \alpha$ (Angelopoulos & Bates 2021). With a score $s(x, y)$ that is large when $y$ looks wrong, compute it on the $n$ calibration points, take $\hat q$ = the $\lceil (n+1)(1-\alpha) \rceil$-th smallest score, and predict $C(x) = \{y : s(x, y) \le \hat q\}$. We use $\alpha = 0.1$ and two scores, on the temperature-scaled model:

  • threshold score $1 - \hat p_y(x)$: keep every class whose probability is at least $1 - \hat q$. Sets can be empty.
  • adaptive score (APS, as described by Angelopoulos & Bates 2021): the total probability of the classes ranked above $y$, plus $u \cdot \hat p_y$ with $u$ a uniform random number drawn once per image. The set takes classes in order of probability while their score stays at or below $\hat q$. Without $u$, a confident model's scores all pile up just below 1 and the sets become large. We also always keep the most likely class, which can only raise coverage. Angelopoulos et al. 2021 add a penalty on large sets (RAPS).

The guarantee is about the average over calibration sets and test points, so we also repeat the split 1,000 times.

alpha, n = 0.1, len(ca)
k = math.ceil((n + 1) * (1 - alpha))
with torch.no_grad(): p_cal, p_test = F.softmax(model(X[ca]) / T_best, 1), F.softmax(model(X[te]) / T_best, 1)

g = torch.Generator().manual_seed(2); u_cal, u_test = torch.rand(len(ca), generator=g), torch.rand(len(te), generator=g)

def thr_score(p, y, u=None): return 1 - p[torch.arange(len(y)), y]
def thr_sets(p, q, u=None): return (1 - p) <= q
def aps_score(p, y, u):
    order = p.argsort(1, descending=True); sp = p.gather(1, order)
    r, i = (order == y[:, None]).float().argmax(1), torch.arange(len(y))     # rank of the true class
    return (sp.cumsum(1) - sp)[i, r] + u * sp[i, r]                         # mass ranked above y, plus u * p_y
def aps_sets(p, q, u):
    order = p.argsort(1, descending=True); sp = p.gather(1, order)
    keep = (sp.cumsum(1) - sp + u[:, None] * sp) <= q                        # each class's score, in rank order
    keep[:, 0] = True                                                       # always keep the most likely class
    return torch.zeros_like(keep).scatter(1, order, keep)

qhat, sets = {}, {}
print(f"n = {n} calibration points, alpha = {alpha}: qhat is the {k}th smallest score")

    qhat[name] = torch.sort(score(p_cal, Y[ca], u_cal))[0][k - 1].item()
    sets[name] = make_sets(p_test, qhat[name], u_test); size = sets[name].sum(1).float()

          f"empty {(size == 0).float().mean():.1%} | one label {(size == 1).float().mean():.1%} | two or more {(size >= 2).float().mean():.1%}")

7. The same measures under a distribution shift¶

Rotate the test digits by 10°, 20° and 30° (with scipy.ndimage.rotate). The temperature, the conformal thresholds and the ensemble were all fitted on unrotated data, which is what happens when the world changes after deployment.

def rotated(x, angle):
    imgs = x.view(-1, 8, 8).numpy()
    return torch.tensor(np.clip(np.stack([rotate(im, angle, reshape=False, order=1) for im in imgs]), 0, 1).reshape(-1, 64), dtype=torch.float32)

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds.)

  1. Small changes break a standard network. Changing every pixel by at most 0.1 cut test accuracy from 0.957 to 0.447 with one FGSM step and to 0.393 with 20 PGD steps; at 0.2 PGD reached 0.000. PGD was at least as strong as FGSM at every size of change.
  2. Adversarial training bought a lot of robustness: PGD accuracy at 0.1 rose from 0.393 to 0.787, and at 0.2 from 0.000 to 0.300. Against expectation, clean accuracy did not drop (0.960 against 0.957). The robustness–accuracy trade-off is real on harder data (Madry et al. saw a clear drop on CIFAR-10), but it was not visible on these small, simple images. Note also that FGSM overstated the robust model's strength at 0.2 (0.413 against 0.300 for PGD): always evaluate with the stronger attack.
  3. This model was only slightly overconfident (mean confidence 0.974, accuracy 0.957). Temperature scaling with T = 1.27 lowered the NLL from 0.139 to 0.126 and left accuracy unchanged, but ECE barely moved (0.028 to 0.027). With 300 test images and almost all of them in the top confidence bin, ECE is a noisy number.
  4. The ensemble improved NLL but not ECE: NLL 0.126 against 0.139 for the average member, same accuracy (0.957), but ECE 0.033, no better than single members (0.023 to 0.031).
  5. Conformal coverage held on average, not for every group. Threshold sets covered 0.917 of test images with a mean size of 0.93 labels; 7.3% of the sets were empty ("no label is likely enough"). Over 1,000 random splits the mean coverage was 0.9011, as promised, but single splits ranged from 0.863 to 0.937 (5th to 95th percentile), and coverage by class ranged from 0.83 (digit 3) to 1.00. Adaptive sets were never empty, covered 0.977 and averaged 1.06 labels.
  6. A shift breaks everything at once. Rotating the test digits by 10°, 20° and 30° lowered accuracy to 0.787, 0.650 and 0.417, raised ECE to 0.084, 0.181 and 0.360, and pulled the coverage of the threshold sets down to 0.587, 0.440 and 0.247 (adaptive sets: 0.863, 0.740 and 0.523). The coverage guarantee assumes the test data are exchangeable with the calibration data, and rotation breaks that. The ensemble helped a little at 10° (accuracy 0.817, NLL 0.584 against 0.654) but not at 20° or 30°.
  7. These are 8×8 digits and a small MLP. The patterns (fragile accuracy, overconfidence under shift, average-only guarantees) are the ones reported for large models; the sizes of the numbers are not.
