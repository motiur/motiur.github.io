Geometric Deep Learning and Graphs

Symmetry as the organising idea behind modern architectures: message passing, expressive power, graph transformers, equivariant CNNs and E(3) models for atoms, curved spaces, generative models on graphs, and graph learning in medicine.

  • GNNs
  • Equivariance
  • Graph transformers
  • Hyperbolic embeddings
  • Graph diffusion

Before you start

One notebook per session. Open them in Kaggle Notebooks or Google Colab.

  • Every cell without a NOT RUN label was run once on a CPU on 17 November 2026 (Python 3, NumPy 2.5, scikit-learn 1.9, PyTorch 2.15). These cells use small built-in or synthetic data, so they run anywhere in a minute or two.
  • Cells labelled NOT RUN use the real datasets and libraries named in the syllabus (PyTorch Geometric, escnn, OGB, Boltz-2, Cora, ZINC, QM9, METR-LA, ogbl-ddi). They were written from the libraries' documented interfaces but not executed. Run them once yourself before recording, and fix any call that has changed.
  • The synthetic data is there to make the idea visible quickly. Numbers from it are not benchmark results.
  • The knowledge graph in session 10 and the disease tree in session 8 are simplified teaching examples, not medical references.
  • Each notebook ends with TODO items for students.
