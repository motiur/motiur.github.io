1. A synthetic hierarchy and the Poincaré-disk helpers¶

The data is a synthetic hierarchy, a random tree that stands in for a real taxonomy such as the WordNet noun hierarchy (section 7, NOT RUN) or the ICD-10 disease codes (Course 7 session 8). The root has 4 children, nodes at depths 1 and 2 have 2 to 4 children, and deeper nodes have 0 to 4, down to depth 5.

We work in the Poincaré disk with curvature −1 ($c = 1$), re-implementing what we need from session 6:

  • distance $d(x, y) = \operatorname{arcosh}\!\left(1 + \dfrac{2\|x - y\|^2}{(1 - \|x\|^2)(1 - \|y\|^2)}\right) = 2\operatorname{artanh}\|(-x) \oplus y\|$;
  • in 2-D a point is a complex number $z$ with $|z| < 1$, and Möbius addition becomes $a \oplus z = \dfrac{a + z}{1 + \bar a z}$;
  • the Möbius translation $z \mapsto (-a) \oplus z = \dfrac{z - a}{1 - \bar a z}$ moves $a$ to the origin and is an isometry: it changes no distance.

The cell checks the two distance formulas against each other, the complex Möbius addition against session 6's vector formula, and that the translation keeps every distance.

2. The two evaluation measures¶

Mean average precision (MAP) asks whether each node's true neighbours are the nodes closest to it in the embedding. For node $a$ with neighbours $N_a$, take each neighbour $b$, the ball around $a$ that just reaches $b$, and the precision $|N_a \cap \text{ball}| / |\text{ball}|$; average over $b$ (the average precision of $a$), then over all nodes (Sala et al. 2018). MAP is 1 when every node's neighbours come first. It ignores the size of the distances, only their order.

Distortion compares embedding distances $d_E$ with graph distances $d_G$ over all pairs. The average distortion is the mean of $|s\,d_E/d_G - 1|$, with the global scale $s$ chosen to make it smallest (a weighted median). The worst-case distortion is $\max(d_E/d_G) / \min(d_E/d_G)$, which needs no scale; it is 1 for a perfect copy of the tree's metric.

By hand first: node $a$ has two neighbours, ranked 1st and 3rd among all other nodes. Its average precision is $(1/1 + 2/3)/2 = 0.833$. The cell checks this.

def mean_ap(E, A):
    aps = []
    for a in range(len(E)):
        dist, nbr = np.delete(E[a], a), np.delete(A[a], a) > 0
        dn = dist[nbr]
        aps.append(np.mean([(dn <= x).sum() / (dist <= x).sum() for x in dn]))   # "<=" handles ties
    return float(np.mean(aps))

def distortion(E, D):
    ratio = E[iu] / D[iu]
    inv = 1 / ratio; order = np.argsort(inv); cw = np.cumsum(ratio[order])
    s = inv[order][np.searchsorted(cw, cw[-1] / 2)]           # minimizes sum |s * ratio - 1|
    return float(np.mean(np.abs(s * ratio - 1))), float(ratio.max() / ratio.min())

# the hand example: node 0 with neighbours 1 and 3; distances from node 0 put them 1st and 3rd
E_toy = np.zeros((4, 4)); E_toy[0, 1:] = E_toy[1:, 0] = [1.0, 2.0, 3.0]          # node 1 nearest, then 2, then 3
A_toy = np.zeros((4, 4)); A_toy[0, [1, 3]] = 1
dist0, nbr0 = E_toy[0, 1:], A_toy[0, 1:] > 0
print("hand example, average precision of node 0:", round(np.mean([(dist0[nbr0] <= x).sum() / (dist0 <= x).sum() for x in dist0[nbr0]]), 3))
print(f"the tree's own distances: MAP {mean_ap(D, A):.3f}, distortion (average, worst case) {distortion(D, D)}")

3. Poincaré embeddings trained with Riemannian SGD¶

The loss of Nickel & Kiela (2017): for each linked pair $(u, v)$, here the tree's edges in both directions, draw 10 random nodes $v'$ as negatives and minimize

$$-\log \frac{e^{-d(u, v)}}{e^{-d(u, v)} + \sum_{v'} e^{-d(u, v')}},$$

which pulls $v$ towards $u$ and pushes the negatives away. Sampled nodes that are actually linked to $u$ are masked out.

Riemannian SGD in the ball. The metric is $\lambda_x^2$ times the Euclidean one, with $\lambda_x = 2/(1 - \|x\|^2)$, so the Riemannian gradient is the Euclidean gradient times $1/\lambda_x^2 = (1 - \|x\|^2)^2/4$. The update $x \leftarrow x - \eta\,\frac{(1 - \|x\|^2)^2}{4}\nabla_E$ is followed by a retraction that pulls any point with $\|x\| \ge 1 - 10^{-5}$ back to that radius. As in the paper, points start uniformly in $[-0.001, 0.001]$ and the first 10% of epochs use $\eta/10$ ("burn-in").

The Euclidean baseline uses the same loss, negatives and schedule with plain gradient descent. We train 2-D and 10-D versions of both, each with the learning rates 0.03, 0.1 and 0.3 for 1,000 full-batch epochs, and print every run: tuning only one side would not be a fair comparison (Course 1 session 9). Real hierarchies are bigger, so real runs use minibatches and more epochs.

pos = np.array(list(T.edges()) + [(v, u) for u, v in T.edges()])
Pu, Pv, At = torch.tensor(pos[:, 0]), torch.tensor(pos[:, 1]), torch.tensor(A)

def dist_poincare_t(x, y):
    sq = ((x - y)**2).sum(-1)
    den = (1 - (x**2).sum(-1)) * (1 - (y**2).sum(-1))
    return torch.arccosh(torch.clamp(1 + 2 * sq / den, min=1 + 1e-12))     # clamp: arcosh'(1) is infinite

def dist_euclid_t(x, y):
    return torch.sqrt(((x - y)**2).sum(-1) + 1e-12)

def train(geom, dim, lr, epochs=1000, K=10, seed=0):
    g = torch.Generator().manual_seed(seed)                   # same initial points and negatives for every model
    X = ((torch.rand(n, dim, generator=g) * 2 - 1) * 1e-3).requires_grad_(True)
    dist = dist_poincare_t if geom == "Poincare" else dist_euclid_t
    for ep in range(epochs):
        neg = torch.randint(0, n, (len(Pu), K), generator=g)
        d = dist(X[Pu][:, None, :], X[torch.cat([Pv[:, None], neg], 1)])     # column 0: the true neighbour
        linked = (At[Pu[:, None], neg] > 0) | (neg == Pu[:, None])
        logits = torch.cat([-d[:, :1], (-d[:, 1:]).masked_fill(linked, -float("inf"))], 1)
        loss = (torch.logsumexp(logits, 1) + d[:, 0]).sum()
        X.grad = None; loss.backward()
        eta = lr / 10 if ep < epochs // 10 else lr
        with torch.no_grad():
            if geom == "Poincare":
                X -= eta * (1 - (X**2).sum(1, keepdim=True))**2 / 4 * X.grad      # Riemannian gradient step
                r = X.norm(dim=1, keepdim=True)
                X.copy_(torch.where(r >= 1 - 1e-5, X / r * (1 - 1e-5), X))     # retraction into the ball
            else:
                X -= eta * X.grad
    with torch.no_grad():
        E = dist(X[:, None, :], X[None, :, :]).numpy()
    np.fill_diagonal(E, 0.0)
    return X.detach().numpy(), E, loss.item() / len(Pu)

4. Which geometry won?¶

For each model we keep the learning rate with the highest MAP; compare with the full table above before trusting a single number. Two more measures help: the Spearman correlation between a node's depth and its embedding distance from the root (does the hierarchy level show up as distance from the root?), and how many points sit at the retraction radius $1 - 10^{-5}$, where Riemannian SGD can no longer move them outwards. The plot shows distance from the root against depth, in units of the median embedded edge length, so that a perfect copy of the tree would give the line "distance = depth".

5. Session 4's constructive embedding, on this tree¶

Sarkar's construction (Sarkar 2011; Sala et al. 2018) needs no training. Put the root at the origin and its children at hyperbolic distance $\tau$, evenly spread in angle. Then, for each node $a$ already placed: translate $a$ to the origin (the parent lands at some point $w$), place $a$'s children at distance $\tau$ at evenly spaced angles that skip the direction of $w$, and translate back. A point at hyperbolic distance $\tau$ from the origin has Euclidean radius $\tanh(\tau/2)$.

Larger scale factors $\tau$ make the distortion smaller, but the leaves move exponentially close to the boundary: a leaf about $5\tau$ from the origin has $1 - |z| \approx 2e^{-5\tau}$. The cell measures both, and what happens when the coordinates are stored in float32.

def sarkar(tau):
    r = np.tanh(tau / 2)
    Z = np.zeros(n, dtype=complex)
    for i, c in enumerate(children[0]):
        Z[c] = r * np.exp(2j * np.pi * i / len(children[0]))
    stack = list(children[0])
    while stack:
        a = stack.pop()
        w = madd(-Z[a], Z[parent[a]])                         # where the parent lands when a moves to 0
        k = len(children[a]) + 1                              # children plus the parent's direction
        for i, c in enumerate(children[a], start=1):
            Z[c] = madd(Z[a], r * np.exp(1j * (np.angle(w) + 2 * np.pi * i / k)))
            stack.append(c)
    return Z

def dist_matrix(Z, dtype=np.float64):
    x = to_xy(Z).astype(dtype)
    sq = ((x[:, None, :] - x[None, :, :])**2).sum(-1)
    nn = (x**2).sum(-1)
    with np.errstate(divide="ignore", invalid="ignore"):
        E = np.arccosh((1 + 2 * sq / ((1 - nn)[:, None] * (1 - nn)[None, :])).astype(dtype))
    np.fill_diagonal(E, 0.0)
    return E

6. Pictures¶

To draw an embedding with its root at the centre we apply the Möbius translation that moves the root to 0; distances do not change (section 1). Edges are drawn as geodesics, $\gamma(t) = x \oplus \big(t \otimes ((-x) \oplus y)\big)$, where $t \otimes w = \tanh(t\operatorname{artanh}|w|)\,w/|w|$ is Möbius scalar multiplication. The Euclidean embedding is shifted so that its root is at 0.

def geodesic(x, y, m=20):
    w = madd(-x, y)
    t = np.linspace(0, 1, m)
    return madd(x, np.tanh(t * np.arctanh(abs(w))) * w / abs(w))

def draw(ax, Z, title, disk=True):

    ax.set_xlabel("coordinate 1", fontsize=8); ax.set_ylabel("coordinate 2", fontsize=8)

7. A real hierarchy: WordNet mammals (NOT RUN here)¶

Nickel & Kiela (2017) embedded the WordNet noun hierarchy using its transitive closure: every (descendant, ancestor) pair, not only parent–child links. The mammal subtree is the usual small benchmark. This needs nltk and a download of the WordNet corpus.

# NOT RUN: needs nltk and a download of the WordNet corpus (nltk.download("wordnet"))
import nltk
nltk.download("wordnet")
from nltk.corpus import wordnet as wn

root = wn.synset("mammal.n.01")
nouns = sorted({s.name() for s in root.closure(lambda s: s.hyponyms())} | {root.name()})
idx = {name: i for i, name in enumerate(nouns)}

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds, except the timings.)

  1. The helpers agree. The two distance formulas matched to 1.2e-14, complex and vector Möbius addition to 6.2e-16, and the Möbius translation changed no distance by more than 1.2e-14. The tree has 297 nodes (1, 4, 12, 35, 77 and 168 per depth) and diameter 10.
  2. In 2-D, hyperbolic won clearly. The best Poincaré run reached MAP 0.914 against 0.719 for the best Euclidean run, and every 2-D Poincaré run (0.772 to 0.914) beat every 2-D Euclidean run (0.697 to 0.719). Average distortion was 0.202 against 0.343, and the worst case 23.7 against 681.0: in the plane, crowded leaves end up almost on top of each other.
  3. In 10-D, Euclidean caught up and, at its best learning rate, won. Euclidean reached MAP 1.000 (learning rate 0.3) against 0.991 for Poincaré (0.1). The ranking depends on the learning rate: at 0.03 and 0.1, Poincaré was ahead (0.965 and 0.991 against 0.801 and 0.924). Hyperbolic space helps most when dimensions are scarce.
  4. Depth shows up as distance from the root, more clearly in hyperbolic space. The Spearman correlation between depth and distance from the root was 0.752 (Poincaré, 2-D) against 0.289 (Euclidean, 2-D), and 0.848 against 0.586 in 10-D. Measured in median edge lengths, the depth-5 nodes sat 1.9 to 3.5 edges from the root in the 2-D Poincaré embedding but 2.7 to 23.6 in the 2-D Euclidean one: to keep crowded leaves apart, the plane has to stretch some edges far beyond others. In 10-D both stayed in a narrow band (2.3 to 3.1 and 2.4 to 4.1). In every case the distance is below the depth, because paths through the tree bend.
  5. The construction beat every trained embedding, at a price in precision. With $\tau = 2$ it had MAP 1.000, average distortion 0.066 and worst case 2.591; with $\tau = 3$, 0.039 and 1.429. But the leaves sat $1.0 \times 10^{-4}$ and $6.8 \times 10^{-7}$ from the boundary. At $\tau = 4$ (distortion 0.028), 79 points rounded onto the boundary in float32 and 15,753 distances became infinite or undefined; at $\tau = 8$ one point was computed outside the disk even in float64. The trained embeddings were never pushed that far (no point reached the retraction radius), partly because their loss rewards ranking, not exact distances.
  6. Disk pictures mislead. In the trained 2-D Poincaré picture most nodes crowd along the circle and long geodesics cross the disk. Near the boundary, short-looking gaps are long hyperbolic distances (Course 7 session 8), and the crossing geodesics are the badly placed edges that MAP penalizes.
