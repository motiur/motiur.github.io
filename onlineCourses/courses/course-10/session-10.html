1. SO(3): Rodrigues' formula, the log map and the geodesic distance¶

A rotation is a $3 \times 3$ matrix with $R^\top R = I$ and $\det R = 1$; these form the group SO(3), a 3-dimensional manifold. Its tangent space at $I$, the Lie algebra so(3), holds the skew-symmetric matrices $$[\omega]_\times = \begin{pmatrix} 0 & -\omega_3 & \omega_2 \\ \omega_3 & 0 & -\omega_1 \\ -\omega_2 & \omega_1 & 0 \end{pmatrix}, \qquad [\omega]_\times v = \omega \times v.$$

  • exp (Rodrigues' formula): with $\theta = \|\omega\|$ and $K = [\omega]_\times$, $\exp(K) = I + \dfrac{\sin\theta}{\theta}K + \dfrac{1 - \cos\theta}{\theta^2}K^2$: a rotation by angle $\theta$ about the axis $\omega/\theta$.
  • log: $\theta = \operatorname{atan2}\!\big(\tfrac12\|\text{vee}(R - R^\top)\|,\ \tfrac12(\operatorname{tr}R - 1)\big)$ and $\omega = \dfrac{\theta}{2\sin\theta}\,\text{vee}(R - R^\top)$, where vee reads the vector out of a skew-symmetric matrix. Near $\theta = 0$ use $\omega \approx \tfrac12\text{vee}(R - R^\top)$. Near $\theta = \pi$, $\sin\theta \to 0$ and this formula loses accuracy; there we use the symmetric part, $nn^\top = \big(\tfrac12(R + R^\top) - \cos\theta\,I\big)/(1 - \cos\theta)$, for the axis $n$.
  • geodesic distance: $d(R_1, R_2) = \|\log(R_1^\top R_2)\| =$ the angle of the rotation $R_1^\top R_2$, between 0 and $\pi$. The formula $\arccos\big((\operatorname{tr}R - 1)/2\big)$ is exact on paper but inaccurate for small angles; atan2 is not.

SE(3), the group of poses (a rotation $R$ and a translation $t$), uses $4 \times 4$ matrices $\begin{pmatrix} R & t \\ 0 & 1\end{pmatrix}$. Its exp map sends a twist $(\omega, v)$ to $R = \exp([\omega]_\times)$ and $t = Vv$ with $V = I + \frac{1 - \cos\theta}{\theta^2}K + \frac{\theta - \sin\theta}{\theta^3}K^2$ (Solà et al. 2018). The cell checks all of this against SciPy: Rotation.from_rotvec uses the same axis-angle vector $\omega$, and scipy.linalg.expm exponentiates any matrix.

import time, warnings
import numpy as np
import scipy.linalg as sla
import torch
import matplotlib.pyplot as plt
from scipy.spatial.transform import Rotation as Rot

t_start = time.time()
torch.set_num_threads(1)
np.random.seed(0); torch.manual_seed(0)
rng = np.random.default_rng(0)

def hat(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0]])

def vee(S):
    return np.array([S[2, 1], S[0, 2], S[1, 0]])

def exp_so3(w):
    th, K = np.linalg.norm(w), hat(w)
    if th < 1e-8:
        return np.eye(3) + K + K @ K / 2
    return np.eye(3) + np.sin(th) / th * K + (1 - np.cos(th)) / th**2 * K @ K

def angle(R):                                                 # rotation angle, accurate for all angles
    return np.arctan2(np.linalg.norm(vee(R - R.T)) / 2, (np.trace(R) - 1) / 2)

def log_so3(R):
    th = angle(R)
    if th < 1e-6:
        return vee(R - R.T) / 2
    if th < np.pi - 1e-3:
        return th / (2 * np.sin(th)) * vee(R - R.T)
    B = ((R + R.T) / 2 - np.cos(th) * np.eye(3)) / (1 - np.cos(th))      # equals n n^T
    k = np.argmax(np.diag(B)); n = B[:, k] / np.sqrt(B[k, k])
    return th * (n if vee(R - R.T) @ n >= 0 else -n)

2. Representations and their discontinuities¶

A network must output some numbers that encode a rotation:

  • Euler angles (3 numbers). SciPy's "xyz" means rotations about the fixed x, y and z axes in that order, so $R = R_z(\gamma)R_y(\beta)R_x(\alpha)$; capital "XYZ" means rotations about the moving axes. Angles wrap around at ±180°, and at $\beta = \pm 90°$ only $\alpha - \gamma$ (or $\alpha + \gamma$) is determined: gimbal lock.
  • Unit quaternions (4 numbers): $q$ and $-q$ give the same rotation, so any rule that picks one of them (for example $q_w \ge 0$) must jump somewhere. SciPy stores quaternions as $(x, y, z, w)$ unless you pass scalar_first=True.
  • The 6-D representation of Zhou et al. (2019): the first two columns of $R$. To decode any 6 numbers $(a_1, a_2)$, apply Gram–Schmidt: $b_1 = a_1/\|a_1\|$, $b_2 = $ the normalized part of $a_2$ orthogonal to $b_1$, $b_3 = b_1 \times b_2$, and $R = [b_1\ b_2\ b_3]$.

Zhou et al. proved that every representation of 3-D rotations in 4 or fewer real dimensions is discontinuous, while 5-D and 6-D continuous ones exist. The cell walks along a smooth path of rotations (about the z axis from 170° to 190°, with a small tilt) and records the largest jump between neighbouring samples in each representation, then shows gimbal lock.

3. Learning a rotation from a point cloud¶

The task: a fixed cloud of 10 points (a synthetic stand-in for the atoms of a molecule or the keypoints of an object) is rotated by a uniformly random rotation $R$, and Gaussian noise of standard deviation 0.05 is added. From the 30 noisy coordinates, in a fixed order, an MLP must predict $R$.

Three networks differ only in their last layer and decoder: Euler angles (3 outputs), a quaternion (4 outputs, normalized) or the 6-D representation (6 outputs, Gram–Schmidt). All three are trained with the same loss on the decoded matrix, $\|\hat R - R\|_F^2$, with fresh random rotations in every batch (256 per step, 3,000 Adam steps with a cosine schedule), and tested on 5,000 new rotations by the geodesic error in degrees. The decoders are checked against SciPy first.

Because the points correspond one to one, the best possible answer has a closed form: the orthogonal Procrustes (Kabsch) solution by SVD from session 5. It shows how far the networks are from the optimum.

def euler_to_matrix(e):                                       # scipy "xyz": R = Rz(c) Ry(b) Rx(a)
    a, b, c = e.unbind(-1)
    o, z = torch.ones_like(a), torch.zeros_like(a)
    Rx = torch.stack([o, z, z, z, a.cos(), -a.sin(), z, a.sin(), a.cos()], -1).view(-1, 3, 3)
    Ry = torch.stack([b.cos(), z, b.sin(), z, o, z, -b.sin(), z, b.cos()], -1).view(-1, 3, 3)
    Rz = torch.stack([c.cos(), -c.sin(), z, c.sin(), c.cos(), z, z, z, o], -1).view(-1, 3, 3)
    return Rz @ Ry @ Rx

def quat_to_matrix(q):                                        # q = (w, x, y, z), normalized here
    w, x, y, z = (q / q.norm(dim=-1, keepdim=True)).unbind(-1)
    return torch.stack([1 - 2 * (y * y + z * z), 2 * (x * y - w * z), 2 * (x * z + w * y),
                        2 * (x * y + w * z), 1 - 2 * (x * x + z * z), 2 * (y * z - w * x),
                        2 * (x * z - w * y), 2 * (y * z + w * x), 1 - 2 * (x * x + y * y)], -1).view(-1, 3, 3)

def sixd_to_matrix(v):                                        # Gram-Schmidt (Zhou et al. 2019)
    b1 = v[:, :3] / v[:, :3].norm(dim=-1, keepdim=True)
    b2 = v[:, 3:] - (b1 * v[:, 3:]).sum(-1, keepdim=True) * b1
    b2 = b2 / b2.norm(dim=-1, keepdim=True)
    return torch.stack([b1, b2, torch.cross(b1, b2, dim=-1)], -1)

r = Rot.random(100, rng=rng)
M64 = torch.tensor(r.as_matrix())
print(f"decoders vs scipy: Euler {(euler_to_matrix(torch.tensor(r.as_euler('xyz'))) - M64).abs().max():.1e}, "
      f"quaternion {(quat_to_matrix(torch.tensor(r.as_quat(scalar_first=True))) - M64).abs().max():.1e}, "
      f"6-D {(sixd_to_matrix(torch.cat([M64[:, :, 0], M64[:, :, 1]], 1)) - M64).abs().max():.1e}")

P = torch.randn(10, 3, generator=torch.Generator().manual_seed(7)); P = P - P.mean(0)
def batch(n, g, noise=0.05):
    R = quat_to_matrix(torch.randn(n, 4, generator=g))       # normalized Gaussian quaternions: uniform rotations
    X = P[None] @ R.transpose(1, 2) + noise * torch.randn(n, 10, 3, generator=g)
    return X.reshape(n, -1), R

def geodesic_deg(R1, R2):                                     # batched, with atan2
    M = R1.transpose(1, 2) @ R2
    s = torch.stack([M[:, 2, 1] - M[:, 1, 2], M[:, 0, 2] - M[:, 2, 0], M[:, 1, 0] - M[:, 0, 1]], -1).norm(dim=-1) / 2
    return torch.rad2deg(torch.atan2(s, (M.diagonal(dim1=1, dim2=2).sum(-1) - 1) / 2))

Xte, Rte = batch(5000, torch.Generator().manual_seed(123))
heads = {"Euler angles": (3, euler_to_matrix), "quaternion": (4, quat_to_matrix), "6-D (Gram-Schmidt)": (6, sixd_to_matrix)}
errors = {}
for name, (k, decode) in heads.items():

    net = torch.nn.Sequential(torch.nn.Linear(30, 128), torch.nn.ReLU(), torch.nn.Linear(128, 128), torch.nn.ReLU(), torch.nn.Linear(128, k))

    sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, 3000)

4. Averaging rotations¶

Fifty noisy measurements of one orientation: $R_i = R_0\exp([\omega_i]_\times)$ with $\omega_i$ drawn from $N(0, (15°)^2 I)$, around a true $R_0$ whose Euler angle about z is 178°, close to the ±180° wrap-around. Five ways to average them (Hartley et al. 2013 survey the correct ones):

  • naive Euler: average the three Euler angles;
  • naive quaternion: average the quaternions as they come, here with random signs, as when $q$ and $-q$ come from different sensors;
  • sign-aligned quaternion: flip each $q_i$ to agree in sign with the first one, then average and normalize;
  • chordal $L_2$ mean: $\arg\min_R \sum_i \|R - R_i\|_F^2$, which is the projection of $\sum_i R_i$ onto SO(3) by SVD; SciPy's Rotation.mean() minimizes the same quantity;
  • geodesic $L_2$ (Karcher) mean: $\arg\min_R \sum_i d(R, R_i)^2$, by the iteration $R \leftarrow R\exp\big(\frac1N\sum_i \log(R^\top R_i)\big)$ (session 3's iteration, on SO(3)).
R0 = Rot.from_euler("xyz", [10, 20, 178], degrees=True)
samples = R0 * Rot.from_rotvec(rng.normal(0, np.deg2rad(15), (50, 3)))
Ms, true = samples.as_matrix(), R0.as_matrix()
err_deg = lambda R: np.rad2deg(angle(true.T @ R))

E = samples.as_euler("xyz")
Q = samples.as_quat() * rng.choice([-1, 1], (50, 1))        # same rotations, random signs
Qa = Q * np.sign(Q @ Q[0])[:, None]
U, _, Vt = np.linalg.svd(Ms.sum(0))
chordal = U @ np.diag([1, 1, np.linalg.det(U @ Vt)]) @ Vt
Rk, steps = chordal.copy(), []
for it in range(100):
    L = np.mean([log_so3(Rk.T @ Ri) for Ri in Ms], axis=0)
    steps.append(np.linalg.norm(L)); Rk = Rk @ exp_so3(L)
    if steps[-1] < 1e-14:
        break
print(f"Euler angles about z in the data range from {np.rad2deg(E[:, 2].min()):.1f} to {np.rad2deg(E[:, 2].max()):.1f} degrees")
estimates = {"naive Euler average": Rot.from_euler("xyz", E.mean(0)).as_matrix(),
             "naive quaternion average": Rot.from_quat(Q.mean(0)).as_matrix(),
             "sign-aligned quaternion average": Rot.from_quat(Qa.mean(0)).as_matrix(),
             "chordal L2 mean (SVD)": chordal,
             "scipy Rotation.mean()": samples.mean().as_matrix(),
             "geodesic L2 (Karcher) mean": Rk}
for name, Rm in estimates.items():
    print(f"  {name:32s} {err_deg(Rm):8.3f} degrees from the true rotation")

print(f"chordal vs scipy mean: {np.rad2deg(angle(chordal.T @ estimates['scipy Rotation.mean()'])):.1e} degrees; chordal vs Karcher: {np.rad2deg(angle(chordal.T @ Rk)):.4f} degrees")

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds, except the timings.)

  1. Rodrigues' formula is right. It matched SciPy's from_rotvec to 8.9e-16 and expm of the skew-symmetric matrix to 2.9e-15, and $\log(\exp(\omega)) = \omega$ held to 8.8e-14 for 2,000 rotations with angles up to $\pi$. The SE(3) closed form matched expm of the $4 \times 4$ twist matrix to 4.4e-16.
  2. Edge cases need care. At $\pi - 10^{-9}$ the textbook log formula was off by 1.3e-07, while the symmetric-part formula stayed at 8.9e-16. For a rotation by $10^{-8}$ rad, the arccos formula returned 0; atan2 and SciPy returned 1.000e-08.
  3. Euler angles and quaternions jump; the 6-D representation does not. Along a path whose neighbouring rotations differ by only 0.1°, the Euler angle about z jumped by 359.9° and the quaternion with $w \ge 0$ jumped by 1.999 (its z component went from +1 to −1), while the two matrix columns changed by at most 0.0017. At pitch 90°, Euler angles (10, 90, 20) and (40, 90, 50) gave the same matrix, and SciPy read it back as (−10, 90, 0) with a gimbal-lock warning.
  4. The representation decided the worst cases. On 5,000 test rotations, the 6-D network had mean error 1.81° and worst 5.8°. The quaternion network had mean 4.13°, but a 99th percentile of 26.5° and a worst case of 178.7°; Euler angles were worst, with mean 9.29°, 99th percentile 118.2° and worst 177.2°. This is what Zhou et al. (2019) predict. Even the 6-D network stayed behind the closed-form Procrustes solution (mean 1.20°, worst 3.4°): when correspondences are known, solve with the SVD and learn only what has no closed form.
  5. Average rotations on the group. With the data straddling ±180° about z, averaging Euler angles landed 174.4° from the truth, and averaging quaternions with random signs 61.4° away. Sign-aligned quaternions (2.090°), the chordal mean (2.036°, identical to SciPy's Rotation.mean() to 2.3e-14°) and the Karcher mean (2.108°, 7 iterations) all worked and were within 0.08° of each other; their remaining error comes from the noise in 50 samples.
