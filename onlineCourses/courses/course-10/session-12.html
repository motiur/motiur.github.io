1. A graph with three kinds of geometry¶

The test graph is synthetic: a cycle of 16 nodes, a binary tree of depth 4 (31 nodes) hanging from cycle node 0, and a $4 \times 4$ grid hanging from cycle node 8. Real graphs mix such parts too: a social network has tree-like hierarchies and cycles, a road network has grids and trees. We keep the shortest-path distances of the whole graph, and label each node by its part.

import time, itertools
import numpy as np
import networkx as nx
import torch
import matplotlib.pyplot as plt

t_start = time.time()
torch.set_num_threads(1)
torch.set_default_dtype(torch.float64)
np.random.seed(0); torch.manual_seed(0)

G = nx.cycle_graph(16)
part = {v: "cycle" for v in G}
tree = nx.balanced_tree(2, 4)
for u, v in tree.edges():
    G.add_edge(u + 16, v + 16)
part.update({v + 16: "tree" for v in tree})
G.add_edge(0, 16)                                             # tree root hangs from cycle node 0
grid = nx.grid_2d_graph(4, 4)
gid = {v: 16 + tree.number_of_nodes() + i for i, v in enumerate(grid)}
for u, v in grid.edges():
    G.add_edge(gid[u], gid[v])
part.update({gid[v]: "grid" for v in grid})
G.add_edge(8, gid[(0, 0)])                                    # grid corner hangs from cycle node 8

n = G.number_of_nodes()
parts = np.array([part[i] for i in range(n)])
D = np.zeros((n, n))
for u, row in nx.all_pairs_shortest_path_length(G):
    for v, l in row.items():
        D[u, v] = l
print(f"{n} nodes, {G.number_of_edges()} edges, diameter {int(D.max())}; nodes per part: "
      + ", ".join(f"{p} {np.sum(parts == p)}" for p in ["tree", "cycle", "grid"]))

pos = nx.kamada_kawai_layout(G)
plt.figure(figsize=(6, 3.4))
colors = {"tree": "C0", "cycle": "C3", "grid": "C2"}
nx.draw_networkx_edges(G, pos, alpha=0.4)
for p, col in colors.items():
    nx.draw_networkx_nodes(G, pos, nodelist=[v for v in G if part[v] == p], node_size=25, node_color=col, label=p)
plt.legend(fontsize=8); plt.axis("off"); plt.title("test graph: a tree, a cycle and a grid", fontsize=10)
plt.tight_layout(); plt.show()

2. Diagnosing the geometry of each part¶

Two diagnostics, both from distances only.

Four-point δ (session 8), computed exactly over all quadruples inside each part, relative to the part's diameter: 0 for a tree, up to 1.

A triangle test for curvature (the idea behind the estimate of Gu et al. 2019). For a triangle $a, b, c$, let $m$ be the midpoint of a shortest path from $b$ to $c$. In flat space the parallelogram law fixes the length of the median: $$d(a, m)_{\text{flat}} = \sqrt{\tfrac12\big(d(a, b)^2 + d(a, c)^2\big) - \tfrac14 d(b, c)^2}.$$ On a sphere the true $d(a, m)$ is longer than this, in hyperbolic space shorter. We report $d(a, m)/d(a, m)_{\text{flat}} - 1$: positive suggests positive curvature, negative suggests negative curvature. In a graph we use pairs $b, c$ at even distance, so that the midpoint is a node.

First we check the sign rule on random small triangles in the unit sphere, the plane and the hyperbolic plane (Lorentz model), where the geodesic midpoint of $x$ and $y$ is the normalized $x + y$ (sphere and hyperboloid) or $(x + y)/2$ (plane). Then we apply it to every triangle inside each part of the graph.

def four_point_exact(Dm):
    q = np.array(list(itertools.combinations(range(len(Dm)), 4)))
    x, y, z, w = q.T
    S = np.sort(np.stack([Dm[x, y] + Dm[z, w], Dm[x, z] + Dm[y, w], Dm[x, w] + Dm[y, z]]), axis=0)
    return ((S[2] - S[1]) / 2).max()

rng = np.random.default_rng(0)
N = 20000
def cap_points(kind):                                         # random points within about 1 of a base point
    v = rng.normal(size=(N, 2)) * 0.5; r = np.linalg.norm(v, axis=1, keepdims=True)
    if kind == "sphere":
        return np.concatenate([np.sin(r) * v / r, np.cos(r)], 1)
    if kind == "hyperbolic":
        return np.concatenate([np.cosh(r), np.sinh(r) * v / r], 1)
    return v
minkowski = lambda x, y: -x[:, 0] * y[:, 0] + (x[:, 1:] * y[:, 1:]).sum(1)
dist_fn = {"sphere": lambda x, y: np.arctan2(np.linalg.norm(np.cross(x, y), axis=1), (x * y).sum(1)),
           "plane": lambda x, y: np.linalg.norm(x - y, axis=1),
           "hyperbolic": lambda x, y: np.arccosh(np.maximum(-minkowski(x, y), 1))}
mid_fn = {"sphere": lambda b, c: (b + c) / np.linalg.norm(b + c, axis=1, keepdims=True),
          "plane": lambda b, c: (b + c) / 2,
          "hyperbolic": lambda b, c: (b + c) / np.sqrt(-minkowski(b + c, b + c))[:, None]}
print("triangle test in the model spaces (20,000 random triangles each):")
for kind in ["sphere", "plane", "hyperbolic"]:
    a, b, c = cap_points(kind), cap_points(kind), cap_points(kind)
    d, m = dist_fn[kind], mid_fn[kind](b, c)
    ratio = d(a, m) / np.sqrt((d(a, b)**2 + d(a, c)**2) / 2 - d(b, c)**2 / 4) - 1
    print(f"  {kind:10s}: mean {ratio.mean():+.4f}, positive {np.mean(ratio > 1e-9):.0%}, negative {np.mean(ratio < -1e-9):.0%}"
          + (f" (midpoint check: |d(b,m) - d(b,c)/2| <= {np.abs(d(b, m) - d(b, c) / 2).max():.0e})" if kind != "plane" else ""))

def triangle_ratios(nodes):
    out = []
    for b, c in itertools.combinations(nodes, 2):
        L = D[b, c]
        if L < 2 or L % 2:
            continue
        m = nodes[(D[b, nodes] == L / 2) & (D[c, nodes] == L / 2)][0]
        for a in nodes:
            flat2 = (D[a, b]**2 + D[a, c]**2) / 2 - L**2 / 4
            if a not in (b, c, m) and flat2 > 0:
                out.append(D[a, m] / np.sqrt(flat2) - 1)
    return np.array(out)

print("\npart    2 delta/diameter   triangles   mean ratio - 1   positive   zero   negative")
for p in ["tree", "cycle", "grid"]:
    nodes = np.flatnonzero(parts == p)
    Dp = D[np.ix_(nodes, nodes)]
    r = triangle_ratios(nodes)
    print(f"{p:6s} {2 * four_point_exact(Dp) / Dp.max():12.3f} {len(r):13d} {r.mean():+14.3f} {np.mean(r > 1e-12):10.0%} {np.mean(np.abs(r) <= 1e-12):6.0%} {np.mean(r < -1e-12):9.0%}")

3. Product manifolds and Riemannian Adam¶

A product manifold $M_1 \times M_2$ (Gu et al. 2019) gives each node one point in every factor, and since geodesics move in all factors at once, distances add in squares: $d^2 = d_1^2 + d_2^2$. Our factors, each with a learnable radius $s$ (curvature $\pm 1/s^2$; for $\mathbb{E}$ the radius only rescales):

  • $\mathbb{E}^k$: points in $\mathbb{R}^k$, $d = s\|x - y\|$;
  • $S^2$: unit vectors in $\mathbb{R}^3$, $d = s\operatorname{atan2}(\|x \times y\|, x^\top y)$;
  • $S^1$: angles, $d = s\,|\text{wrap}(\theta_1 - \theta_2)|$;
  • $\mathbb{H}^2$: the Lorentz model, $\langle x, x\rangle_L = -1$, $d = s\operatorname{arcosh}(-\langle x, y\rangle_L)$ (session 6).

We minimize the mean of $(d_{\text{emb}}/d_G - 1)^2$ over all 1,953 pairs. The Riemannian gradient is the Euclidean gradient projected onto the tangent space (sphere: $g - (x^\top g)x$; hyperboloid: flip the sign of the 0th component, then add $\langle x, h\rangle_L x$), the step is the exp map, and Riemannian Adam (Bécigneul & Ganea 2019) keeps a first moment that is moved to the new tangent space by projection after each step and one scalar second moment per point (session 5). The cell checks that each Riemannian gradient predicts the change of the loss along a geodesic, and that points stay on their manifolds.

iu = np.triu_indices(n, 1)
I0, I1, Dg = torch.tensor(iu[0]), torch.tensor(iu[1]), torch.tensor(D[iu])
pair_part = np.where(parts[iu[0]] == parts[iu[1]], parts[iu[0]], "between parts")
mink = lambda x, y: -x[..., 0] * y[..., 0] + (x[..., 1:] * y[..., 1:]).sum(-1)

def factor_dist(kind, a, b):
    if kind == "E":
        return ((a - b) ** 2).sum(-1).clamp_min(1e-18).sqrt()
    if kind == "S":
        return torch.atan2(torch.linalg.cross(a, b).norm(dim=-1).clamp_min(1e-18), (a * b).sum(-1))
    if kind == "S1":
        return (torch.remainder(a[..., 0] - b[..., 0] + np.pi, 2 * np.pi) - np.pi).abs().clamp_min(1e-12)
    return torch.arccosh((-mink(a, b)).clamp_min(1 + 1e-12))     # "H"

def init(kind, dim, g):
    if kind == "E":
        return torch.randn(n, dim, generator=g)
    if kind == "S":
        x = torch.randn(n, 3, generator=g); return x / x.norm(dim=-1, keepdim=True)
    if kind == "S1":
        return torch.rand(n, 1, generator=g) * 2 * np.pi
    v = torch.randn(n, 2, generator=g) * 0.5; r = v.norm(dim=-1, keepdim=True)
    return torch.cat([torch.cosh(r), torch.sinh(r) * v / r], -1)

def rgrad(kind, x, g):
    if kind == "S":
        return g - (x * g).sum(-1, keepdim=True) * x
    if kind == "H":
        h = g.clone(); h[:, 0] = -h[:, 0]
        return h + mink(x, h)[:, None] * x
    return g

def rnorm2(kind, v):
    return mink(v, v).clamp_min(0)[:, None] if kind == "H" else (v * v).sum(-1, keepdim=True)

def rexp(kind, x, u):
    if kind == "S":
        nu = u.norm(dim=-1, keepdim=True).clamp_min(1e-18)
        return torch.cos(nu) * x + torch.sin(nu) * u / nu
    if kind == "H":
        nu = mink(u, u).clamp_min(1e-18).sqrt()[:, None]
        y = torch.cosh(nu) * x + torch.sinh(nu) * u / nu
        y[:, 0] = torch.sqrt(1 + (y[:, 1:] ** 2).sum(-1))      # re-project against rounding
        return y
    return x + u

def transport(kind, y, m):                                    # move the momentum to the new tangent space
    if kind == "S":
        return m - (y * m).sum(-1, keepdim=True) * y
    if kind == "H":
        return m + mink(y, m)[:, None] * y
    return m

def distances(spec, Xs, rho):
    return sum((torch.exp(rho[i]) * factor_dist(k, X[I0], X[I1])) ** 2 for i, ((k, _), X) in enumerate(zip(spec, Xs))).clamp_min(1e-18).sqrt()

# check: the Riemannian gradient predicts the change of the loss along a geodesic, for the sphere and the hyperboloid
g0 = torch.Generator().manual_seed(0)
for kind in ["S", "H"]:
    spec = [(kind, 2)]
    X = init(kind, 2, g0).requires_grad_(True); rho = torch.tensor([np.log(5.0)])
    loss = ((distances(spec, [X], rho) / Dg - 1) ** 2).mean(); loss.backward()
    grad = rgrad(kind, X.detach(), X.grad)
    v = rgrad(kind, X.detach(), torch.randn(X.shape, generator=g0))             # a random tangent direction
    inner = (mink(grad, v).sum() if kind == "H" else (grad * v).sum()).item()
    eps = 1e-6
    with torch.no_grad():
        f = lambda t: ((distances(spec, [rexp(kind, X, t * v)], rho) / Dg - 1) ** 2).mean().item()
        fd = (f(eps) - f(-eps)) / (2 * eps)
    print(f"{'sphere' if kind == 'S' else 'hyperboloid'}: <grad, v> = {inner:.8f}, finite difference along exp_x(t v) = {fd:.8f}")

def embed(spec, steps=2000, lr=0.05, seed=0, b1=0.9, b2=0.999, eps=1e-8):
    g = torch.Generator().manual_seed(seed)
    Xs = [init(k, dim, g).requires_grad_(True) for k, dim in spec]
    rho = torch.zeros(len(spec), requires_grad=True)          # log of each factor's radius
    ms, vs = [torch.zeros_like(X) for X in Xs], [torch.zeros(n, 1) for _ in Xs]
    mr, vr = torch.zeros(len(spec)), torch.zeros(len(spec))
    for it in range(1, steps + 1):
        loss = ((distances(spec, Xs, rho) / Dg - 1) ** 2).mean()
        for X in Xs:
            X.grad = None
        rho.grad = None
        loss.backward()
        with torch.no_grad():
            for j, ((k, _), X) in enumerate(zip(spec, Xs)):
                gr = rgrad(k, X, X.grad)
                ms[j] = b1 * ms[j] + (1 - b1) * gr
                vs[j] = b2 * vs[j] + (1 - b2) * rnorm2(k, gr)
                Y = rexp(k, X, -lr * (ms[j] / (1 - b1**it)) / ((vs[j] / (1 - b2**it)).sqrt() + eps))
                ms[j] = transport(k, Y, ms[j]); X.copy_(Y)
            mr = b1 * mr + (1 - b1) * rho.grad; vr = b2 * vr + (1 - b2) * rho.grad**2
            rho -= lr * (mr / (1 - b1**it)) / ((vr / (1 - b2**it)).sqrt() + eps)
    with torch.no_grad():
        ratio = (distances(spec, Xs, rho) / Dg).numpy()
        on_manifold = max([(mink(X, X) + 1).abs().max().item() for (k, _), X in zip(spec, Xs) if k == "H"]
                          + [(X.norm(dim=-1) - 1).abs().max().item() for (k, _), X in zip(spec, Xs) if k == "S"] + [0.0])
    return dict(avg=np.mean(np.abs(ratio - 1)), worst=ratio.max() / ratio.min(), radii=torch.exp(rho).detach().numpy(),
                parts={p: np.mean(np.abs(ratio[pair_part == p] - 1)) for p in ["tree", "cycle", "grid", "between parts"]},
                off=on_manifold, x0=max([X[:, 0].max().item() for (k, _), X in zip(spec, Xs) if k == "H"] + [1.0]))

5. Learnable curvature with a library (NOT RUN here)¶

geoopt implements the κ-stereographic model, whose curvature κ can be learned and can pass through 0, so one factor can move between spherical, flat and hyperbolic geometry (Bachmann et al. 2020; Skopek et al. 2020), together with Riemannian Adam.

# NOT RUN: needs geoopt (pip install geoopt); check the API against your installed version
import geoopt
factors = [geoopt.Stereographic(k=-1.0, learnable=True), geoopt.Stereographic(k=1.0, learnable=True)]
points = [geoopt.ManifoldParameter(f.expmap0(0.1 * torch.randn(n, 2)), manifold=f) for f in factors]
opt = geoopt.optim.RiemannianAdam(points + [f.k for f in factors], lr=0.05)
for it in range(2000):
    d = sum(f.dist(x[I0], x[I1]) ** 2 for f, x in zip(factors, points)).clamp_min(1e-18).sqrt()
    loss = ((d / Dg - 1) ** 2).mean()
    opt.zero_grad(); loss.backward(); opt.step()
print("learned curvatures:", [round(f.k.item(), 3) for f in factors], "average distortion:", ((d / Dg - 1).abs().mean()).item())

7. Planning the capstone¶

The capstone (see the course syllabus) compares a curved-space model with a strong Euclidean baseline on data whose geometry matters. Before you train anything:

  1. Diagnose. Measure what you can: δ-hyperbolicity and the triangle test for graphs, concentration on the sphere for directions, the spread of eigenvalues for covariance matrices.
  2. Match budgets. Same dimension or parameter count, same training steps, and the same tuning effort (learning rates, seeds) for every geometry.
  3. Use a strong baseline. A tuned Euclidean model, and the simplest closed-form method when one exists (Procrustes in session 10, logistic regression in session 8).
  4. Check numerics. float64 near boundaries, clipping, points staying on their manifolds, NaN counts.
  5. Report every run. Means with spread over at least three seeds, failed runs included, and say plainly when the curved model did not help.

What to notice¶

(Written from the run above; your numbers will match if you keep the seeds, except the timings.)

  1. The triangle test reads curvature correctly in the model spaces. On random small triangles the median-to-flat ratio minus 1 averaged +0.0252 on the sphere (all positive), 0 in the plane and −0.0182 in the hyperbolic plane (all negative). The geodesic midpoints were exact to 9e-14.
  2. The diagnostics separate the tree from the cycle, but not the grid. The tree had $2\delta/\text{diameter} = 0$ and a mean ratio of −0.174 (66% of its triangles negative, none positive); the cycle had 1.000 and +0.283 (27% positive, none negative). The grid also had $2\delta/\text{diameter} = 1.000$ and a positive mean (+0.126) with both signs (20% positive, 25% negative): grid distances count city blocks, which no flat plane reproduces exactly, so treat these tests as hints.
  3. The Riemannian gradients are right (they matched finite differences along geodesics to 8 digits), and points stayed on their manifolds up to rounding. The largest error, 3.0e-08, came from Lorentz points with coordinates up to $x_0 = 3.3 \times 10^4$, about 11 units from the origin: in the Lorentz model, rounding grows with the square of the coordinates (session 6).
  4. Hyperbolic factors won; mixed curvature won most. Mean average distortion over three seeds: $\mathbb{E}^2$ 0.1253, $S^2$ 0.1258, $\mathbb{H}^2$ 0.0756, $\mathbb{E}^3$ 0.0929, $\mathbb{H}^2 \times S^1$ 0.0671 and $\mathbb{H}^2 \times \mathbb{E}^1$ 0.0592. The 2-D hyperbolic plane beat 3-D Euclidean space on average, mostly through the tree (0.087 against 0.149), but it was worst on the cycle (0.249) and had a large worst case (7.26 against 2.56). The products kept the tree's gain (0.073 and 0.063) without losing as much elsewhere.
  5. The spherical factors did not do what we expected. $S^2$ learned a radius of about 25, much larger than the graph, and behaved like the plane (0.1258 against 0.1253). In $\mathbb{H}^2 \times S^1$, the circle kept a useful radius (6.05) in one seed, which gave that product's best run (0.0618), but shrank to 0.65 and 0.45 in the other two. Against expectation, a flat extra dimension ($\mathbb{H}^2 \times \mathbb{E}^1$) beat the circle on the cycle itself (0.144 against 0.194). A geometry that fits on paper still has to be found by the optimizer.
  6. Seeds matter. The spread between seeds was 0.0618–0.0717 for $\mathbb{H}^2 \times S^1$ and 0.0550–0.0638 for $\mathbb{H}^2 \times \mathbb{E}^1$, about as large as the gap between these two spaces. With one seed each, either could have looked like the winner.
